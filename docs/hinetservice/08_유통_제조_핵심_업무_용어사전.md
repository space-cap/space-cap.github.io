# 유통·제조 핵심 업무 용어사전

> 목표: ERP, MES, CRM, SI 현장에서 자주 듣는 용어를 빠르게 찾아볼 수 있게 정리한다.

## 1. 영업·판매 용어

| 용어 | 의미 | 실무에서 듣는 말 |
| --- | --- | --- |
| 거래처 | 물건이나 서비스를 사고파는 상대 회사 | "거래처별 단가가 달라요." |
| 고객 | 제품이나 서비스를 구매하는 대상 | "고객별 구매 이력을 보고 싶어요." |
| 견적 | 판매 전 가격과 조건을 제시하는 문서 또는 데이터 | "견적서 양식을 바꿔 주세요." |
| 수주 | 고객 주문을 접수하는 업무 | "수주가 들어오면 생산계획으로 넘겨 주세요." |
| 출고 | 고객에게 물건을 내보내는 업무 | "출고 처리하면 재고가 빠져야 해요." |
| 매출 | 판매가 확정되어 회계상 수익으로 잡히는 것 | "출고 기준 매출인지, 세금계산서 기준 매출인지 확인해야 해요." |
| 수금 | 고객에게 받을 돈을 실제로 받은 것 | "수금 등록했는데 미수금이 안 줄어요." |
| 미수금 | 매출은 잡혔지만 아직 받지 못한 돈 | "거래처별 미수금 현황을 뽑아 주세요." |
| 단가 | 품목 하나의 가격 | "거래처별 단가를 적용해 주세요." |
| 거래명세서 | 거래 내용을 고객에게 전달하는 출력물 | "거래명세서에 바코드를 넣어 주세요." |

## 2. 구매·입고 용어

| 용어 | 의미 | 실무에서 듣는 말 |
| --- | --- | --- |
| 공급사 | 물건을 공급하는 거래처 | "공급사별 발주 현황이 필요해요." |
| 발주 | 공급사에게 구매를 요청하는 업무 | "발주서 출력 양식을 수정해 주세요." |
| 입고 | 구매한 물건이 창고에 들어오는 업무 | "입고하면 재고가 늘어야 해요." |
| 매입 | 구매가 회계상 비용 또는 자산으로 잡히는 것 | "입고와 매입을 분리해서 처리해요." |
| 지급 | 공급사에게 대금을 지불하는 것 | "지급 예정 금액을 보고 싶어요." |
| 미지급금 | 매입은 되었지만 아직 지급하지 않은 돈 | "공급사별 미지급금을 확인해 주세요." |
| 구매단가 | 매입할 때 적용되는 가격 | "최근 구매단가를 자동으로 가져오게 해 주세요." |
| 납기 | 물건을 받거나 납품해야 하는 날짜 | "납기 지연 건만 조회하고 싶어요." |

## 3. 재고·물류 용어

| 용어 | 의미 | 실무에서 듣는 말 |
| --- | --- | --- |
| 품목 | 판매, 구매, 생산, 재고 관리의 대상 | "품목코드 체계를 새로 잡아야 해요." |
| 품목코드 | 품목을 식별하는 고유 코드 | "같은 품목이 코드 두 개로 등록됐어요." |
| 창고 | 재고가 보관되는 장소 | "창고별 재고를 따로 봐야 해요." |
| 재고 | 현재 보유 중인 물건 수량 | "ERP 재고와 실제 재고가 안 맞아요." |
| 가용재고 | 실제로 판매나 생산에 사용할 수 있는 재고 | "예약 수량을 빼고 가용재고를 보여 주세요." |
| 안전재고 | 품절을 막기 위해 최소로 보유해야 하는 재고 | "안전재고 밑으로 내려가면 발주 알림이 필요해요." |
| 재고실사 | 실제 창고 수량을 세는 작업 | "PDA로 실사재고를 등록해요." |
| 재고조정 | 시스템 재고를 실제 재고에 맞추는 작업 | "조정 사유를 필수로 입력하게 해 주세요." |
| 창고이동 | 한 창고에서 다른 창고로 재고를 옮기는 것 | "본사창고에서 매장창고로 이동 처리해 주세요." |
| 로케이션 | 창고 안의 상세 위치 | "A-01 선반에 있는 재고만 조회하고 싶어요." |
| 송장 | 택배 배송을 위한 운송장 정보 | "송장번호를 택배사로 전송해야 해요." |

| BOM | 제품을 만들기 위한 자재 목록 | "BOM 기준으로 자재 소요량을 계산해 주세요." |
| 생산계획 | 어떤 제품을 언제 얼마나 만들지 정하는 것 | "수주 기반 생산계획을 만들어요." |
| 작업지시 | 현장에 실제 작업을 지시하는 데이터 | "작업지시가 MES로 내려가야 해요." |
| 공정 | 제품을 만드는 작업 단계 | "공정별 실적을 보고 싶어요." |
| 라인 | 생산이 흐르는 설비나 작업 흐름 단위 | "라인별 생산량을 집계해 주세요." |
| 설비 | 생산에 사용하는 기계나 장비 | "설비별 비가동 시간을 관리해요." |
| 작업자 | 생산 작업을 수행하는 사람 | "작업자별 실적을 남겨야 해요." |
| 생산실적 | 실제 생산한 결과 | "생산실적이 ERP 재고로 반영돼야 해요." |
| 양품 | 정상 제품 | "양품 수량만 제품 입고 처리해요." |
| 불량 | 기준을 만족하지 못한 제품 | "불량 유형을 선택하게 해 주세요." |
| 수율 | 투입 대비 양품 비율 | "수율이 낮은 공정을 찾아야 해요." |
| Capa | 생산 가능 능력 | "설비 Capa 대비 계획이 초과됐어요." |

## 11. 처음에는 이렇게 외우기

모든 용어를 한 번에 외우려고 하지 말고 흐름으로 묶어서 기억한다.

```text
영업: 견적 -> 수주 -> 출고 -> 매출 -> 수금
구매: 발주 -> 입고 -> 매입 -> 지급
재고: 입고 -> 출고 -> 이동 -> 실사 -> 조정
생산: BOM -> 계획 -> 지시 -> 실적 -> 검사 -> 입고
프로젝트: 분석 -> 설계 -> 개발 -> 테스트 -> 오픈 -> 안정화
```

현장에서 모르는 말을 들으면 이 용어사전에 추가하면서 자기만의 실무 사전을 만들어 가면 좋다.
