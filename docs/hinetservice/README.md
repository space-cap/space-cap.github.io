## 먼저 잡아야 할 큰 그림

하이네트서비스의 공개 제품군을 기준으로 보면, 회사의 업무는 중소·중견 제조/유통 기업의 업무 흐름을 시스템으로 연결하는 일에 가깝습니다.

- `ERP`: 수주, 발주, 입출고, 재고, 회계, 인사, 생산 같은 회사의 핵심 업무를 통합 관리한다.
- `MES`: 생산 현장의 작업지시, 공정, 설비, 작업실적, 품질, 추적성을 관리한다.
- `CRM`: 고객, 상담, 영업기회, 계약, AS, 클레임 같은 고객 접점을 관리한다.
- `SI`: 고객사의 업무에 맞게 시스템을 분석, 설계, 개발, 연동, 오픈하는 프로젝트 방식이다.
- `SM/유지보수`: 이미 오픈된 시스템을 안정적으로 운영하고, 오류 수정과 개선 요청을 처리한다.

## 입사 초기 읽는 방법

처음부터 모든 용어를 외우려고 하기보다, 업무 흐름을 먼저 이해하는 것이 좋습니다.

1. 회사가 어떤 시스템을 파는지 파악한다.
2. ERP에서 `수주 -> 출고 -> 매출 -> 수금` 흐름을 이해한다.
3. MES에서 `작업지시 -> 생산 -> 검사 -> 실적 -> 출고` 흐름을 이해한다.
4. 고객 요청이 어떤 문서와 화면, DB, 배포로 이어지는지 본다.
5. 용어사전을 반복해서 보며 현장에서 들리는 말을 연결한다.
