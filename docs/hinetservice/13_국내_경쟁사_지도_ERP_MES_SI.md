# 국내 경쟁사 지도: ERP·MES·SI

> 목표: 하이네트서비스가 속한 ERP, MES, SI 시장의 국내 경쟁 구도를 큰 범주별로 이해한다.

## 1. 경쟁사를 나누는 기준

하이네트서비스의 경쟁사를 하나의 목록으로만 보면 혼란스럽다.

ERP, MES, SI 시장은 고객 규모와 업종, 구축 방식에 따라 경쟁사가 달라진다.

이 문서에서는 다음 기준으로 나눈다.

1. 대형 SI·IT서비스 업체
2. 국내 ERP 패키지 업체
3. MES·스마트팩토리 전문 업체
4. 중소·중견 맞춤형 ERP/MES 업체

하이네트서비스는 공개 자료 기준으로 중소·중견 제조/유통 기업을 대상으로 ERP, MES, 그룹웨어, 주변 연동을 제공하는 회사에 가깝다. 따라서 대기업 SI 업체와 항상 직접 경쟁한다고 보기는 어렵지만, 시장의 기준점으로 알아둘 필요가 있다.

## 2. 대형 SI·IT서비스 업체

대형 SI 업체는 대기업, 그룹사, 공공, 글로벌 제조기업의 대규모 프로젝트를 수행한다.

| 업체 | 주요 영역 | 알아둘 포인트 |
| --- | --- | --- |
| 삼성SDS | ERP, Nexplant MES, 스마트팩토리, IT운영 | ERP 구축/운영과 MES 솔루션을 모두 제공하는 대형 IT서비스 업체 |
| LG CNS | Factova MES, 스마트팩토리, ERP, 클라우드 | 제조 DX, MES, 가상공장, AI 기반 제조 영역이 강함 |
| SK AX | 제조 AX, MES, ERP, AI, 클라우드 | 제조와 AI 전환 중심으로 대형 IT서비스 제공 |
| 현대오토에버 | 자동차·부품 제조, MES, SDF | 완성차와 부품 제조 밸류체인 기반 스마트팩토리 |
| 롯데이노베이트 | 유통, 물류, 리테일, IT서비스 | 롯데그룹 기반 유통·물류 IT 역량 |
| CJ올리브네트웍스 | 식품·바이오 스마트팩토리, MES/QMS/WMS | 식품·바이오 제조와 품질관리 영역에서 참고할 만함 |
| 포스코DX | 철강·산업 자동화, 스마트팩토리 | 중후장대 산업 현장과 자동화 중심 |

이 업체들은 규모와 고객군이 다르지만, 제안서나 고객 미팅에서 "대형사 수준의 기능"을 비교 대상으로 언급할 수 있다.

## 3. 국내 ERP 패키지 업체

ERP 시장에서 자주 비교되는 업체들이다.

| 업체 | 주요 특징 | 하이네트서비스 관점의 비교 포인트 |
| --- | --- | --- |
| 더존비즈온 | 회계·ERP·그룹웨어 통합 플랫폼, 국내 인지도 높음 | 회계와 그룹웨어 중심 표준 패키지 경쟁력 |
| 영림원소프트랩 | K-System, 중견기업 ERP, 업종별 구축 | 중견 제조·유통 ERP 구축 경쟁 |
| 이카운트 | 웹 기반 저비용 ERP, 빠른 도입 | 가격과 도입 속도에서 비교될 수 있음 |
| 이맥스솔루션 | ERP, MES, QMS, 그룹웨어, 소스 제공·기술이전 강조 | 맞춤형 ERP와 통합 구축 관점에서 비교 |

중소기업 고객은 가격, 도입 기간, 커스터마이징 가능성, 유지보수 응답 속도를 중요하게 본다.

## 4. MES·스마트팩토리 전문 업체

MES는 제조 현장에 가까운 영역이므로 ERP 업체와 다른 경쟁사가 등장한다.

| 업체 | 주요 특징 | 비교 포인트 |
| --- | --- | --- |
| 삼성SDS | Nexplant MES, 반도체·디스플레이·2차전지 | 고도화 제조, 대규모 자동화 |
| LG CNS | Factova MES, 제조 기준정보, WMS | 제조 DX와 스마트팩토리 통합 |
| 현대오토에버 | 표준 MES, SDF, 자동차 제조 | 자동차 생산라인과 유연 제조 |
| 한화시스템 ICT | XPERION MES | 모듈형·맞춤형 MES |
| 한국네트웍스 | Pi-MES/air-MES, GMP/HACCP MES | 일반 제조, 화학, 제약, 식음료 |
| CJ올리브네트웍스 | FactoryOne, 식품·바이오 스마트팩토리 | 식품, 바이오, QMS, HACCP |

하이네트서비스가 중소·중견 제조 고객을 대상으로 HIPRO-MES를 제공한다면, 경쟁 포인트는 대형 자동화보다 고객 업무 적합성, 비용, 빠른 대응, ERP와의 실시간 연동이 될 가능성이 높다.

## 5. 중소·중견 맞춤형 ERP/MES 업체

하이네트서비스와 더 직접적으로 비교될 가능성이 높은 영역이다.

이 범주에는 다음 유형이 있다.

- 특정 업종 전문 ERP 업체
- 스마트공장 공급기업 등록 업체
- MES 전문 중소기업
- 바코드/PDA/POS 연동 전문 업체
- 더존, 이카운트, Odoo 커스터마이징 컨설팅 업체
- 자체 ERP/MES를 보유한 지역 기반 SI 업체

이 업체들은 규모는 작아도 고객 입장에서는 실질적인 경쟁사다.

고객은 보통 다음을 비교한다.

- 우리 업종을 이해하는가
- 기존 업무를 얼마나 반영해 주는가
- 구축 비용은 얼마인가
- 유지보수 대응이 빠른가
- 정부지원사업 경험이 있는가
- 바코드, 택배, 쇼핑몰, 공공 API 연동 경험이 있는가
- 개발자와 직접 소통할 수 있는가

## 6. 경쟁 비교 항목

경쟁사를 볼 때는 단순히 회사 규모보다 다음 항목으로 비교하는 것이 좋다.

| 비교 항목 | 질문 |
| --- | --- |
| 고객 규모 | 소기업, 중소기업, 중견기업, 대기업 중 어디가 주 고객인가 |
| 업종 | 제조, 유통, 식품, 축산, 부품, 화학, 제약 중 어디에 강한가 |
| 제품 범위 | ERP만 하는가, MES와 그룹웨어까지 하는가 |
| 커스터마이징 | 고객 업무에 맞춰 수정 가능한가 |
| 연동 | 쇼핑몰, 택배, 은행, 국세청, 바코드, POS 연동 경험이 있는가 |
| 구축 방식 | 패키지 도입인가, SI 구축인가, 혼합형인가 |
| 유지보수 | 장애 대응과 개선 요청 속도가 빠른가 |
| 가격 | 초기 구축비와 유지보수비가 고객 예산에 맞는가 |
| 기술스택 | 고객 서버, 클라우드, DB, 모바일 대응이 가능한가 |
| 정부사업 | 스마트공장 지원사업 경험이 있는가 |

## 7. 하이네트서비스의 차별화 후보

공개 자료 기준으로 추정할 수 있는 차별화 후보는 다음과 같다.

- ERP와 MES를 함께 제공한다.
- 바코드, POS, 쇼핑몰, 택배, 모바일, 국세청 등 주변 연동이 다양하다.
- 중소·중견기업에 맞춘 수정 개발을 강조한다.
- 개발자와 직접 소통하는 서비스를 강조한다.
- 제조와 유통이 섞인 고객 업무에 대응할 수 있다.
- 스마트공장 구축 사례와 정부사업 페이지를 운영한다.

실제 차별화는 입사 후 영업자료, 고객 사례, 내부 제품 구조를 확인해 보완해야 한다.

## 8. 입사자가 경쟁사를 알아야 하는 이유

경쟁사를 아는 것은 영업팀만의 일이 아니다.

개발자도 경쟁사를 알면 다음을 이해할 수 있다.

- 고객이 왜 특정 기능을 요구하는가
- 고객이 어떤 시스템에서 이전해 왔는가
- 우리 제품의 강점과 약점이 무엇인가
- 어떤 기능은 표준으로 기대되는가
- 어떤 요구는 추가 개발로 봐야 하는가
- 고객에게 설명할 때 어떤 비교 관점이 필요한가

## 10. 이 문서에서 꼭 가져갈 것

하이네트서비스의 경쟁사는 하나의 회사군이 아니라 ERP, MES, SI, 스마트공장, 연동 개발 영역에 걸쳐 있다.

입사 초기에는 경쟁사를 외우기보다 "어떤 고객에게 어떤 방식으로 비교되는가"를 중심으로 이해하면 된다.
