# 스마트공장과 정부지원사업 이해

> 목표: 스마트공장이 무엇이고, ERP/MES 구축이 정부지원사업과 어떻게 연결되는지 이해한다.

## 1. 스마트공장이란 무엇인가

스마트공장은 생산 현장의 데이터를 수집하고 분석해서 생산성, 품질, 납기, 원가를 개선하는 공장이다.

단순히 자동화 설비가 많은 공장이 아니라, 업무와 설비에서 발생하는 데이터를 시스템으로 연결해 의사결정에 활용하는 것이 핵심이다.

스마트공장에서 자주 등장하는 시스템은 다음과 같다.

- ERP: 수주, 구매, 재고, 생산계획, 회계
- MES: 작업지시, 생산실적, 공정, 품질, LOT
- POP/PDA: 현장 데이터 입력
- WMS: 창고와 물류 관리
- QMS: 품질 관리
- 설비 데이터 수집: 센서, PLC, 장비 연동
- 모니터링: 생산현황, 설비상태, 불량률 대시보드

## 2. ERP/MES와 스마트공장의 관계

중소·중견 제조기업의 스마트공장 시작점은 ERP나 MES인 경우가 많다.

ERP는 회사 전체 업무 데이터를 정리하고, MES는 현장 실행 데이터를 잡는다. 둘이 연결되면 계획과 실적이 이어진다.

```text
ERP 수주/생산계획
-> MES 작업지시
-> 현장 생산실적
-> MES 품질/LOT 이력
-> ERP 재고/원가/납기 관리
```

이 흐름이 만들어지면 회사는 다음을 볼 수 있다.

- 어떤 주문이 생산 중인가
- 자재가 충분한가
- 생산이 계획보다 늦는가
- 불량이 어느 공정에서 많이 나는가
- 완제품 재고가 얼마인가
- 납기를 지킬 수 있는가

## 3. 정부지원사업의 기본 구조

스마트공장 정부지원사업은 중소·중견기업이 시스템 구축 비용 일부를 지원받아 스마트공장을 도입하도록 돕는 제도다.

일반적으로 다음 역할이 등장한다.

| 역할 | 의미 |
| --- | --- |
| 도입기업 | 스마트공장을 구축하려는 제조기업 |
| 공급기업 | ERP, MES, 설비연동 등 솔루션을 구축하는 기업 |
| 운영기관 | 사업 운영과 평가를 지원하는 기관 |
| 정부/전담기관 | 지원사업 공고, 예산, 기준, 점검을 관리 |
| 전문가/평가위원 | 사업계획, 중간점검, 최종점검 평가 |

하이네트서비스 같은 회사는 공급기업 역할로 참여할 가능성이 있다.

## 4. 구축 수준 개념

스마트공장 사업에서는 기업의 디지털화 수준을 단계로 나누어 관리한다.

세부 명칭과 기준은 사업연도와 공고에 따라 달라질 수 있으므로, 실제 프로젝트에서는 해당 연도 공고문을 반드시 확인해야 한다.

입문자는 다음 정도로 이해하면 된다.

| 수준 | 쉬운 설명 |
| --- | --- |
| 기초 | 종이·엑셀 업무를 시스템으로 전환하고 기본 데이터를 모음 |
| 중간 | ERP/MES 연동, 현장 실적 수집, 품질·재고 데이터 활용 |
| 고도화 | 설비 자동수집, 실시간 분석, 예측, 최적화, AI 활용 |

중요한 것은 "높은 단계"라는 말보다 고객사가 실제로 무엇을 개선하려는지다.

## 5. 사업 진행 흐름

스마트공장 정부지원사업은 보통 다음 흐름으로 진행된다.

```text
사업 공고 확인
-> 도입기업 발굴
-> 현장 진단
-> 사업계획서 작성
-> 신청
-> 선정 평가
-> 협약
-> 착수
-> 분석/설계
-> 개발/구축
-> 중간점검
-> 테스트
-> 최종점검
-> 성공판정
-> 사후관리
```

## 6. 주요 산출물

정부지원사업에서는 시스템뿐 아니라 문서가 매우 중요하다.

자주 등장하는 산출물은 다음과 같다.

- 사업계획서
- 구축 범위 정의서
- 요구사항정의서
- WBS
- 착수보고서
- 중간보고서
- 완료보고서
- 화면설계서
- 인터페이스 정의서
- 테스트 결과서
- 사용자 교육 자료
- 검수 확인서
- 성과 지표 자료

문서가 부족하면 실제 개발을 잘했더라도 점검에서 문제가 될 수 있다.

## 7. 성과 지표

스마트공장 사업은 "시스템을 만들었다"에서 끝나지 않고, 개선 효과를 봐야 한다.

성과 지표 예시는 다음과 같다.

- 생산성 향상
- 불량률 감소
- 납기 준수율 향상
- 재고 정확도 향상
- 작업시간 감소
- 수기 입력 감소
- 리드타임 단축
- 원가 정확도 향상

개발자는 성과 지표가 어떤 데이터에서 계산되는지 이해해야 한다.

## 8. 개발자가 주의할 점

### 8.1 범위 관리

정부지원사업은 협약된 범위가 중요하다. 고객 요청이라고 해서 모두 무상으로 추가하면 일정과 비용이 무너질 수 있다.

변경이 필요하면 변경 요청과 승인 절차를 확인해야 한다.

### 8.2 일정 관리

중간점검과 최종점검 날짜가 정해져 있으면 그 날짜에 맞춰 시연 가능한 상태가 필요하다.

완성도가 100%가 아니더라도 핵심 시나리오는 보여줄 수 있어야 한다.

### 8.3 증빙 관리

회의록, 교육 사진, 테스트 결과, 사용자 서명, 화면 캡처 같은 증빙이 필요할 수 있다.

개발자는 귀찮게 느껴도 프로젝트 방어를 위해 기록을 남겨야 한다.

### 8.4 실제 사용성

정부지원사업은 시스템 구축 자체가 목적이 아니다. 고객 현장에서 실제로 써야 한다.

사용자가 너무 불편하면 오픈 후 시스템이 방치될 수 있다.

## 9. 입사자가 먼저 확인할 것

- 회사가 스마트공장 공급기업으로 어떤 사업에 참여하는가
- 자주 구축하는 업종은 무엇인가
- 표준 사업계획서나 산출물 템플릿이 있는가
- 중간점검과 최종점검에서 자주 지적받는 항목은 무엇인가
- 성과 지표는 어떤 방식으로 산출하는가
- 정부지원사업과 일반 유상 프로젝트의 차이는 무엇인가

## 10. 이 문서에서 꼭 가져갈 것

스마트공장은 데이터 기반 제조 운영을 만드는 일이고, ERP/MES는 그 핵심 시스템이다.

정부지원사업에서는 개발 실력뿐 아니라 범위, 일정, 산출물, 증빙, 성과 지표가 중요하다. 입사자는 "기능을 만들었다"와 "사업 기준을 충족했다"가 다를 수 있다는 점을 기억해야 한다.
