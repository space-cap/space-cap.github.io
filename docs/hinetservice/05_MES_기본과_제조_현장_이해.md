# MES 기본과 제조 현장 이해

> 목표: MES가 왜 필요한지, ERP와 어떻게 다르며 제조 현장에서 어떤 데이터를 다루는지 이해한다.

## 1. MES란 무엇인가

MES는 `Manufacturing Execution System`의 약자다. 한국어로는 제조실행시스템이라고 부른다.

ERP가 회사 전체의 자원과 거래를 관리한다면, MES는 공장 현장에서 실제 생산이 어떻게 실행되는지를 관리한다.

쉽게 말하면 MES는 다음 질문에 답하는 시스템이다.

- 지금 어떤 작업을 하고 있는가?
- 어떤 설비에서 생산 중인가?
- 작업자는 누구인가?
- 어떤 자재를 투입했는가?
- 몇 개를 생산했고 몇 개가 불량인가?
- 어떤 LOT에서 만들어졌는가?
- 품질검사는 통과했는가?
- 문제가 생기면 어느 공정까지 추적할 수 있는가?

## 2. ERP와 MES의 역할 차이

ERP와 MES는 둘 다 생산과 관련이 있지만 관심사가 다르다.

| 구분 | ERP | MES |
| --- | --- | --- |
| 관심 범위 | 회사 전체 자원과 거래 | 제조 현장의 실행 |
| 시간 단위 | 일, 주, 월 단위 계획과 마감 | 실시간 또는 작업 단위 |
| 주요 데이터 | 수주, 발주, 재고, 매출, 회계, 생산계획 | 작업지시, 공정실적, 설비, 검사, 불량, LOT |
| 사용자 | 사무직, 영업, 구매, 회계, 생산관리 | 현장 작업자, 반장, 품질, 설비 담당 |
| 목적 | 경영 관리와 자원 계획 | 생산 실행, 추적성, 품질, 현장 통제 |

둘은 보통 이렇게 연결된다.

```text
ERP 생산계획/작업지시 -> MES 현장 작업 실행 -> MES 생산실적/품질정보 -> ERP 재고/원가/매출 반영
```

## 3. 제조 현장의 기본 단위

MES를 이해하려면 제조 현장의 단위를 알아야 한다.

| 용어 | 의미 |
| --- | --- |
| 공장 | 생산이 이루어지는 전체 장소 |
| 라인 | 특정 제품이나 공정을 수행하는 생산 흐름 |
| 공정 | 제품을 만들기 위한 작업 단계 |
| 설비 | 생산에 사용하는 기계나 장비 |
| 작업자 | 실제 작업을 수행하는 사람 |
| 작업장 | 작업이 이루어지는 물리적 구역 |
| 품목 | 생산 대상 또는 투입 자재 |
| LOT | 같은 조건으로 묶어 관리하는 생산/입고 단위 |

예를 들어 케이블 절단 업체라면 공정은 입고, 절단, 검사, 포장, 출고처럼 나뉠 수 있다. 식품 제조업체라면 계량, 혼합, 가열, 냉각, 포장, 검사처럼 나뉠 수 있다.

## 4. 작업지시와 생산실적

MES의 핵심은 작업지시와 생산실적이다.

### 4.1 작업지시

작업지시는 현장에 "무엇을, 언제, 얼마나, 어떤 공정에서 만들라"고 지시하는 데이터다.

주요 항목은 다음과 같다.

- 작업지시번호
- 품목
- 지시수량
- 납기
- 공정
- 설비
- 작업장
- 우선순위
- 투입 자재

### 4.2 생산실적

생산실적은 작업지시에 따라 실제로 수행한 결과다.

주요 항목은 다음과 같다.

- 생산수량
- 양품수량
- 불량수량
- 시작시간
- 종료시간
- 작업자
- 설비
- LOT
- 검사 결과

계획과 실적을 비교하면 생산성이 보인다.

## 5. 공정과 라우팅

공정은 제품을 만들기 위한 단계이고, 라우팅은 그 공정의 순서다.

예를 들어 어떤 제품의 라우팅이 다음과 같을 수 있다.

```text
원자재 입고 -> 절단 -> 가공 -> 검사 -> 포장 -> 제품입고
```

MES는 각 단계에서 작업이 제대로 진행되었는지 확인한다.

현장에서는 "앞 공정이 끝나지 않았는데 다음 공정으로 넘어가면 안 된다" 같은 통제가 필요하다. 이런 통제를 `인터락(Interlock)`이라고 부르기도 한다.

## 6. LOT와 추적성

MES에서 매우 중요한 개념이 LOT와 추적성이다.

`LOT`는 같은 조건으로 묶어서 관리하는 단위다. 원자재 입고 LOT, 생산 LOT, 검사 LOT처럼 쓰일 수 있다.

추적성은 문제가 생겼을 때 원인과 영향을 거슬러 올라가거나 내려갈 수 있는 능력이다.

예를 들어 어떤 완제품에서 불량이 발견되면 다음을 추적해야 할 수 있다.

- 어떤 원자재 LOT가 들어갔는가
- 어느 공급사에서 들어온 자재인가
- 어느 설비에서 생산했는가
- 작업자는 누구였는가
- 어떤 검사 결과가 있었는가
- 같은 LOT로 만든 제품이 어디로 출고되었는가

식품, 제약, 축산, 전자부품, 자동차부품 업종에서는 추적성이 특히 중요하다.

## 7. 바코드, PDA, POP

MES는 현장 데이터 입력이 중요하다. 사무실 PC만으로는 현장의 실시간 데이터를 모으기 어렵다.

그래서 다음 장비나 화면을 자주 사용한다.

| 도구 | 의미 | 용도 |
| --- | --- | --- |
| 바코드 | 품목, LOT, 위치 등을 빠르게 식별하는 코드 | 입출고, 공정 이동, 재고 실사 |
| PDA | 휴대용 단말기 | 창고, 현장, 이동 작업 입력 |
| POP | Point of Production | 현장 작업자가 생산실적을 입력하는 화면 |
| 키오스크 | 현장 터치 화면 | 작업지시 조회, 실적 입력 |
| 라벨 프린터 | 바코드 라벨 출력 장비 | 제품, 박스, 팔레트, 자재 라벨 |

바코드 시스템은 단순히 스캔하는 기능이 아니다. 잘 설계하면 데이터 입력 오류를 줄이고, LOT 추적성과 재고 정확도를 높인다.

## 8. 설비 연동과 데이터 수집

MES가 더 고도화되면 설비에서 데이터를 자동으로 가져온다.

예를 들어 다음 데이터를 수집할 수 있다.

- 설비 가동 상태
- 생산 수량
- 온도
- 압력
- 속도
- 검사값
- 알람
- 비가동 시간

설비 연동은 편리하지만 어렵다. 설비마다 통신 방식이 다르고, 데이터 형식도 다르며, 네트워크 상태와 현장 환경의 영향을 받는다.

개발자는 다음을 확인해야 한다.

- 설비가 어떤 프로토콜을 지원하는가
- 데이터 수집 주기는 얼마인가
- 누락 데이터는 어떻게 처리하는가
- 설비 시간이 서버 시간과 맞는가
- 장애 시 수동 입력이 가능한가
- 수집 데이터가 품질 판정이나 인터락에 쓰이는가

## 9. 품질과 불량 관리

MES는 생산 수량뿐 아니라 품질도 다룬다.

품질 관리에서는 다음 데이터가 중요하다.

- 검사 항목
- 검사 기준
- 검사 결과
- 합격/불합격
- 불량 유형
- 불량 원인
- 조치 내용

불량은 단순히 버리는 수량이 아니다. 어떤 공정에서 어떤 원인으로 불량이 발생했는지 분석해야 개선이 가능하다.

## 10. MES 프로젝트에서 현장 방문이 중요한 이유

MES는 책상 위에서만 설계하기 어렵다.

현장에 가면 문서에 없는 현실이 보인다.

- 작업자가 장갑을 끼고 있어 키보드 입력이 어렵다.
- 바코드 라벨이 먼지나 습기 때문에 잘 안 읽힌다.
- 설비 위치와 네트워크 위치가 멀다.
- 작업 순서가 문서와 다르다.
- 현장에서는 한 사람이 여러 설비를 동시에 본다.
- 생산이 멈추면 시스템 테스트도 어렵다.

MES 개발자는 현장의 물리적 제약을 이해해야 한다. 좋은 화면은 예쁜 화면이 아니라 작업자가 실수 없이 빠르게 쓸 수 있는 화면이다.

## 11. 입사자가 먼저 외울 MES 흐름

처음에는 다음 흐름을 외우면 좋다.

```text
ERP 수주/생산계획
-> ERP 작업지시
-> MES 작업지시 수신
-> 현장 작업 시작
-> 자재 투입
-> 공정 진행
-> 검사
-> 생산실적 등록
-> 완제품 입고
-> ERP 재고/원가 반영
```

이 흐름에서 데이터가 끊기면 생산, 재고, 원가, 품질이 모두 영향을 받는다.

## 12. 이 문서에서 꼭 가져갈 것

MES는 제조 현장의 실행 데이터를 잡는 시스템이다. ERP가 "무엇을 계획하고 얼마로 관리할 것인가"에 가깝다면, MES는 "현장에서 실제로 어떻게 만들었는가"에 가깝다.

입사 초기에는 작업지시, 생산실적, 공정, 설비, LOT, 바코드, 검사, 불량이라는 단어를 먼저 익히면 MES 업무를 따라가기 쉬워진다.
