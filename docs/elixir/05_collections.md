# 05. 컬렉션: 데이터를 담는 네 가지 그릇

Elixir에서 데이터를 묶어서 관리하는 방법은 크게 네 가지가 있습니다. 상황에 맞는 적절한 그릇을 선택하는 것이 중요합니다.

---

## 1. 리스트 (Lists)

리스트는 **대괄호(`[ ]`)**를 사용합니다. 연결 리스트(Linked List) 구조이므로, 맨 앞에 항목을 추가하는 것이 매우 빠릅니다.

```elixir
iex> [1, 2, "three", :four]
[1, 2, "three", :four]

# 리스트 합치기 (++)와 빼기 (--)
iex> [1, 2] ++ [3, 4]
[1, 2, 3, 4]
iex> [1, 2, 3] -- [2]
[1, 3]
```

### 머리(Head)와 꼬리(Tail)
리스트의 첫 번째 요소를 **Head**, 나머지를 **Tail**이라고 부릅니다. 이는 재귀 처리에 매우 중요한 개념입니다.
```elixir
iex> [head | tail] = [1, 2, 3]
iex> head
1
iex> tail
[2, 3]
```

---

## 2. 튜플 (Tuples)

튜플은 **중괄호(`{ }`)**를 사용합니다. 메모리에 연속적으로 저장되므로 크기를 알거나 요소에 접근하는 것이 빠르지만, 요소를 수정/추가할 때마다 전체 튜플을 복사해야 합니다.

```elixir
iex> {:ok, "success"}
{:ok, "success"}

# 주로 함수의 결과값으로 사용됩니다.
iex> File.read("hello.txt")
{:error, :enoent}
```

---

## 3. 맵 (Maps)

키-값(Key-Value) 쌍을 저장할 때 사용하며, **`%{ }`** 문법을 씁니다. 가장 자주 사용되는 컬렉션입니다.

```elixir
iex> user = %{:name => "호세", :age => 30}
iex> user[:name]
"호세"

# 키가 아톰일 때의 편리한 문법
iex> user = %{name: "호세", age: 30}
iex> user.name
"호세"
```

### 맵 업데이트
Elixir의 데이터는 불변이므로, 업데이트 시 새로운 맵을 생성합니다.
```elixir
iex> %{user | age: 31}
%{name: "호세", age: 31}
```

---

## 4. 키워드 리스트 (Keyword Lists)

리스트 안에 튜플이 들어있는 형태(`[{ :key, value }]`)입니다. 함수의 옵션을 전달할 때 주로 사용됩니다.
- 특징: 키의 순서가 유지됨, 동일한 키를 여러 번 가질 수 있음.

```elixir
iex> [primary: "red", secondary: "blue"]
[primary: "red", secondary: "blue"]
```

---

## 노련한 작가의 요약표 👴

| 종류 | 문법 | 특징 | 주 용도 |
| :--- | :--- | :--- | :--- |
| **List** | `[ ]` | 연결 리스트, 앞쪽 추가 빠름 | 동적 목록 처리, 재귀 |
| **Tuple** | `{ }` | 인덱스 접근 빠름 | 함수의 결과 반환 (`{:ok, val}`) |
| **Map** | `%{ }` | 키-값 쌍, 가장 유연함 | 구조화된 데이터, 상태 관리 |
| **Keyword** | `[k: v]` | 리스트 형태의 키-값 | 함수의 옵션 인자 전달 |

---

## 노련한 선배의 한마디 👴

> "리스트의 맨 뒤에 데이터를 추가하는 작업(`list ++ [new]`)은 리스트가 길어질수록 매우 느려집니다. 대신 맨 앞에 추가하고(`[new | list]`) 나중에 한 번에 뒤집는(`Enum.reverse`) 습관을 들이세요. 이것이 Elixir 성능 최적화의 첫걸음입니다."
