# 03. 기초 타입: Elixir의 말씨 익히기

언어를 배울 때 가장 먼저 익혀야 할 것은 그 언어가 사용하는 단어의 종류입니다. Elixir는 함수형 언어답게 명확하고 실용적인 데이터 타입들을 가지고 있습니다. IEx에서 직접 따라 하며 익혀보세요!

---

## 1. 수치형 (Numbers)

### 정수 (Integers)
제한이 없는 크기를 지원합니다. 아주 큰 수도 문제없습니다.
```elixir
iex> 123
123
iex> 1_000_000  # 가독성을 위해 언더바(_)를 쓸 수 있습니다.
1000000
```
- **진수 표현**: `0b`(2진수), `0o`(8진수), `0x`(16진수)를 사용합니다.

### 부동 소수점 (Floats)
소수점이 포함된 숫자입니다.
```elixir
iex> 3.14
3.14
iex> 1.0e-2
0.01
```

---

## 2. 아톰 (Atoms)

아톰은 **이름 자체가 값**인 상수입니다. 다른 언어의 Symbol이나 Enum과 비슷합니다. `:`으로 시작합니다.

```elixir
iex> :hello
:hello
iex> :ok == :ok
true
iex> :error != :ok
true
```
> [!NOTE]
> 아톰은 메모리에 한 번 등록되면 가비지 컬렉션(GC)되지 않습니다. 따라서 사용자 입력으로부터 동적으로 아톰을 생성하는 것은 피해야 합니다. (메모리 고갈 위험)

---

## 3. 불리언 (Booleans)

Elixir의 불리언은 사실 **아톰**입니다!
- `true`는 사실 `:true`와 같습니다.
- `false`는 사실 `:false`와 같습니다.
- `nil` 역시 사실 `:nil`과 같으며, '값이 없음'을 나타냅니다.

```elixir
iex> is_atom(true)
true
```

---

## 4. 날짜와 시간 (Date and Time)

30년 베테랑으로서 강조하자면, 실무에서 날짜 처리는 지옥이 될 수 있습니다. Elixir는 이를 위해 표준 라이브러리에서 강력한 타입을 제공합니다.

### Date (날짜만)
```elixir
iex> ~D[2026-05-15]
~D[2026-05-15]
```

### Time (시간만)
```elixir
iex> ~T[11:30:00]
~T[11:30:00.000]
```

### DateTime (날짜 + 시간 + 타임존)
```elixir
iex> DateTime.utc_now()
#DateTime<2026-05-15 02:30:45.123Z>
```

---

## 5. 비교 연산의 순서

Elixir는 독특하게도 **서로 다른 타입끼리도 비교**할 수 있습니다. 그 순서는 다음과 같습니다:
`number < atom < reference < function < port < pid < tuple < map < list < bitstring`

이 순서를 알면 데이터를 정렬(Sorting)할 때 매우 유용합니다.
