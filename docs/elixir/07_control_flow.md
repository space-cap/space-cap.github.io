# 07. 제어 구문: 논리의 흐름 다스리기

Elixir에는 다른 언어처럼 `if`, `else`가 존재하지만, 함수형 패러다임에 맞게 설계된 `case`와 `cond`가 훨씬 더 강력한 힘을 발휘합니다.

---

## 1. if와 unless

조건이 참인지 거짓인지에 따라 실행합니다.

```elixir
# if 문
if true do
  "참입니다"
else
  "거짓입니다"
end

# unless 문 (if의 반대, 거짓일 때 실행)
unless false do
  "거짓이 아니군요"
end
```

> [!IMPORTANT]
> Elixir에서 `if`는 문장이 아니라 **표현식(Expression)**입니다. 즉, 항상 값을 반환합니다.

---

## 2. case: 패턴 매칭의 정수

값의 형태(패턴)에 따라 실행 흐름을 나눕니다. Elixir에서 가장 많이 쓰이는 구문입니다.

```elixir
case {1, 2, 3} do
  {4, 5, 6} ->
    "매치되지 않습니다"
  {1, x, 3} ->
    "x는 #{x}로 매치되었습니다"
  _ ->
    "그 외의 모든 경우"
end
```

---

## 3. cond: 여러 조건을 검사할 때

여러 개의 `if-else if`를 써야 할 상황이라면 `cond`가 정답입니다.

```elixir
cond do
  2 + 2 == 5 ->
    "거짓입니다"
  2 * 2 == 3 ->
    "이것도 거짓입니다"
  1 + 1 == 2 ->
    "이것이 참이므로 실행됩니다"
  true ->
    "아무것도 매치되지 않을 때 실행되는 기본값 (else 역할)"
end
```

---

## 4. with: 연쇄적인 매칭 처리

여러 단계의 작업을 수행하다가, 중간에 하나라도 실패하면 멈춰야 할 때 사용합니다. 코드가 아주 깔끔해집니다.

```elixir
user_input = %{"name" => "호세", "age" => "30"}

with {:ok, name} <- Map.fetch(user_input, "name"),
     {:ok, age} <- Map.fetch(user_input, "age") do
  "이름은 #{name}, 나이는 #{age}세입니다."
else
  :error -> "필요한 정보가 부족합니다."
end
```

---

## 노련한 작가의 비교 가이드 👴

| 구문 | 언제 사용하는가? | 비고 |
| :--- | :--- | :--- |
| **if / unless** | 아주 간단한 참/거짓 판별 | 사용 빈도가 낮음 |
| **case** | 값의 **구조나 패턴**을 검사할 때 | **가장 권장됨** |
| **cond** | 서로 다른 **여러 조건식**을 검사할 때 | `if-else if` 대용 |
| **with** | 여러 단계의 **성공/실패 흐름**을 제어할 때 | 파이프라인의 보완재 |

---

## 노련한 선배의 한마디 👴

> "초보자들은 습관적으로 `if`를 먼저 찾습니다. 하지만 Elixir 마스터는 항상 **`case`**를 먼저 생각하죠. 패턴 매칭을 활용한 `case` 문은 코드의 가독성을 높여줄 뿐만 아니라, 우리가 예상치 못한 데이터가 들어왔을 때 에러를 발생시켜 시스템의 결함을 조기에 발견하게 도와줍니다."
