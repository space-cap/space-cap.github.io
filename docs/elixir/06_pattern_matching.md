# 06. 패턴 매칭: Elixir의 마법 지팡이

Elixir를 배우는 많은 이들이 "아하!" 하고 무릎을 치는 순간이 바로 이 장입니다. 패턴 매칭은 단순히 값을 할당하는 것을 넘어, 데이터의 구조를 파악하고 추출하는 강력한 도구입니다.

---

## 1. 매치 연산자 (`=`)

Elixir에서 `=`는 할당 연산자가 아니라 **매치(Match) 연산자**입니다. "왼쪽과 오른쪽이 일치하는가?"를 묻고, 일치한다면 값을 바인딩합니다.

```elixir
iex> x = 1
1
iex> 1 = x
1
iex> 2 = x
** (MatchError) no match of right hand side value: 1
```

---

## 2. 복합 구조 매칭

리스트, 튜플, 맵의 내부 구조를 그대로 본떠서 값을 추출할 수 있습니다.

### 튜플 매칭
```elixir
iex> {:ok, message} = {:ok, "안녕하세요"}
iex> message
"안녕하세요"
```

### 리스트 매칭
```elixir
iex> [a, b, c] = [1, 2, 3]
iex> [head | tail] = [1, 2, 3, 4, 5]
iex> head
1
iex> tail
[2, 3, 4, 5]
```

### 맵 매칭
맵의 모든 키를 매칭할 필요는 없습니다. 필요한 것만 골라낼 수 있습니다.
```elixir
iex> %{name: name} = %{name: "호세", age: 30}
iex> name
"호세"
```

---

## 3. 핀 연산자 (`^`)

이미 값이 정해진 변수를 다시 바인딩하지 않고, **기존의 값과 일치하는지 확인만** 하고 싶을 때 사용합니다.

```elixir
iex> x = 1
1
iex> ^x = 2
** (MatchError) no match of right hand side value: 2
```

---

## 4. 언더스코어 (`_`): 무시하고 싶은 값

패턴 매칭을 할 때 관심 없는 부분은 `_`로 처리합니다.

```elixir
iex> [head | _] = [1, 2, 3, 4]
iex> head
1
# 꼬리 부분은 무시되었습니다.
```

---

## 5. 패턴 매칭의 실전 활용

함수의 결과를 처리할 때 가장 빛을 발합니다.

```elixir
case File.read("config.json") do
  {:ok, contents} -> IO.puts("파일 내용: #{contents}")
  {:error, reason} -> IO.puts("파일 읽기 실패: #{reason}")
end
```
데이터의 상태에 따라 코드가 어떻게 흐를지 직관적으로 보여줍니다.

---

## 노련한 작가의 조언 👴

> "패턴 매칭은 코드에서 **조건문(if/else)을 획기적으로 줄여줍니다.** 데이터를 검사하고 추출하는 로직이 하나로 합쳐지기 때문이죠. 처음에는 어색할 수 있지만, 패턴 매칭에 익숙해지면 다른 언어에서도 `=`를 볼 때마다 패턴 매칭이 그리워질 것입니다."
