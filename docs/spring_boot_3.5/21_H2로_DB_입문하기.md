# H2로 DB 입문하기

## 이번 장에서 배울 것

이 장에서는 H2 데이터베이스로 Spring Boot 애플리케이션에 DB를 연결하는 첫 단계를 배운다.

H2는 가볍고 빠른 Java 기반 데이터베이스다. 별도 설치 없이 프로젝트 의존성만으로 사용할 수 있어서 학습과 테스트에 좋다. 다만 운영용 DB로 생각하면 안 된다. 운영에서는 PostgreSQL, MySQL 같은 별도 DB를 사용한다.

## H2를 처음 DB로 쓰는 이유

초보자가 DB까지 배우려면 준비할 것이 많다.

- DB 서버 설치
- 사용자 생성
- 데이터베이스 생성
- 포트 설정
- 드라이버 설정
- 접속 도구 설정

H2를 쓰면 이 부담을 줄일 수 있다. Spring Boot는 H2 같은 임베디드 DB가 클래스패스에 있으면 기본 DataSource를 자동 설정할 수 있다.

## 의존성 추가

Gradle 기준으로 다음 의존성을 추가한다.

```groovy
dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-jdbc'
    runtimeOnly 'com.h2database:h2'
}
```

JPA를 바로 사용할 프로젝트라면 다음처럼 시작할 수도 있다.

```groovy
dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-data-jpa'
    runtimeOnly 'com.h2database:h2'
}
```

이 장에서는 DB 연결 자체를 이해하기 위해 JDBC 기준으로 설명한다.

## H2 설정

`src/main/resources/application.yml`:

```yaml
spring:
  datasource:
    url: jdbc:h2:mem:todo
    username: sa
    password:
    driver-class-name: org.h2.Driver

  h2:
    console:
      enabled: true
      path: /h2-console
```

각 설정의 의미는 다음과 같다.

- `jdbc:h2:mem:todo`: 메모리 안에 `todo`라는 DB를 만든다.
- `username: sa`: H2 기본 사용자 이름이다.
- `password`: 비밀번호 없음.
- `h2.console.enabled`: 브라우저에서 H2 콘솔을 사용할 수 있게 한다.
- `h2.console.path`: 콘솔 접속 경로다.

## 메모리 DB와 파일 DB

H2는 메모리 DB와 파일 DB로 사용할 수 있다.

메모리 DB:

```yaml
spring:
  datasource:
    url: jdbc:h2:mem:todo
```

애플리케이션을 종료하면 데이터가 사라진다. 테스트와 학습에 좋다.

파일 DB:

```yaml
spring:
  datasource:
    url: jdbc:h2:file:./data/todo
```

파일에 데이터가 남는다. 학습 중 데이터를 유지하고 싶을 때 쓸 수 있지만, 처음에는 메모리 DB가 깔끔하다.

## schema.sql로 테이블 만들기

`src/main/resources/schema.sql`:

```sql
create table todos (
    id bigint generated by default as identity primary key,
    title varchar(100) not null,
    completed boolean not null,
    created_at timestamp not null
);
```

Spring Boot는 임베디드 DB를 사용할 때 `schema.sql`을 찾아 테이블을 만들 수 있다.

## data.sql로 초기 데이터 넣기

`src/main/resources/data.sql`:

```sql
insert into todos (title, completed, created_at)
values ('Spring Boot 공부', false, current_timestamp);

insert into todos (title, completed, created_at)
values ('H2 연결 확인', true, current_timestamp);
```

애플리케이션 시작 시 초기 데이터가 들어간다.

## H2 콘솔 접속

애플리케이션을 실행한 뒤 브라우저에서 접속한다.

```text
http://localhost:8080/h2-console
```

입력값:

```text
JDBC URL: jdbc:h2:mem:todo
User Name: sa
Password:
```

접속 후 다음 SQL을 실행한다.

```sql
select * from todos;
```

초기 데이터가 보이면 성공이다.

## 간단한 조회 Controller

아직 JDBC를 자세히 배우기 전이지만, DB에서 값을 읽는 맛을 보자.

```java
package com.example.todo.todo;

import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.List;

@RestController
@RequestMapping("/todos")
public class TodoController {

    private final JdbcTemplate jdbcTemplate;

    public TodoController(JdbcTemplate jdbcTemplate) {
        this.jdbcTemplate = jdbcTemplate;
    }

    @GetMapping
    public List<TodoResponse> findAll() {
        return jdbcTemplate.query(
                "select id, title, completed from todos order by id",
                (rs, rowNum) -> new TodoResponse(
                        rs.getLong("id"),
                        rs.getString("title"),
                        rs.getBoolean("completed")
                )
        );
    }
}
```

DTO:

```java
package com.example.todo.todo;

public record TodoResponse(
        Long id,
        String title,
        boolean completed
) {
}
```

요청:

```bash
curl http://localhost:8080/todos
```

## 자주 하는 실수

### H2 콘솔 JDBC URL을 다르게 입력한다

애플리케이션 설정의 URL과 H2 콘솔의 URL이 같아야 한다. `jdbc:h2:mem:todo`로 설정했으면 콘솔에도 같은 값을 넣는다.

### 메모리 DB 데이터가 사라져서 당황한다

`jdbc:h2:mem:`은 애플리케이션 종료 시 데이터가 사라진다. 이것은 정상이다.

### 운영에서도 H2를 쓰려고 한다

H2는 학습과 테스트에 좋다. 운영에서는 PostgreSQL, MySQL 같은 별도 DB를 사용한다.
