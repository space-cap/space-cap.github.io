# 이메일 전송

## 이번 장에서 배울 것

이번 장에서는 Spring Boot에서 이메일을 보내는 기본 방법을 배운다.

이메일 전송은 회원 가입, 비밀번호 재설정, 주문 확인, 알림 발송처럼 많은 서비스에서 필요하다. Spring Boot는 `JavaMailSender`를 자동 설정해 이메일 전송을 쉽게 시작할 수 있게 해준다.

## 이메일 전송의 구조

애플리케이션이 직접 상대방의 메일함에 메일을 꽂아 넣는 것은 아니다. 보통 다음 흐름으로 동작한다.

```text
Spring Boot 애플리케이션
    -> SMTP 서버
        -> 수신자 메일 서버
            -> 수신자 메일함
```

SMTP 서버는 Gmail, Naver Works, AWS SES, Mailgun, SendGrid 같은 서비스를 사용할 수 있다.

## 의존성 추가

Gradle:

```groovy
dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-mail'
}
```

`spring-boot-starter-mail`이 있으면 Spring Boot는 설정 값을 보고 `JavaMailSender`를 자동으로 만든다.

## 기본 설정

`application.yml`:

```yaml
spring:
  mail:
    host: smtp.example.com
    port: 587
    username: your-account@example.com
    password: your-password
    properties:
      mail:
        smtp:
          auth: true
          starttls:
            enable: true
          connectiontimeout: 5000
          timeout: 5000
          writetimeout: 5000
```

운영에서는 비밀번호를 파일에 직접 쓰지 말고 환경 변수나 secret 관리 도구를 사용해야 한다.

```yaml
spring:
  mail:
    username: ${MAIL_USERNAME}
    password: ${MAIL_PASSWORD}
```

## 단순 텍스트 메일 보내기

```java
package com.example.todo.mail;

import org.springframework.mail.SimpleMailMessage;
import org.springframework.mail.javamail.JavaMailSender;
import org.springframework.stereotype.Service;

@Service
public class MailService {

    private final JavaMailSender mailSender;

    public MailService(JavaMailSender mailSender) {
        this.mailSender = mailSender;
    }

    public void sendWelcomeMail(String to) {
        SimpleMailMessage message = new SimpleMailMessage();
        message.setTo(to);
        message.setSubject("Todo 서비스에 오신 것을 환영합니다");
        message.setText("가입이 완료되었습니다. 오늘 할 일을 하나 등록해 보세요.");

        mailSender.send(message);
    }
}
```

단순 텍스트 메일은 가장 이해하기 쉽다. 하지만 실제 서비스에서는 HTML 메일을 더 많이 사용한다.

## HTML 메일 보내기

HTML 메일은 `MimeMessageHelper`를 사용한다.

```java
package com.example.todo.mail;

import jakarta.mail.MessagingException;
import jakarta.mail.internet.MimeMessage;
import org.springframework.mail.javamail.JavaMailSender;
import org.springframework.mail.javamail.MimeMessageHelper;
import org.springframework.stereotype.Service;

@Service
public class HtmlMailService {

    private final JavaMailSender mailSender;

    public HtmlMailService(JavaMailSender mailSender) {
        this.mailSender = mailSender;
    }

    public void sendPasswordResetMail(String to, String resetUrl) {
        try {
            MimeMessage message = mailSender.createMimeMessage();
            MimeMessageHelper helper = new MimeMessageHelper(message, "UTF-8");

            helper.setTo(to);
            helper.setSubject("비밀번호 재설정 안내");
            helper.setText("""
                    <h1>비밀번호 재설정</h1>
                    <p>아래 링크를 눌러 비밀번호를 재설정하세요.</p>
                    <a href="%s">비밀번호 재설정</a>
                    """.formatted(resetUrl), true);

            mailSender.send(message);
        } catch (MessagingException e) {
            throw new IllegalStateException("메일 생성에 실패했습니다.", e);
        }
    }
}
```

`setText(html, true)`의 두 번째 인자 `true`는 HTML로 보내겠다는 뜻이다.

## 템플릿 엔진과 함께 쓰기

문자열로 HTML을 직접 만들면 유지보수가 어렵다. 실제 서비스에서는 Thymeleaf 같은 템플릿 엔진을 함께 사용할 수 있다.

템플릿 예:

```html
<!doctype html>
<html>
<body>
<h1>안녕하세요, [[${name}]]님</h1>
<p>가입을 환영합니다.</p>
</body>
</html>
```

메일 서비스에서는 템플릿에 데이터를 넣어 HTML 문자열을 만든 뒤 전송한다.

초보 단계에서는 먼저 `SimpleMailMessage`와 `MimeMessageHelper`를 이해하고, 그 다음 템플릿을 붙이면 된다.

## 이메일 전송을 비동기로 처리하기

메일 발송은 외부 SMTP 서버와 통신하므로 시간이 걸릴 수 있다. 사용자 가입 API가 메일 발송이 끝날 때까지 기다리면 응답이 느려진다.

이럴 때는 지난 장에서 배운 `@Async`를 사용할 수 있다.

```java
import org.springframework.scheduling.annotation.Async;
import org.springframework.stereotype.Service;

@Service
public class AsyncMailService {

    private final MailService mailService;

    public AsyncMailService(MailService mailService) {
        this.mailService = mailService;
    }

    @Async
    public void sendWelcomeMailAsync(String to) {
        mailService.sendWelcomeMail(to);
    }
}
```

주의할 점은 비동기 메일 발송이 실패해도 원래 요청은 이미 성공했을 수 있다는 것이다. 중요한 메일은 재시도와 실패 기록이 필요하다.

## 타임아웃 설정

공식 문서에서는 일부 메일 기본 타임아웃이 무한대일 수 있으므로 명시적으로 설정하는 것을 권한다. SMTP 서버가 응답하지 않으면 스레드가 오래 묶일 수 있기 때문이다.

```yaml
spring:
  mail:
    properties:
      mail:
        smtp:
          connectiontimeout: 5000
          timeout: 5000
          writetimeout: 5000
```

메일 설정에서 타임아웃은 운영 안정성에 매우 중요하다.

## 개발 환경에서 메일 테스트하기

개발 중에는 실제 사용자에게 메일을 보내면 안 된다.

대신 다음 도구를 사용할 수 있다.

- MailHog
- Mailpit
- GreenMail
- 로컬 SMTP 테스트 서버
- 이메일 API 서비스의 sandbox 모드

Docker Compose로 Mailpit을 띄우는 예:

```yaml
services:
  mailpit:
    image: axllent/mailpit
    ports:
      - "1025:1025"
      - "8025:8025"
```

Spring 설정:

```yaml
spring:
  mail:
    host: localhost
    port: 1025
```

브라우저에서 `http://localhost:8025`로 들어가면 발송된 메일을 확인할 수 있다.

## 운영에서 생각할 것

메일은 외부 시스템이다. 항상 실패할 수 있다고 생각해야 한다.

운영 체크리스트:

- SMTP 계정과 비밀번호를 안전하게 관리한다.
- 타임아웃을 설정한다.
- 실패 로그를 남긴다.
- 중요한 메일은 재시도한다.
- 중복 발송을 방지한다.
- 발송량 제한을 확인한다.
- 스팸 처리되지 않도록 SPF, DKIM, DMARC를 설정한다.

## 자주 하는 실수

### 비밀번호를 `application.yml`에 그대로 커밋한다

메일 계정은 민감 정보다. 환경 변수나 secret 저장소를 사용해야 한다.

### 메일 발송을 요청 스레드에서 오래 기다린다

메일 서버가 느리면 API 응답도 느려진다. 비동기 처리와 타임아웃을 고려하자.

### 개발 중 실제 사용자에게 메일을 보낸다

로컬 SMTP 테스트 도구를 사용하자.

### 메일 발송 성공을 비즈니스 성공과 같은 의미로 본다

회원 가입은 성공했지만 메일은 실패할 수 있다. 두 상태를 분리해서 생각해야 한다.
