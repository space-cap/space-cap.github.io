# Spring Boot 3.5.x 학습 문서 작성 계획서

> 작성 기준일: 2026-05-18  
> 기준 버전: Spring Boot 3.5.x  
> 현재 공식 3.5 문서 기준 버전: Spring Boot 3.5.14

## 1. 문서 작성 목표

이 문서 모음은 Spring Boot 3.5.x를 처음 배우는 사람도 차근차근 따라올 수 있도록 만드는 입문서형 학습 자료를 목표로 한다.

한 문서에 모든 내용을 몰아넣지 않고, 책의 장처럼 작은 문서로 나누어 작성한다. 각 문서는 다음 흐름을 따른다.

1. 왜 이 내용을 배우는가
2. 꼭 알아야 할 개념
3. 직접 따라 하는 예제
4. 자주 하는 실수
5. 다음 문서로 넘어가기 전에 확인할 것

## 2. 대상 독자

- Java 기초 문법은 조금 알고 있지만 Spring은 처음인 사람
- Spring은 들어봤지만 Spring Boot의 자동 설정, 스타터, 실행 방식이 막연한 사람
- REST API, DB 연동, 인증, 테스트, 배포까지 한 번에 큰 그림을 잡고 싶은 사람
- Spring Boot 2.x 또는 3.4 이하를 사용하다가 Spring Boot 3.5.x 기준으로 다시 정리하고 싶은 사람

## 3. 문서 작성 원칙

- 초보자가 이해할 수 있는 말로 먼저 설명하고, 공식 용어는 그 다음에 소개한다.
- 예제는 작게 시작해서 하나의 게시판 또는 할 일 API 프로젝트로 점진적으로 확장한다.
- Maven과 Gradle을 모두 언급하되, 기본 예제는 Gradle 또는 Maven 중 하나를 선택해 일관되게 진행한다.
- Spring Boot 3.5.x 기준의 Java, Spring Framework, Servlet, Jakarta EE 변화를 분명히 구분한다.
- 설정 파일, 애너테이션, 자동 설정은 "외우기"보다 "왜 그렇게 동작하는지"를 설명한다.
- 실무에서 자주 만나는 오류와 해결 방법을 각 장 끝에 넣는다.
- 모든 코드 예제는 가능한 한 복사해서 실행할 수 있게 작성한다.

## 4. 기준 환경

Spring Boot 3.5 공식 문서 기준으로 다음 환경을 기본 전제로 삼는다.

- Java: 17 이상
- Spring Framework: 6.2 이상
- Maven: 3.6.3 이상
- Gradle: 7.6.4 이상 또는 8.4 이상
- 내장 Servlet 컨테이너: Tomcat 10.1, Jetty 12.0, Undertow 2.3

문서 예제의 권장 환경은 다음처럼 정한다.

- Java 21 LTS
- Spring Boot 3.5.x
- Gradle 8.x 또는 Maven 3.9.x
- IDE: IntelliJ IDEA Community 또는 Ultimate, VS Code
- OS: Windows, macOS, Linux 공통 설명
- DB: H2, PostgreSQL
- API 테스트 도구: curl, HTTPie, Postman 또는 IntelliJ HTTP Client

## 6. 예제 프로젝트 방향

문서 전체에서 하나의 예제 프로젝트를 점진적으로 키운다.

예제 후보는 다음과 같다.

1. 할 일 관리 API
   - 초보자가 도메인을 이해하기 쉽다.
   - CRUD, 검증, 예외 처리, DB, 인증, 테스트를 모두 담기 좋다.

2. 간단한 게시판 API
   - 사용자, 게시글, 댓글, 권한 등 실무에 가까운 구조를 만들기 좋다.
   - JPA 연관관계와 트랜잭션 설명에 유리하다.

초기 문서에서는 할 일 관리 API로 시작하고, 후반부에서 게시판 또는 팀 작업 관리 서비스로 확장하는 방식을 권장한다.
