# 자주 쓰는 설정 프로퍼티

## 이번 장에서 배울 것

이번 장에서는 Spring Boot 프로젝트에서 자주 사용하는 설정 프로퍼티를 목적별로 정리한다.

Spring Boot 설정은 `application.yml`, `application.properties`, 환경 변수, 명령행 인자 등 여러 곳에서 올 수 있다. 초보자는 먼저 "어떤 기능을 설정할 때 어떤 이름을 자주 쓰는지"를 익히면 된다.

## 서버 설정

### 포트

```yaml
server:
  port: 8080
```

포트 충돌이 나면 임시로 바꿔 실행할 수 있다.

```bash
java -jar app.jar --server.port=8081
```

### context path

```yaml
server:
  servlet:
    context-path: /api
```

모든 경로 앞에 `/api`가 붙는다.

```text
/todos -> /api/todos
```

무심코 설정하면 API 경로가 전부 바뀌므로 주의한다.

### graceful shutdown

```yaml
server:
  shutdown: graceful

spring:
  lifecycle:
    timeout-per-shutdown-phase: 30s
```

배포 중 요청을 안전하게 마무리하고 종료할 때 사용한다.

## 애플리케이션 기본 정보

```yaml
spring:
  application:
    name: todo-api
```

로그, 모니터링, tracing에서 서비스 이름으로 사용될 수 있다.

## Profile

```yaml
spring:
  profiles:
    active: local
```

운영에서는 파일에 고정하기보다 환경 변수나 실행 인자로 지정하는 편이 좋다.

```bash
java -jar app.jar --spring.profiles.active=prod
```

profile별 파일:

```text
application.yml
application-local.yml
application-prod.yml
```

## 데이터베이스

### DataSource

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/todo
    username: todo
    password: secret
    driver-class-name: org.postgresql.Driver
```

운영에서는 `username`, `password`를 환경 변수로 분리한다.

```yaml
spring:
  datasource:
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
```

### HikariCP

Spring Boot의 기본 JDBC connection pool은 HikariCP다.

```yaml
spring:
  datasource:
    hikari:
      maximum-pool-size: 10
      minimum-idle: 5
      connection-timeout: 30000
```

풀 크기는 DB와 애플리케이션 서버 수를 함께 고려해야 한다.

## JPA

```yaml
spring:
  jpa:
    open-in-view: false
    hibernate:
      ddl-auto: validate
    properties:
      hibernate:
        format_sql: true
```

학습용:

```yaml
spring:
  jpa:
    hibernate:
      ddl-auto: create
```

운영에서는 `create`, `create-drop`, `update`를 조심해야 한다. 운영 DB 스키마는 Flyway나 Liquibase로 관리하는 편이 안전하다.

## SQL 초기화

```yaml
spring:
  sql:
    init:
      mode: always
      schema-locations: classpath:schema.sql
      data-locations: classpath:data.sql
```

테스트나 로컬 환경에서 유용하다. 운영에서는 의도치 않은 초기화가 일어나지 않도록 주의한다.

## Flyway

```yaml
spring:
  flyway:
    enabled: true
    locations: classpath:db/migration
    baseline-on-migrate: false
```

마이그레이션 파일 예:

```text
db/migration/V1__create_todo_table.sql
```

## 로깅

```yaml
logging:
  level:
    root: info
    com.example.todo: debug
    org.hibernate.SQL: debug
```

SQL 바인딩 값까지 보고 싶다면 Hibernate 버전에 맞는 logger를 확인해야 한다.

파일 로그:

```yaml
logging:
  file:
    name: logs/todo-api.log
```

컨테이너 환경에서는 파일보다 표준 출력 로그를 수집하는 방식이 일반적이다.

## Actuator

의존성:

```groovy
implementation 'org.springframework.boot:spring-boot-starter-actuator'
```

기본 설정:

```yaml
management:
  endpoints:
    web:
      exposure:
        include: health,info,metrics,prometheus
  endpoint:
    health:
      probes:
        enabled: true
      show-details: when_authorized
```

운영에서는 endpoint 노출을 최소화하자.

## 보안

간단한 기본 사용자:

```yaml
spring:
  security:
    user:
      name: admin
      password: secret
```

학습용으로는 편하지만 운영 인증 방식으로는 부족하다.

OAuth2 Resource Server JWT 예:

```yaml
spring:
  security:
    oauth2:
      resourceserver:
        jwt:
          issuer-uri: https://issuer.example.com
```

## 캐시

Caffeine:

```yaml
spring:
  cache:
    type: caffeine
    cache-names:
      - todos
      - categories
    caffeine:
      spec: maximumSize=1000,expireAfterWrite=10m
```

Redis:

```yaml
spring:
  cache:
    type: redis
  data:
    redis:
      host: localhost
      port: 6379
```

## 메일

```yaml
spring:
  mail:
    host: smtp.example.com
    port: 587
    username: ${MAIL_USERNAME}
    password: ${MAIL_PASSWORD}
    properties:
      mail:
        smtp:
          auth: true
          starttls:
            enable: true
          connectiontimeout: 5000
          timeout: 5000
          writetimeout: 5000
```

메일은 타임아웃을 꼭 설정하자.

## REST Client

Spring Boot 3.5는 HTTP client 관련 설정이 강화되었다.

Reactive WebClient connector timeout 예:

```yaml
spring:
  http:
    reactiveclient:
      connect-timeout: 2s
      read-timeout: 1s
      redirects: dont-follow
```

외부 API를 호출하는 서비스는 timeout 설정을 반드시 점검한다.

## Jackson JSON

```yaml
spring:
  jackson:
    property-naming-strategy: SNAKE_CASE
    default-property-inclusion: non_null
```

API 응답 필드 이름이 바뀌면 클라이언트에 영향이 있으므로 초기에 결정하는 편이 좋다.

## 설정을 찾는 방법

공식 문서의 Common Application Properties를 검색한다.

예:

```text
server.port
spring.datasource.url
management.endpoints.web.exposure.include
```

IDE 자동완성도 적극 활용하자. Spring Boot jars에는 configuration metadata가 포함되어 있어 IDE가 설정 이름과 설명을 보여줄 수 있다.

## 자주 하는 실수

### 운영 비밀번호를 파일에 커밋한다

민감 정보는 환경 변수, secret manager, CI/CD secret으로 분리하자.

### `ddl-auto: update`를 운영에서 쓴다

의도치 않은 스키마 변경이 생길 수 있다.

### Actuator endpoint를 과하게 노출한다

필요한 endpoint만 노출하고 인증을 적용하자.

### 설정 이름을 블로그에서 복사하고 공식 문서를 확인하지 않는다

버전에 따라 설정 이름이 바뀔 수 있다. Spring Boot 3.5 공식 문서 기준으로 확인하자.
