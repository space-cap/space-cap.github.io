## 🧠 5. Gemini 5대 핵심 기능 래퍼 (`gemini_advanced.py`)

- **Context Caching (`GeminiCacheManager`)**: 대량의 재무 텍스트를 캐싱하여 반복 질문 시 비용 90% 절감 (TTL 30분).
- **Structured Output (`generate_structured`)**: JSON 스키마를 강제 주입하여 안정적이고 구조화된 핵심 지표 결과물 보장.
- **Code Execution (`generate_with_code_execution`)**: AI가 직접 Python 코드를 작성하고 샌드박스에서 실행해 DCF(현금흐름할인) 적정가치를 도출.
- **Grounding Search (`generate_with_search`)**: Google 검색 기반으로 실시간 최신 뉴스를 불러와 분석 결과 교차 검증.
- **URL Context (`analyze_url`)**: DART 사업보고서 URL을 직접 읽고 분석.

## 🚀 6. AI 6단계 분석 파이프라인 (`run_demo.py`)

### Step 1: DART 재무제표 수집 (필수)

- **동작**: DART API로 10년치 연도별 재무제표 수집 (연결 우선, 없으면 개별). API 호출 제한 방지를 위해 0.3초 딜레이 적용.
- **항목**: 매출액, 영업이익, 당기순이익, 자산/부채/자본, 현금성자산 등 10개 핵심 지표.
- **저장**: `data/` 폴더에 원본 및 억원 단위 변환 JSON 파일 자동 저장.

### Step 2: Context Cache 등록

- 재무 데이터를 텍스트로 변환 후 Gemini Cache에 등록. 실패해도 다음 단계로 진행 (비치명적 오류 처리).

### Step 3: Structured Output (핵심 지표 분석)

- **페르소나**: CFA 애널리스트.
- **산출물**: 연도별 지표(ROE, 영업이익률 등), 10년 요약(CAGR, 최고/최악 연도), 밸류에이션(투자등급 S~D, 강점/리스크).
- **포맷**: 사전 정의된 엄격한 JSON 스키마 반환.

### Step 4: Code Execution (DCF 적정가치 산출)

- **페르소나**: 퀀트 애널리스트.
- **동작**: FCF(잉여현금흐름) 추정 (세율 25%, 감가상각 10%, CAPEX 5% 가정), WACC 9%, 영구성장률 2% 적용. 민감도 분석(그리드) 수행을 위한 파이썬 코드 실행.

### Step 5: Grounding Search (뉴스 교차검증)

- **페르소나**: 한국 주식 시장 전문 애널리스트.
- **동작**: 1~4단계 결과를 바탕으로 최근 뉴스를 검색하여 재무 데이터와 현재 시장 컨센서스 간의 괴리, 놓친 리스크 등을 교차 검증 (최종 판정: 매수/관망/매도).

### Step 6: URL Context (사업보고서 분석 - Bonus)

- **동작**: DART 최신 사업보고서 URL을 읽어 경영 리스크, 향후 가이던스, 특이사항 요약.

## ⚠️ 8. 에러 처리 및 주의사항

- **치명적 에러**: Step 1(DART 수집) 실패 시 분석 전체가 중단됩니다.
- **단계별 독립 실행**: Step 2~6은 개별 실패하더라도 최소한의 더미 데이터나 에러 메시지를 표시하며 다음 단계를 계속 진행합니다.
- **제한 사항**:
    - DART API 분당 호출 제한 방어 로직(0.3초 sleep) 유지 필수.
    - Gemini Code Execution은 비결정적(Non-deterministic)이므로 매번 산출되는 코드가 조금씩 다를 수 있습니다.
    - *본 결과물은 투자 참고용이며 실제 투자 판단의 책임은 사용자에게 있습니다.*

★ Insight ─────────────────────────────────────

**DCF (Discounted Cash Flow, 현금흐름할인법)**는 기업의 적정 가치를 계산하는 대표적인

밸류에이션 방법입니다.

핵심 원리: "이 회사가 앞으로 벌어들일 돈을 오늘 가치로 환산하면 얼마인가?"

이 프로젝트에서 하는 것 (Step 4):

1. 최근 3년 재무데이터 + 10년 트렌드를 기반으로
2. 향후 5년간 **FCF(잉여현금흐름)**를 추정하고
3. WACC 9%(할인율)로 현재 가치로 할인하고
4. 5년 이후는 **영구성장률 2%**로 계속 성장한다고 가정
5. 이걸 다 합치면 → 기업의 적정 가치(억원)

쉽게 비유하면:

- 친구가 치킨집을 팔겠다고 함

- "이 가게가 앞으로 매년 5천만원 벌 거야" → 그러면 지금 얼마에 사는 게 적정한가?

- 미래의 돈은 현재의 돈보다 가치가 낮으니까 할인해서 계산

민감도 분석 테이블: WACC(7~11%)와 영구성장률(1~3%)을 바꿔가며 "낙관/기본/비관"

시나리오별 가치를 보여줍니다.
