# 5장. 객체 지향 프로그래밍 기초

오브젝트 파스칼의 '오브젝트(Object)'는 '객체'라는 뜻입니다. 객체 지향 프로그래밍은 프로그램을 **현실 세계의 사물(객체)**처럼 생각하고 만드는 아주 강력하고 현대적인 방법입니다.

## 1. 클래스와 객체
- **클래스(Class)**: 객체를 만들기 위한 **설계도**나 **붕어빵 틀**입니다.
- **객체(Object)**: 설계도를 보고 실제로 만들어낸 **제품**이나 구워진 **붕어빵**입니다.

자동차를 예로 들어보겠습니다.

```pascal
type
  // TCar 라는 자동차 클래스(설계도)를 만듭니다. (클래스 이름은 관례적으로 T로 시작합니다)
  TCar = class
  public
    // 속성 (자동차의 특징: 변수처럼 값을 가집니다)
    Color: String;
    Speed: Integer;

    // 메서드 (자동차가 할 수 있는 행동: 프로시저나 함수)
    procedure Drive;
  end;

// 설계도 안에 있는 행동(메서드)이 정확히 어떤 작동을 하는지 바깥에 작성해 줍니다.
procedure TCar.Drive;
begin
  Writeln(Color, ' 자동차가 시속 ', Speed, 'km로 달립니다!');
end;
```

## 2. 객체 만들고 사용하기
설계도(클래스)를 만들었으니, 이제 진짜 자동차(객체)를 만들어서 사용해 볼까요?

```pascal
var
  MyCar: TCar; // 내 자동차를 담을 객체 변수
begin
  // 1. 설계도를 바탕으로 자동차를 메모리에 실제로 만듭니다 (생성)
  MyCar := TCar.Create;

  try
    // 2. 자동차의 속성을 꾸며줍니다
    MyCar.Color := '빨간색';
    MyCar.Speed := 100;

    // 3. 자동차를 달리게 합니다 (메서드 호출)
    MyCar.Drive; 
  finally
    // 4. 다 쓴 자동차는 반드시 메모리에서 지워주어야 합니다! (매우 중요)
    MyCar.Free;
  end;
end.
```

## 3. 메모리 관리 (Create와 Free)
오브젝트 파스칼에서 객체를 사용할 때 가장 중요하게 기억해야 할 규칙은 **"내가 만든(Create) 객체는 내가 반드시 파괴(Free)한다"** 입니다.
- `Create`: 객체를 메모리에 만들 때 사용합니다. 이를 **생성자**라고 부릅니다.
- `Free`: 객체를 메모리에서 지울 때 사용합니다.
- `try ... finally`: 프로그램 실행 도중 에러가 나더라도 `finally` 아래의 `Free` 코드가 무조건 실행되게 만들어 줍니다. 이를 통해 메모리가 낭비(메모리 누수)되는 것을 안전하게 막을 수 있습니다.
