# 2장. 변수와 데이터 타입

프로그램을 만들려면 정보를 저장하고 기억할 공간이 필요합니다. 이때 사용하는 것이 바로 **변수(Variable)**입니다. 변수를 물건을 담는 '상자'라고 상상해 보세요!

## 1. 데이터 타입 (상자의 종류)
상자에 물건을 담을 때, 물건의 크기나 종류에 따라 알맞은 상자를 고르듯, 파스칼에서도 저장할 정보에 맞춰 **데이터 타입(종류)**을 정해 주어야 합니다.

자주 쓰는 기본 데이터 타입은 다음과 같습니다:
- `Integer`: **정수** (소수점이 없는 숫자. 예: 1, 0, -100)
- `Double` (또는 `Real`): **실수** (소수점이 있는 숫자. 예: 3.14, -0.5)
- `String`: **문자열** (글자나 문장. 예: '안녕하세요', 'Apple')
- `Boolean`: **참/거짓** (예: True, False)

## 2. 변수 만들기 (상자 준비하기)
변수를 사용하려면 먼저 `var`라는 키워드를 사용하여 "이런 이름과 종류의 상자를 쓸게요"라고 컴퓨터에게 선언해야 합니다.

```pascal
var
  Age: Integer;       // 나이를 저장할 정수형 상자
  Height: Double;     // 키를 저장할 실수형 상자
  Name: String;       // 이름을 저장할 문자열 상자
  IsStudent: Boolean; // 학생인지 여부를 저장할 참/거짓 상자
```

## 3. 변수에 값 넣기
파스칼에서는 변수에 값을 넣을 때 `:=` (콜론과 이퀄) 기호를 사용합니다. 수학에서 쓰는 그냥 `=`이 아님을 주의하세요!

```pascal
begin
  Age := 20;
  Height := 175.5;
  Name := '홍길동';
  IsStudent := True;

  Writeln('내 이름은 ', Name, '입니다.');
  Writeln('나이는 ', Age, '살 입니다.');
end.
```

## 4. 상수 (변하지 않는 값)
게임의 최고 점수 한도나, 원주율(파이)처럼 절대로 변하면 안 되는 고정된 값은 `const`를 사용하여 **상수**로 만듭니다.

```pascal
const
  Pi = 3.141592; // 파이 값은 변하지 않으므로 상수로 선언
```
상수는 한번 값을 정하면 나중에 실수로라도 바꿀 수 없어서 코드를 안전하게 유지해 줍니다.
