# 1장. 오브젝트 파스칼 시작하기

안녕하세요! 오브젝트 파스칼(Object Pascal)의 세계에 오신 것을 환영합니다. 🎉  
이 문서는 프로그래밍을 처음 접하거나, 오브젝트 파스칼을 처음 배우는 초보자분들을 위해 아주 쉽게 쓰여졌습니다.  
설치부터 첫 번째 프로그램 실행까지, 차근차근 함께해 봅시다!

---

## 1. 오브젝트 파스칼이란?

오브젝트 파스칼은 1970년대에 탄생한 교육용 언어 **파스칼(Pascal)** 에  
**객체 지향(Object-Oriented)** 기능을 추가하여 발전시킨 언어입니다.

현재는 주로 아래 두 가지 도구에서 널리 사용됩니다:

| 도구 | 특징 | 가격 |
|---|---|---|
| **Delphi** (델파이) | 임베디드/엔터프라이즈/모바일 앱 개발에 강함. RAD(빠른 앱 개발)의 대명사 | 유료 (커뮤니티 에디션 무료) |
| **Free Pascal + Lazarus** | 완전 무료 오픈소스. 델파이와 거의 같은 문법 | 완전 무료 |

## 2. 오브젝트 파스칼의 특징

- 🧩 **읽기 쉬운 문법**: `begin`, `end`, `if...then...else` 등 영어 문장과 비슷하여 초보자가 이해하기 매우 편합니다.
- 🛡️ **안전한 타입 검사**: 변수에 저장할 데이터의 종류를 엄격하게 검사하여 초보자의 실수를 미리 막아줍니다.
- ⚡ **빠른 실행 속도**: 코드가 컴퓨터가 바로 실행할 수 있는 기계어(네이티브 코드)로 컴파일되어 매우 빠릅니다.
- 🖥️ **윈도우/리눅스/맥/모바일**: 하나의 코드로 다양한 플랫폼용 앱을 만들 수 있습니다.

---

## 3. 어떤 개발 도구(IDE)를 사용할까?

> **IDE(통합 개발 환경)** 란? 코드를 작성하고, 실행하고, 에러를 찾는 모든 기능이 한 곳에 모여있는 프로그램입니다.

### 🥇 초보자 최우선 추천: Lazarus IDE (무료!)

**Lazarus**는 델파이와 거의 동일한 문법을 지원하는 **100% 무료 오픈소스 IDE**입니다.  
내부 컴파일러로 **Free Pascal Compiler (FPC)**를 사용합니다.

- ✅ 완전 무료
- ✅ 윈도우, 맥, 리눅스 모두 지원
- ✅ 비주얼 폼 디자이너 (마우스로 화면을 디자인하는 도구) 포함
- ✅ 델파이 코드와 높은 호환성

### 🥈 전문가용: Delphi Community Edition (무료!)

**엠바카데로(Embarcadero)**사의 **Delphi**는 세계에서 가장 유명한 파스칼 IDE입니다.  
개인/학생/스타트업에게는 **Community Edition(커뮤니티 에디션)**이 무료로 제공됩니다.

- ✅ 개인 및 소규모 팀 무료
- ✅ 안드로이드, iOS, 윈도우, 맥 앱 개발 가능
- ✅ 매우 강력한 디버거 및 프로파일러
- ⚠️ 상업적 사용 시 유료 (수익 제한 있음)

### 🥉 VS Code에서도 가능한가요? (네, 가능합니다! 단, 추천하지는 않음)

**VS Code**는 주로 웹 개발이나 Python 등에 쓰이지만,  
파스칼 전용 확장 플러그인을 설치하면 사용할 수 있습니다.

단, 초보자에게는 아래의 이유로 **Lazarus를 강력히 추천**합니다:
- Lazarus는 처음부터 파스칼을 위해 만들어진 IDE
- 자동완성, 디버깅, 폼 디자이너 등이 훨씬 편리
- VS Code + 파스칼은 설정이 복잡하고 기능이 제한적

> 그래도 VS Code 설정 방법이 궁금하신 분은 [7번 항목](#7-vs-code에서-파스칼-사용하기)을 참고하세요!

## 4. Lazarus 설치하기 (단계별 가이드)

### Step 1: 공식 사이트에서 다운로드

1. 브라우저에서 **https://www.lazarus-ide.org** 에 접속합니다.
2. 상단 메뉴에서 **[Download]** 를 클릭합니다.
3. 본인의 운영체제에 맞는 설치 파일을 다운로드합니다.
   - **Windows 64-bit**: `lazarus-xxx-fpc-xxx-win64.exe` ← 대부분의 경우

### Step 2: 설치 파일 실행

1. 다운로드된 `.exe` 파일을 **더블클릭**하여 실행합니다.
2. **"다음(Next)"** 버튼을 계속 눌러 기본 옵션으로 설치합니다.
   - 설치 경로는 기본값인 `C:\Lazarus` 를 그대로 사용하는 것을 권장합니다.
3. 설치가 완료되면 **"Finish"** 를 클릭합니다.

> ⚠️ 설치 경로에 **한글**이나 **공백**이 포함되면 오류가 날 수 있습니다! 반드시 영문 경로를 사용하세요.

### Step 3: Lazarus 첫 실행

- 바탕화면의 **Lazarus 아이콘**을 더블클릭합니다.
- 처음 실행 시 언어를 선택하는 창이 나올 수 있습니다. (한국어도 지원합니다!)

## 5. Delphi Community Edition 설치하기

### Step 1: 무료 등록 및 다운로드

1. **https://www.embarcadero.com/products/delphi/starter** 에 접속합니다.
2. **"Download Free Trial"** 또는 **"Community Edition"** 버튼을 찾아 클릭합니다.
3. 이메일 주소를 입력하여 무료 계정을 등록합니다.
4. 이메일로 오는 인증 링크를 클릭하고 설치 파일을 다운로드합니다.

### Step 2: 설치

1. 다운로드된 설치 파일을 실행합니다.
2. 로그인 화면이 나오면 방금 만든 계정 정보를 입력합니다.
3. 설치 옵션에서 **"Delphi"** 를 선택하고 **Windows 대상 플랫폼**을 체크합니다.
4. "Install"을 눌러 설치를 진행합니다. (시간이 꽤 걸립니다, 10~30분)

> ⚠️ 인터넷 연결이 필요하며, 여유 용량이 최소 10GB 이상 필요합니다.

## 6. 첫 번째 프로젝트 만들고 실행하기 (Lazarus 기준)

### Step 1: 새 프로젝트 만들기

1. Lazarus를 실행합니다.
2. 메뉴에서 **[File] → [New...] → [Application]** 을 선택합니다.
   - GUI 창 없이 텍스트만 출력하려면 **[Console Application]** 을 선택하세요.

### Step 2: 코드 작성

콘솔 애플리케이션을 만들었다면, 에디터 창에 아래 코드를 입력합니다:

```pascal
program HelloWorld;

{$APPTYPE CONSOLE} // 콘솔(검은 창)에서 실행하겠다는 의미입니다.

begin
  // 화면에 글자를 출력합니다.
  Writeln('안녕하세요! 오브젝트 파스칼의 세계에 오신 것을 환영합니다!');
  Writeln('Hello, World!');
  
  // 사용자가 엔터키를 누를 때까지 기다립니다. (창이 바로 닫히는 것을 방지)
  Readln;
end.
```

### Step 3: 파일 저장

- **[File] → [Save All]** 또는 키보드 단축키 **Ctrl + Shift + S** 를 누릅니다.
- 저장할 폴더를 새로 만들고 (예: `C:\MyPascal\HelloWorld`) 저장합니다.

### Step 4: 컴파일 및 실행

| 방법 | 단축키 | 설명 |
|---|---|---|
| **실행** | `F9` | 컴파일하고 바로 실행합니다 |
| **컴파일만** | `Ctrl + F9` | 코드 오류만 확인합니다 |
| **단계별 실행 (디버깅)** | `F8` | 코드를 한 줄씩 실행하며 확인합니다 |

`F9`를 누르면 검은 콘솔 창이 뜨면서 메시지가 출력됩니다. 🎉

### 코드 설명

- `program HelloWorld;`: 이 프로그램의 이름을 컴퓨터에게 알려줍니다.
- `begin` / `end.`: 프로그램이 시작되고 끝나는 범위를 표시합니다. (마지막 `end` 뒤에는 마침표 `.` 필수!)
- `{ }` 또는 `//`: 주석(설명문). 프로그램 실행에는 영향이 없고, 메모를 남기는 용도입니다.
- `Writeln(...)`: 괄호 안의 내용을 화면에 출력하고 줄바꿈 합니다.
- `Readln`: 사용자의 키보드 입력을 기다립니다.

## 7. VS Code에서 파스칼 사용하기

VS Code에서 파스칼을 사용하려면 별도 컴파일러와 확장 플러그인을 직접 설치해야 합니다.

### Step 1: Free Pascal Compiler (FPC) 설치

컴파일러는 우리가 작성한 파스칼 코드를 컴퓨터가 이해하는 기계어로 변환해 주는 프로그램입니다.

1. **https://www.freepascal.org/download.html** 에 접속합니다.
2. **Windows** 항목에서 **64-bit** 설치 파일을 다운로드합니다.
3. 설치 파일을 실행하고 기본 옵션으로 설치합니다. (기본 경로: `C:\FPC\`)

### Step 2: 환경 변수 설정 (PATH 추가)

설치 후 `fpc` 명령어를 어디서든 쓸 수 있도록 등록해야 합니다.

1. 윈도우 검색창에 **"환경 변수"** 를 검색하고 **"시스템 환경 변수 편집"** 을 클릭합니다.
2. 하단의 **[환경 변수(N)...]** 버튼을 클릭합니다.
3. 시스템 변수 목록에서 **Path** 를 찾아 선택하고 **[편집(E)...]** 을 클릭합니다.
4. **[새로 만들기]** 를 클릭하고 `C:\FPC\버전번호\bin\x86_64-win64` 를 추가합니다.
   (예: `C:\FPC\3.2.2\bin\x86_64-win64`)
5. **[확인]** 버튼을 눌러 창을 모두 닫습니다.

> 설정 후 **명령 프롬프트(CMD)** 를 새로 열어서 `fpc --version` 을 입력했을 때 버전 번호가 나오면 성공!

### Step 3: VS Code 확장 설치

1. VS Code를 열고 왼쪽 사이드바에서 **확장 아이콘(Extensions)** 을 클릭합니다. (`Ctrl+Shift+X`)
2. 검색창에 **"Pascal"** 을 입력합니다.
3. **"OmniPascal"** 또는 **"Pascal"** (by Nader Alosious) 확장을 설치합니다.

### Step 4: VS Code에서 파스칼 파일 만들고 컴파일하기

1. 새 파일을 만들고 확장자를 `.pas`로 저장합니다. (예: `hello.pas`)
2. 코드를 작성합니다.
3. **터미널(Terminal) → 새 터미널** 을 열고 아래 명령어를 입력합니다:

```bash
# 현재 폴더의 hello.pas 파일을 컴파일합니다
fpc hello.pas

# 컴파일 성공 후 생성된 실행 파일을 실행합니다 (윈도우)
hello.exe
```

## 9. 자주 묻는 질문 (FAQ)

**Q: Free Pascal과 Delphi의 문법이 다른가요?**  
A: 기초 문법은 99% 동일합니다. 일부 최신 Delphi 기능(예: 최신 제네릭)만 차이가 있습니다. 이 교재의 내용은 둘 다 동작합니다.

**Q: 한국어를 화면에 출력할 수 있나요?**  
A: 네! 다만 파일을 저장할 때 인코딩을 **UTF-8**로 설정하고, 폰트나 터미널 설정이 한글을 지원해야 합니다. Lazarus에서는 기본적으로 지원됩니다.

**Q: 스마트폰 앱도 만들 수 있나요?**  
A: Delphi (유료/커뮤니티)를 사용하면 안드로이드와 iOS 앱도 파스칼로 만들 수 있습니다! Lazarus도 일부 지원합니다.
