# 1장. 오브젝트 파스칼 시작하기

안녕하세요! 오브젝트 파스칼(Object Pascal)의 세계에 오신 것을 환영합니다. 🎉
이 문서는 프로그래밍을 처음 접하거나, 오브젝트 파스칼을 처음 배우는 초보자분들을 위해 아주 쉽게 쓰여졌습니다.

## 오브젝트 파스칼이란?
오브젝트 파스칼은 읽기 쉽고 배우기 쉬운 프로그래밍 언어인 **파스칼(Pascal)**에 **객체 지향(Object-Oriented)** 기능을 추가하여 발전시킨 언어입니다. 주로 윈도우, 모바일 애플리케이션을 아주 빠르게 만들 수 있는 **델파이(Delphi)**라는 도구에서 널리 사용됩니다.

## 특징
- **읽기 쉬운 문법**: 영어 문장과 비슷해서 초보자가 코드를 읽고 흐름을 이해하기 아주 편합니다.
- **안전함**: 변수나 데이터의 종류(타입)를 엄격하게 검사해서 프로그래머의 실수를 미리 방지해 줍니다.
- **빠른 실행 속도**: 작성한 코드가 컴퓨터가 바로 이해할 수 있는 기계어로 번역(컴파일)되어 아주 빠르게 실행됩니다.

## 첫 번째 프로그램: Hello, World!
모든 프로그래밍 언어의 시작, 화면에 인사를 출력해 볼까요?

```pascal
program HelloWorld;

{$APPTYPE CONSOLE} // 콘솔(검은 창)에서 실행하겠다는 의미입니다.

begin
  // 화면에 글자를 출력합니다.
  Writeln('Hello, World!');
  
  // 사용자가 엔터키를 누를 때까지 기다립니다. (창이 바로 닫히는 것을 방지)
  Readln;
end.
```

- `program HelloWorld;`: 이 프로그램의 이름이 HelloWorld라고 컴퓨터에게 알려줍니다.
- `begin` 과 `end.`: 프로그램이 시작되고 끝나는 부분을 나타냅니다. 괄호 `{ }` 대신 단어를 사용합니다. (마지막 `end` 뒤에는 꼭 마침표 `.`가 붙습니다!)
- `Writeln`: 글자를 화면에 출력(Write)하고 줄바꿈(Line)을 하라는 명령어입니다.
- `Readln`: 사용자의 입력을 기다립니다.

이제 오브젝트 파스칼과 첫 인사를 나누었습니다! 다음 장에서는 데이터를 저장하는 방법에 대해 알아보겠습니다.
