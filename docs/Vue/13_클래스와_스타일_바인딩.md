# 클래스와 스타일 바인딩

## 이번 장에서 배울 것

Vue에서는 상태에 따라 HTML class와 inline style을 동적으로 바꿀 수 있다. 버튼 활성화, 에러 표시, 선택된 항목 강조 같은 기능을 만들 때 자주 사용한다.

---

## class 바인딩 기본

HTML class를 동적으로 적용하려면 `:class`를 사용한다.

```vue
<script setup>
import { ref } from 'vue'

const isActive = ref(true)
</script>

<template>
  <div :class="{ active: isActive }">
    선택된 항목
  </div>
</template>
```

`isActive`가 참이면 `active` class가 적용된다.

---

## 정적 class와 함께 사용하기

기존 class와 동적 class를 함께 사용할 수 있다.

```html
<div class="item" :class="{ active: isActive, error: hasError }">
  항목
</div>
```

`item`은 항상 적용되고, `active`와 `error`는 조건에 따라 적용된다.

---

## computed로 class 정리하기

조건이 복잡해지면 템플릿이 지저분해진다. 이럴 때 `computed`를 사용한다.

```vue
<script setup>
import { computed, ref } from 'vue'

const isActive = ref(true)
const hasError = ref(false)

const itemClass = computed(() => {
  return {
    active: isActive.value,
    error: hasError.value
  }
})
</script>

<template>
  <div class="item" :class="itemClass">항목</div>
</template>
```

템플릿은 짧아지고, 조건은 JavaScript 쪽에서 읽기 쉽게 관리할 수 있다.

---

## 배열 문법

class를 배열로 전달할 수도 있다.

```vue
<script setup>
const baseClass = 'button'
const colorClass = 'button-primary'
</script>

<template>
  <button :class="[baseClass, colorClass]">저장</button>
</template>
```

조건부 class를 섞을 수도 있다.

```html
<button :class="['button', isPrimary ? 'button-primary' : 'button-secondary']">
  확인
</button>
```

---

## style 바인딩 기본

inline style은 `:style`로 연결한다.

```vue
<script setup>
import { ref } from 'vue'

const activeColor = ref('blue')
const fontSize = ref(20)
</script>

<template>
  <p :style="{ color: activeColor, fontSize: fontSize + 'px' }">
    스타일이 바뀌는 문장
  </p>
</template>
```

CSS 속성 이름은 JavaScript 객체처럼 camelCase로 쓸 수 있다.

```js
fontSize
backgroundColor
```

또는 문자열로 kebab-case를 사용할 수 있다.

```html
<p :style="{ 'font-size': fontSize + 'px' }"></p>
```

---

## style 객체로 정리하기

스타일이 많아지면 객체로 분리한다.

```vue
<script setup>
import { computed, ref } from 'vue'

const color = ref('#2563eb')
const size = ref(18)

const textStyle = computed(() => ({
  color: color.value,
  fontSize: `${size.value}px`
}))
</script>

<template>
  <p :style="textStyle">미리보기 텍스트</p>
</template>
```

---

## 언제 class를 쓰고 언제 style을 쓸까?

가능하면 class를 먼저 고려하는 것이 좋다.

| 상황 | 추천 |
| --- | --- |
| 정해진 디자인 상태 전환 | `:class` |
| 에러, 활성화, 선택 상태 | `:class` |
| 사용자가 고른 색상이나 크기 | `:style` |
| 계산된 픽셀 값 적용 | `:style` |

디자인 시스템이나 공통 스타일이 있다면 class 중심이 유지보수하기 쉽다.

---

## 자주 하는 실수

### class 문자열을 직접 이어 붙임

```html
<div :class="'item ' + (isActive ? 'active' : '')"></div>
```

간단한 경우는 괜찮지만 조건이 늘면 읽기 어려워진다. 객체 문법을 쓰자.

```html
<div class="item" :class="{ active: isActive }"></div>
```

### style 숫자에 단위를 빼먹음

```html
<p :style="{ fontSize: fontSize }"></p>
```

대부분의 CSS 크기 값에는 단위가 필요하다.

```html
<p :style="{ fontSize: fontSize + 'px' }"></p>
```

### 템플릿에 조건을 너무 많이 넣음

조건이 복잡하면 `computed`로 분리한다.

## 작은 실습

버튼을 누르면 카드가 선택 상태로 바뀌는 예제를 만들어보자.

```vue
<script setup>
import { ref } from 'vue'

const selected = ref(false)
</script>

<template>
  <article class="card" :class="{ selected }">
    <h2>Vue 카드</h2>
    <p>선택 여부: {{ selected }}</p>
    <button @click="selected = !selected">선택 전환</button>
  </article>
</template>

<style scoped>
.card {
  padding: 16px;
  border: 1px solid #ddd;
}

.selected {
  border-color: #2563eb;
  background: #eff6ff;
}
</style>
```

---

## 이번 장 요약

- `:class`로 class를 동적으로 적용한다.
- class 바인딩에는 객체와 배열 문법을 사용할 수 있다.
- `:style`로 inline style을 동적으로 적용한다.
- 복잡한 class와 style 조건은 `computed`로 분리하면 좋다.
