# 템플릿 문법

## 이번 장에서 배울 것

Vue 템플릿은 HTML을 기반으로 한다. 여기에 Vue만의 문법을 더해 JavaScript 상태를 화면에 연결한다.

이번 장에서는 다음 문법을 배운다.

- 텍스트 보간법 `{{ }}`
- 속성 바인딩 `v-bind`, `:`
- JavaScript 표현식
- 디렉티브
- `v-html` 사용 주의점

---

## 텍스트 보간법

가장 기본적인 데이터 표시 방법은 `{{ }}`다.

```vue
<script setup>
const message = '안녕하세요 Vue'
</script>

<template>
  <p>{{ message }}</p>
</template>
```

브라우저에는 다음처럼 보인다.

```text
안녕하세요 Vue
```

`message` 값이 바뀌면 화면의 텍스트도 바뀐다.

---

## JavaScript 표현식 사용하기

`{{ }}` 안에는 간단한 JavaScript 표현식을 사용할 수 있다.

```vue
<script setup>
const count = 3
const name = 'kim'
</script>

<template>
  <p>{{ count + 1 }}</p>
  <p>{{ name.toUpperCase() }}</p>
  <p>{{ count > 0 ? '있음' : '없음' }}</p>
</template>
```

다만 템플릿에 복잡한 로직을 많이 넣으면 읽기 어려워진다. 복잡한 계산은 `computed`나 함수로 빼는 것이 좋다.

---

## 속성에는 중괄호를 쓰지 않는다

HTML 속성 안에서는 `{{ }}`를 사용할 수 없다.

```html
<!-- 잘못된 예 -->
<div id="{{ dynamicId }}"></div>
```

속성을 동적으로 연결하려면 `v-bind`를 사용한다.

```html
<div v-bind:id="dynamicId"></div>
```

Vue에서는 짧은 문법인 `:`를 더 자주 사용한다.

```html
<div :id="dynamicId"></div>
```

---

## Boolean 속성 바인딩

`disabled`, `checked`, `selected` 같은 속성은 참/거짓에 따라 붙거나 빠진다.

```vue
<script setup>
import { ref } from 'vue'

const isSaving = ref(false)
</script>

<template>
  <button :disabled="isSaving">저장</button>
</template>
```

`isSaving`이 `true`이면 버튼이 비활성화된다.

---

## 여러 속성을 한 번에 바인딩하기

객체를 사용하면 여러 속성을 한 번에 연결할 수 있다.

```vue
<script setup>
const attrs = {
  id: 'save-button',
  type: 'button',
  title: '저장하기'
}
</script>

<template>
  <button v-bind="attrs">저장</button>
</template>
```

결과적으로 버튼에는 `id`, `type`, `title` 속성이 적용된다.

---

## 디렉티브란?

디렉티브는 `v-`로 시작하는 Vue 전용 속성이다.

```html
<p v-if="isVisible">보입니다</p>
<li v-for="item in items" :key="item.id">{{ item.name }}</li>
<button @click="save">저장</button>
```

대표적인 디렉티브는 다음과 같다.

| 디렉티브 | 역할 |
| --- | --- |
| `v-bind` | 속성 바인딩 |
| `v-if` | 조건부 렌더링 |
| `v-for` | 리스트 렌더링 |
| `v-on` | 이벤트 처리 |
| `v-model` | 폼 입력 바인딩 |
| `v-show` | 표시 여부 전환 |

---

## v-on과 @

이벤트를 연결할 때는 `v-on`을 사용한다.

```html
<button v-on:click="save">저장</button>
```

짧게 쓰면 `@`다.

```html
<button @click="save">저장</button>
```

이 문서에서는 일반적으로 짧은 문법을 사용한다.

---

## v-html 주의하기

`{{ }}`는 HTML을 텍스트로 표시한다. 실제 HTML로 렌더링하려면 `v-html`을 사용할 수 있다.

```vue
<script setup>
const rawHtml = '<strong>강조된 문장</strong>'
</script>

<template>
  <p>{{ rawHtml }}</p>
  <p v-html="rawHtml"></p>
</template>
```

하지만 `v-html`은 매우 조심해야 한다. 사용자 입력을 그대로 `v-html`에 넣으면 XSS 보안 문제가 생길 수 있다.

초보자는 원칙적으로 사용자 입력에는 `v-html`을 사용하지 않는다고 기억하자.

---

## 자주 하는 실수

### 속성에 중괄호를 사용함

```html
<!-- 잘못된 예 -->
<img src="{{ imageUrl }}" alt="">
```

```html
<!-- 올바른 예 -->
<img :src="imageUrl" alt="">
```

### 템플릿에 너무 복잡한 로직을 넣음

```html
{{ users.filter((user) => user.active).map((user) => user.name).join(', ') }}
```

이런 코드는 나중에 `computed`로 분리하는 것이 좋다.

### v-html을 사용자 입력에 사용함

사용자가 입력한 값을 HTML로 렌더링하면 보안 위험이 있다. 신뢰할 수 있는 콘텐츠에만 제한적으로 사용한다.

---

## 작은 실습

아래 요구사항을 만족하는 코드를 작성해보자.

- `title` 값을 `h1`에 표시한다.
- `imageUrl` 값을 `img`의 `src`에 연결한다.
- `isDisabled`가 참이면 버튼을 비활성화한다.

예:

```vue
<script setup>
const title = 'Vue 템플릿 연습'
const imageUrl = 'https://vuejs.org/images/logo.png'
const isDisabled = true
</script>

<template>
  <h1>{{ title }}</h1>
  <img :src="imageUrl" alt="Vue 로고">
  <button :disabled="isDisabled">확인</button>
</template>
```

---

## 이번 장 요약

- `{{ }}`는 텍스트를 화면에 표시한다.
- HTML 속성에는 `v-bind` 또는 `:`를 사용한다.
- 이벤트는 `v-on` 또는 `@`로 연결한다.
- `v-`로 시작하는 Vue 전용 속성을 디렉티브라고 한다.
- `v-html`은 보안 위험이 있으므로 신중히 사용한다.
