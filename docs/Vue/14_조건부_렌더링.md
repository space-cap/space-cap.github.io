# 조건부 렌더링

## 이번 장에서 배울 것

조건부 렌더링은 상태에 따라 어떤 요소를 보여주거나 숨기는 기능이다. 로그인 여부, 로딩 상태, 에러 메시지, 빈 목록 안내 등에 자주 사용한다.

---

## v-if

`v-if`는 조건이 참일 때만 요소를 렌더링한다.

```vue
<script setup>
import { ref } from 'vue'

const isLoggedIn = ref(false)
</script>

<template>
  <p v-if="isLoggedIn">로그인 상태입니다.</p>
  <p v-if="!isLoggedIn">로그인이 필요합니다.</p>
</template>
```

조건이 거짓이면 해당 요소는 DOM에 만들어지지 않는다.

---

## v-else

`v-else`는 바로 앞의 `v-if`가 거짓일 때 렌더링된다.

```html
<p v-if="isLoggedIn">로그인 상태입니다.</p>
<p v-else>로그인이 필요합니다.</p>
```

`v-else`는 반드시 `v-if` 바로 다음에 와야 한다.

---

## v-else-if

여러 조건을 순서대로 검사할 때 사용한다.

```vue
<script setup>
import { ref } from 'vue'

const status = ref('loading')
</script>

<template>
  <p v-if="status === 'loading'">불러오는 중...</p>
  <p v-else-if="status === 'error'">오류가 발생했습니다.</p>
  <p v-else>데이터를 불러왔습니다.</p>
</template>
```

---

## template에 v-if 사용하기

여러 요소를 한 조건으로 묶고 싶을 때 `<template>`을 사용할 수 있다.

```html
<template v-if="isLoggedIn">
  <h2>내 정보</h2>
  <p>환영합니다.</p>
</template>
```

`template` 자체는 실제 DOM에 남지 않고 내부 요소만 렌더링된다.

---

## v-show

`v-show`도 조건에 따라 요소를 보여주거나 숨긴다.

```html
<p v-show="isVisible">보이거나 숨겨지는 문장</p>
```

`v-show`는 요소를 DOM에 남겨두고 CSS `display`로 숨긴다.

---

## v-if와 v-show 차이

| 구분 | v-if | v-show |
| --- | --- | --- |
| 거짓일 때 | DOM에 없음 | DOM에 있지만 숨김 |
| 초기 렌더링 | 조건이 거짓이면 만들지 않음 | 일단 만들고 숨김 |
| 자주 토글 | 상대적으로 비용이 있음 | 자주 토글에 유리 |
| 사용 예 | 권한별 화면, 로딩 완료 후 화면 | 탭, 펼침/접힘, 간단한 표시 전환 |

대부분의 초보 예제는 `v-if`로 시작해도 된다. 매우 자주 보였다 숨겨지는 UI라면 `v-show`를 고려한다.

---

## 로딩/에러/성공 화면 만들기

```vue
<script setup>
import { ref } from 'vue'

const status = ref('idle')

function loadData() {
  status.value = 'loading'

  setTimeout(() => {
    status.value = 'success'
  }, 1000)
}
</script>

<template>
  <button @click="loadData">데이터 불러오기</button>

  <p v-if="status === 'idle'">버튼을 눌러주세요.</p>
  <p v-else-if="status === 'loading'">불러오는 중...</p>
  <p v-else-if="status === 'error'">오류가 발생했습니다.</p>
  <p v-else>완료되었습니다.</p>
</template>
```

이 패턴은 API 통신을 배울 때도 계속 사용한다.

---

## 자주 하는 실수

### v-else를 v-if와 떨어뜨림

```html
<p v-if="isReady">준비됨</p>
<hr>
<p v-else>준비 안 됨</p>
```

`v-else`는 `v-if` 바로 다음 형제 요소여야 한다.

### v-if와 v-for를 같은 요소에 함께 사용함

가능하면 같은 요소에 `v-if`와 `v-for`를 함께 쓰지 않는다. 목록을 먼저 계산하거나, 바깥에 `template`을 사용하는 편이 명확하다.

### v-show로 민감한 정보를 숨김

`v-show`는 DOM에 요소가 남아 있다. 권한 때문에 보여주면 안 되는 정보라면 `v-if`를 사용하는 것이 더 낫다.

---

## 작은 실습

다음 상태를 가진 화면을 만들어보자.

- `isLoggedIn`이 `false`이면 로그인 버튼을 보여준다.
- `isLoggedIn`이 `true`이면 환영 문구와 로그아웃 버튼을 보여준다.
- 버튼을 누르면 로그인 상태가 전환된다.

힌트:

```vue
<script setup>
import { ref } from 'vue'

const isLoggedIn = ref(false)
</script>

<template>
  <button @click="isLoggedIn = !isLoggedIn">
    {{ isLoggedIn ? '로그아웃' : '로그인' }}
  </button>

  <p v-if="isLoggedIn">환영합니다.</p>
  <p v-else>로그인이 필요합니다.</p>
</template>
```

---

## 이번 장 요약

- `v-if`는 조건이 참일 때만 요소를 렌더링한다.
- `v-else`, `v-else-if`로 여러 조건을 처리할 수 있다.
- `v-show`는 요소를 DOM에 남긴 채 표시 여부만 바꾼다.
- 자주 토글되는 단순 UI는 `v-show`, 조건에 따라 실제로 만들지 않을 요소는 `v-if`를 고려한다.
