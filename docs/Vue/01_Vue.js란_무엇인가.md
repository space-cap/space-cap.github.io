# Vue.js란 무엇인가

## 이번 장에서 배울 것

이번 장에서는 Vue.js가 무엇인지, 왜 사용하는지, 그리고 초보자가 Vue를 배울 때 어떤 관점으로 접근하면 좋은지 살펴본다.

Vue를 한 문장으로 말하면 **사용자 화면을 만들기 위한 JavaScript 프레임워크**다. 조금 더 풀어 말하면 HTML, CSS, JavaScript 위에서 동작하면서 화면 상태를 쉽게 다루고, 화면을 작은 컴포넌트로 나누어 개발할 수 있게 도와주는 도구다.

---

## Vue를 배우기 전에 알아야 할 큰 그림

웹 화면은 기본적으로 세 가지 기술로 만들어진다.

| 기술 | 역할 |
| --- | --- |
| HTML | 화면의 구조를 만든다. |
| CSS | 화면의 모양을 꾸민다. |
| JavaScript | 화면의 동작을 만든다. |

처음에는 이 세 가지만으로 충분해 보인다. 하지만 화면이 복잡해지면 문제가 생긴다.

- 버튼을 눌렀을 때 여러 곳의 값이 동시에 바뀐다.
- 목록을 추가, 수정, 삭제해야 한다.
- 로그인 여부에 따라 화면이 달라진다.
- 페이지는 여러 개인데 공통 헤더와 메뉴는 재사용하고 싶다.
- 코드가 길어지면서 어디서 무엇이 바뀌는지 찾기 어려워진다.

Vue는 이런 문제를 해결하기 위해 등장했다. 특히 **데이터가 바뀌면 화면도 자동으로 바뀌게 하는 방식**을 제공한다.

---

## Vue의 핵심 생각

Vue를 처음 배울 때는 아래 세 가지를 먼저 잡으면 된다.

### 1. 선언적 렌더링

기존 JavaScript에서는 화면을 직접 찾아서 바꾸는 코드가 많았다.

```js
document.querySelector('#message').textContent = '안녕하세요'
```

Vue에서는 "이 데이터가 이 자리에 보인다"라고 선언한다.

```html
<p>{{ message }}</p>
```

```js
const message = '안녕하세요'
```

데이터가 바뀌면 Vue가 알아서 화면을 갱신한다. 개발자는 DOM을 일일이 조작하는 대신 **상태를 어떻게 표현할지**에 집중할 수 있다.

### 2. 반응성

반응성은 값이 바뀌면 그 값을 사용하는 화면도 함께 바뀌는 성질이다.

예를 들어 `count` 값이 `0`에서 `1`로 바뀌면, 화면에 보이는 숫자도 자동으로 `1`이 된다. Vue를 쓰면 이 연결을 직접 관리하지 않아도 된다.

### 3. 컴포넌트

컴포넌트는 화면을 이루는 작은 부품이다.

예를 들어 블로그 화면을 만든다면 다음처럼 나눌 수 있다.

- `Header`
- `PostList`
- `PostItem`
- `Pagination`
- `Footer`

큰 화면을 작은 부품으로 나누면 코드를 읽기 쉽고, 같은 UI를 여러 곳에서 재사용하기도 쉽다.

## 프레임워크와 라이브러리의 차이

초보자가 자주 헷갈리는 말이 프레임워크와 라이브러리다.

라이브러리는 내가 필요할 때 불러 쓰는 도구에 가깝다. 예를 들어 날짜 계산 라이브러리는 날짜가 필요할 때만 가져다 쓴다.

프레임워크는 애플리케이션의 기본 구조와 개발 방식을 제안한다. Vue는 화면 구성, 상태 변경, 컴포넌트 작성 방식에 대한 규칙과 도구를 제공하므로 프레임워크라고 부른다.

다만 Vue는 비교적 유연하다. 작은 HTML 페이지에 일부 기능만 붙일 수도 있고, 큰 단일 페이지 애플리케이션을 만들 수도 있다. 이런 성격 때문에 Vue 공식 문서에서는 Vue를 **점진적으로 적용 가능한 프레임워크**라고 설명한다.

---

## Vue로 만들 수 있는 것

Vue는 다음과 같은 화면을 만드는 데 사용할 수 있다.

- 관리자 페이지
- 쇼핑몰 장바구니
- 게시판
- 예약 시스템
- 대시보드
- 블로그
- 기존 서버 페이지의 일부 인터랙션
- SPA, SSG, SSR 기반 웹 애플리케이션

처음부터 모든 용어를 알 필요는 없다. 이 문서에서는 작은 예제에서 시작해 점점 실제 프로젝트 구조로 확장한다.

---

## Vue를 배울 때의 추천 순서

Vue 초보자는 아래 순서로 배우면 부담이 적다.

1. HTML, CSS, JavaScript 기본을 간단히 확인한다.
2. CDN으로 Vue를 붙여 아주 작은 예제를 실행한다.
3. Vite로 Vue 프로젝트를 만든다.
4. 템플릿 문법, 상태, 이벤트, 조건부 렌더링, 리스트 렌더링을 배운다.
5. 컴포넌트를 나누고 Props와 Emit을 배운다.
6. Router와 Pinia로 실제 앱 구조를 익힌다.
7. API 통신, 테스트, 배포로 실무 흐름을 익힌다.

## 자주 하는 오해

### Vue를 배우려면 JavaScript를 완벽히 알아야 하나?

완벽할 필요는 없다. 다만 변수, 함수, 배열, 객체, 이벤트, 비동기 처리의 기본은 알고 있으면 좋다. 부족한 부분은 `03_학습_전에_알아야_할_HTML_CSS_JS.md`에서 다시 정리한다.

### Vue만 배우면 HTML과 CSS는 몰라도 되나?

아니다. Vue는 HTML, CSS, JavaScript 위에서 동작한다. Vue를 잘 쓰려면 기본 웹 기술도 함께 이해해야 한다.

### Vue 2부터 배워야 하나?

새로 배우는 사람은 Vue 3부터 배우면 된다. Vue 2는 지원이 종료되었고, 새 프로젝트는 Vue 3 기준으로 시작하는 것이 좋다.

## 작은 실습

아래 코드를 읽고 어떤 부분이 HTML이고, 어떤 부분이 JavaScript 상태인지 구분해보자.

```html
<div id="app">
  <h1>{{ title }}</h1>
  <button @click="count++">클릭 횟수: {{ count }}</button>
</div>
```

```js
const title = 'Vue 시작하기'
const count = 0
```

지금은 실행하지 않아도 된다. 중요한 것은 `title`과 `count` 같은 값이 화면에 연결된다는 감각을 잡는 것이다.
