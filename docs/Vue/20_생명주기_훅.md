# 생명주기 훅

## 이번 장에서 배울 것

컴포넌트는 만들어지고, 화면에 붙고, 업데이트되고, 사라지는 과정을 거친다. 이 과정의 특정 시점에 실행되는 함수를 생명주기 훅이라고 한다.

Composition API에서는 `onMounted`, `onUpdated`, `onUnmounted` 같은 함수를 사용한다.

---

## 생명주기란?

컴포넌트의 생명주기를 단순하게 보면 다음과 같다.

```text
생성 준비
  ↓
화면에 붙음
  ↓
상태 변경으로 업데이트됨
  ↓
화면에서 사라짐
```

각 시점에 필요한 작업이 다르다.

| 시점 | 예시 작업 |
| --- | --- |
| 화면에 붙은 뒤 | API 호출, DOM 접근, 외부 라이브러리 초기화 |
| 업데이트된 뒤 | 변경된 DOM 기준으로 후처리 |
| 사라지기 전후 | 타이머 정리, 이벤트 리스너 제거 |

---

## onMounted

`onMounted`는 컴포넌트가 화면에 붙은 뒤 실행된다.

```vue
<script setup>
import { onMounted } from 'vue'

onMounted(() => {
  console.log('컴포넌트가 화면에 붙었습니다.')
})
</script>

<template>
  <p>생명주기 연습</p>
</template>
```

DOM 요소에 접근하거나 처음 데이터를 불러올 때 자주 사용한다.

---

## onMounted에서 API 호출하기

```vue
<script setup>
import { onMounted, ref } from 'vue'

const posts = ref([])
const loading = ref(false)

async function loadPosts() {
  loading.value = true

  try {
    const response = await fetch('/api/posts')
    posts.value = await response.json()
  } finally {
    loading.value = false
  }
}

onMounted(() => {
  loadPosts()
})
</script>
```

실제 API 통신은 나중에 더 자세히 다룬다. 지금은 "처음 화면에 들어왔을 때 데이터를 불러오는 위치"로 이해하면 된다.

---

## onUpdated

`onUpdated`는 반응형 상태 변경으로 DOM이 업데이트된 뒤 실행된다.

```vue
<script setup>
import { onUpdated, ref } from 'vue'

const count = ref(0)

onUpdated(() => {
  console.log('화면이 업데이트되었습니다.')
})
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>
```

일반적인 상태 변경에는 꼭 필요하지 않다. 대부분 Vue가 화면을 알아서 갱신하기 때문이다.

---

## onUnmounted

`onUnmounted`는 컴포넌트가 화면에서 사라진 뒤 실행된다. 타이머나 이벤트 리스너를 정리할 때 사용한다.

```vue
<script setup>
import { onMounted, onUnmounted, ref } from 'vue'

const seconds = ref(0)
let timerId = null

onMounted(() => {
  timerId = window.setInterval(() => {
    seconds.value++
  }, 1000)
})

onUnmounted(() => {
  window.clearInterval(timerId)
})
</script>

<template>
  <p>{{ seconds }}초</p>
</template>
```

정리하지 않으면 화면에서 사라진 뒤에도 타이머가 계속 돌 수 있다.

---

## setup 안에서 호출하기

생명주기 훅은 보통 `<script setup>`의 최상위에서 호출한다.

```vue
<script setup>
import { onMounted } from 'vue'

onMounted(() => {
  console.log('mounted')
})
</script>
```

조건문 안에서 훅을 불규칙하게 호출하는 식은 피한다.

---

## Options API와 비교

Options API에서는 다음처럼 작성한다.

```vue
<script>
export default {
  mounted() {
    console.log('mounted')
  },
  updated() {
    console.log('updated')
  },
  unmounted() {
    console.log('unmounted')
  }
}
</script>
```

Composition API에서는 다음 함수를 사용한다.

| Options API | Composition API |
| --- | --- |
| `mounted` | `onMounted` |
| `updated` | `onUpdated` |
| `unmounted` | `onUnmounted` |

---

## 자주 하는 실수

### 모든 초기 코드를 onMounted에 넣음

단순한 변수 선언이나 계산은 `onMounted`에 넣지 않아도 된다.

```js
const count = ref(0)
```

DOM 접근, API 호출, 외부 라이브러리 초기화처럼 화면이 준비된 뒤 필요한 작업에 사용한다.

### 타이머를 정리하지 않음

`setInterval`, `addEventListener`를 사용했다면 `onUnmounted`에서 정리하는 습관을 들인다.

### onUpdated에서 상태를 계속 변경함

`onUpdated` 안에서 상태를 바꾸면 다시 업데이트가 발생해 반복될 수 있다. 꼭 필요한 경우가 아니면 피한다.

---

## 작은 실습

타이머 컴포넌트를 만들어보자.

- 컴포넌트가 화면에 나타나면 1초마다 숫자가 증가한다.
- 현재 초를 화면에 표시한다.
- 컴포넌트가 사라질 때 타이머를 정리한다.

힌트:

```js
onMounted(() => {
  timerId = setInterval(() => {
    seconds.value++
  }, 1000)
})

onUnmounted(() => {
  clearInterval(timerId)
})
```

---

## 이번 장 요약

- 생명주기 훅은 컴포넌트의 특정 시점에 실행되는 함수다.
- `onMounted`는 화면에 붙은 뒤 실행된다.
- `onUpdated`는 화면 업데이트 뒤 실행된다.
- `onUnmounted`는 컴포넌트가 사라진 뒤 실행된다.
- 타이머와 이벤트 리스너는 정리하는 습관이 중요하다.
