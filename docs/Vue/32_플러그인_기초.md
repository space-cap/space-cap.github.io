# 플러그인 기초

## 이번 장에서 배울 것

Vue 플러그인은 앱 전체에 기능을 추가하는 방법이다. Vue Router, Pinia 같은 공식 라이브러리도 Vue 앱에 `app.use()`로 등록한다.

초보자는 플러그인을 직접 많이 만들 일은 적지만, 구조를 이해하면 외부 라이브러리를 사용할 때 덜 낯설다.

---

## 플러그인이란?

플러그인은 보통 다음과 같은 일을 한다.

- 전역 컴포넌트 등록
- 전역 디렉티브 등록
- 앱 전체에서 inject할 값 제공
- 전역 속성 또는 메서드 추가
- 외부 라이브러리 초기화

플러그인은 `app.use()`로 설치한다.

```js
import { createApp } from 'vue'
import App from './App.vue'
import myPlugin from './plugins/myPlugin'

const app = createApp(App)

app.use(myPlugin)

app.mount('#app')
```

---

## 플러그인 기본 구조

플러그인은 `install` 메서드를 가진 객체로 만들 수 있다.

`src/plugins/myPlugin.js`

```js
export default {
  install(app, options) {
    console.log('플러그인 설치', options)
  }
}
```

등록:

```js
app.use(myPlugin, {
  message: '안녕하세요'
})
```

`install(app, options)`에서 `app`은 Vue 애플리케이션 인스턴스이고, `options`는 `app.use()`의 두 번째 인자로 전달한 설정이다.

---

## 함수 형태 플러그인

플러그인은 함수로도 만들 수 있다.

```js
export default function myPlugin(app, options) {
  console.log(app, options)
}
```

객체 방식과 함수 방식 모두 가능하다. 처음에는 `install` 메서드를 가진 객체 방식이 이해하기 쉽다.

---

## 전역 컴포넌트 등록 플러그인

공통 버튼을 앱 전체에 등록해보자.

`src/plugins/uiPlugin.js`

```js
import BaseButton from '../components/BaseButton.vue'

export default {
  install(app) {
    app.component('BaseButton', BaseButton)
  }
}
```

`src/main.js`

```js
import { createApp } from 'vue'
import App from './App.vue'
import uiPlugin from './plugins/uiPlugin'

const app = createApp(App)

app.use(uiPlugin)

app.mount('#app')
```

이제 여러 컴포넌트에서 import 없이 `<BaseButton />`을 사용할 수 있다.

---

## provide를 사용하는 플러그인

앱 전체에 설정값을 제공할 수도 있다.

`src/plugins/configPlugin.js`

```js
export default {
  install(app, options) {
    app.provide('appConfig', options)
  }
}
```

등록:

```js
app.use(configPlugin, {
  apiBaseUrl: 'https://api.example.com',
  appName: 'Vue Study'
})
```

사용:

```vue
<script setup>
import { inject } from 'vue'

const config = inject('appConfig')
</script>

<template>
  <p>{{ config.appName }}</p>
</template>
```

## globalProperties

전역 속성을 추가할 수도 있다.

```js
export default {
  install(app) {
    app.config.globalProperties.$formatPrice = (value) => {
      return value.toLocaleString() + '원'
    }
  }
}
```

Options API에서는 `this.$formatPrice(...)`처럼 사용할 수 있다. 하지만 Composition API와 `<script setup>` 중심 프로젝트에서는 provide/inject나 일반 import 함수가 더 명확한 경우가 많다.

초보 단계에서는 `globalProperties`를 남발하지 않는 것이 좋다.

---

## 플러그인을 직접 만들어야 할 때

다음 상황에서는 플러그인이 유용하다.

- 공통 UI 컴포넌트를 한 번에 등록하고 싶다.
- 앱 전체 설정을 주입하고 싶다.
- 전역 디렉티브를 여러 개 묶어 등록하고 싶다.
- 외부 라이브러리 초기화를 앱 시작 시점에 처리하고 싶다.

작은 프로젝트에서는 굳이 직접 플러그인을 만들지 않아도 된다. 필요가 생겼을 때 도입해도 충분하다.

---

## 자주 하는 실수

### app.mount 이후에 플러그인을 등록함

플러그인은 보통 `mount` 전에 등록한다.

```js
app.use(myPlugin)
app.mount('#app')
```

### 모든 공통 함수를 플러그인으로 만듦

단순 유틸 함수는 일반 JavaScript 함수로 export/import하는 편이 더 단순하다.

### 전역 등록을 과하게 사용함

전역 등록은 편하지만 의존성이 숨겨질 수 있다. 정말 앱 전체에서 쓰는 기능에만 사용한다.

---

## 작은 실습

`uiPlugin`을 만들어보자.

요구사항:

- `BaseButton.vue` 컴포넌트 생성
- `src/plugins/uiPlugin.js`에서 `app.component('BaseButton', BaseButton)` 등록
- `main.js`에서 `app.use(uiPlugin)` 호출
- `App.vue`에서 import 없이 `<BaseButton>저장</BaseButton>` 사용

---

## 이번 장 요약

- 플러그인은 앱 전체에 기능을 추가하는 방법이다.
- `app.use(plugin, options)`로 설치한다.
- 플러그인은 `install(app, options)` 메서드를 가진 객체 또는 함수로 만들 수 있다.
- 전역 컴포넌트, 전역 디렉티브, provide 설정 등에 사용한다.
- 작은 프로젝트에서는 꼭 필요할 때만 도입한다.
