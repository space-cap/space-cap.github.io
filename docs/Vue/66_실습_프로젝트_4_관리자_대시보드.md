# 실습 프로젝트 4: 관리자 대시보드

## 이번 프로젝트에서 만들 것

네 번째 실습 프로젝트는 관리자 대시보드다. 실무 Vue 앱에서 자주 만나는 레이아웃, 라우터, 테이블, 필터, 권한, API 상태 처리를 한 번에 연습한다.

---

## 학습 목표

이 프로젝트를 마치면 다음을 할 수 있어야 한다.

- 중첩 라우트로 관리자 레이아웃을 구성한다.
- 사이드바와 상단바를 만든다.
- 테이블 데이터를 렌더링한다.
- 검색, 필터, 정렬 상태를 관리한다.
- API 로딩/에러 상태를 처리한다.
- 인증 store와 라우터 가드를 연결한다.
- 대시보드용 컴포넌트를 분리한다.

---

## 완성 기능

- 관리자 레이아웃
- 대시보드 홈
- 사용자 목록
- 주문 목록
- 검색과 상태 필터
- 권한이 필요한 라우트
- 통계 카드
- 빈 상태와 에러 상태

const routes = [

## 권한 가드

```js
router.beforeEach((to) => {
  const auth = useAuthStore()

  if (to.meta.requiresAuth && !auth.isLoggedIn) {
    return {
      name: 'login',
      query: { redirect: to.fullPath }
    }
  }

  if (to.meta.roles && !to.meta.roles.includes(auth.user?.role)) {
    return { name: 'forbidden' }
  }
})
```

프론트엔드 권한 가드는 화면 접근을 제어하는 UX 장치다. 실제 API 권한은 서버에서도 반드시 확인해야 한다.

## 사용자 목록 상태

`UserListView.vue`

```vue
<script setup>
import { computed, onMounted, ref } from 'vue'

const users = ref([])
const loading = ref(false)
const error = ref(null)
const keyword = ref('')
const roleFilter = ref('all')

const filteredUsers = computed(() => {
  return users.value.filter((user) => {
    const matchesKeyword = user.name.includes(keyword.value)
    const matchesRole =
      roleFilter.value === 'all' || user.role === roleFilter.value

    return matchesKeyword && matchesRole
  })
})

async function loadUsers() {
  loading.value = true
  error.value = null

  try {
    const response = await fetch('/api/users')
    if (!response.ok) {
      throw new Error('사용자 목록을 불러오지 못했습니다.')
    }
    users.value = await response.json()
  } catch (err) {
    error.value = err
  } finally {
    loading.value = false
  }
}

onMounted(loadUsers)
</script>
```

## 사용자 테이블

```vue
<template>
  <section>
    <h1>사용자 관리</h1>

    <div>
      <input v-model.trim="keyword" placeholder="이름 검색">

      <select v-model="roleFilter">
        <option value="all">전체 권한</option>
        <option value="admin">관리자</option>
        <option value="user">사용자</option>
      </select>
    </div>

    <p v-if="loading">불러오는 중...</p>
    <p v-else-if="error">{{ error.message }}</p>
    <p v-else-if="filteredUsers.length === 0">사용자가 없습니다.</p>

    <table v-else>
      <thead>
        <tr>
          <th>이름</th>
          <th>이메일</th>
          <th>권한</th>
          <th>상태</th>
        </tr>
      </thead>
      <tbody>
        <tr v-for="user in filteredUsers" :key="user.id">
          <td>{{ user.name }}</td>
          <td>{{ user.email }}</td>
          <td>{{ user.role }}</td>
          <td>{{ user.active ? '활성' : '비활성' }}</td>
        </tr>
      </tbody>
    </table>
  </section>
</template>
```

테이블에는 실제 `table`, `thead`, `tbody`, `th`, `td`를 사용하면 접근성과 구조가 좋아진다.

## 주문 목록 확장

주문 목록도 사용자 목록과 비슷하게 만들 수 있다.

필터 예:

- 주문 상태: 결제 완료, 배송 중, 취소
- 기간: 오늘, 7일, 30일
- 검색어: 주문번호 또는 구매자

계산 값 예:

- 총 주문 수
- 총 매출
- 취소 주문 수
- 평균 주문 금액

## DataTable로 분리할까?

테이블이 여러 곳에서 반복되면 `DataTable.vue`로 분리할 수 있다. 하지만 초보 단계에서는 먼저 각 화면에서 직접 구현하고, 반복이 보일 때 분리하는 것이 좋다.

너무 일찍 범용 테이블을 만들면 props와 slot이 복잡해질 수 있다.

---

## 점검 체크리스트

- `/admin` 하위 라우트가 레이아웃 안에 표시된다.
- 로그인하지 않으면 관리자 페이지에 접근할 수 없다.
- 관리자 권한이 없으면 접근이 차단된다.
- 로딩, 에러, 빈 상태가 모두 표시된다.
- 검색과 필터가 함께 동작한다.
- 테이블에 안정적인 key가 있다.
