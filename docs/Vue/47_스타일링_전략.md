# 스타일링 전략

## 이번 장에서 배울 것

Vue는 특정 스타일링 방식을 강제하지 않는다. 일반 CSS, scoped CSS, CSS Modules, Sass, Tailwind CSS, UI 라이브러리 등 여러 선택지가 있다.

이번 장에서는 초보자가 프로젝트 규모에 맞게 스타일링 방식을 선택하는 기준을 배운다.

---

## 기본 CSS

가장 단순한 방식은 일반 CSS 파일을 import하는 것이다.

`src/assets/main.css`

```css
body {
  margin: 0;
  font-family: system-ui, sans-serif;
}

.container {
  max-width: 960px;
  margin: 0 auto;
  padding: 0 20px;
}
```

`src/main.js`

```js
import './assets/main.css'
```

전역 스타일, reset, 공통 레이아웃에 적합하다.

---

## scoped CSS

컴포넌트 전용 스타일은 `scoped`를 사용한다.

```vue
<template>
  <article class="card">
    <h2>카드 제목</h2>
  </article>
</template>

<style scoped>
.card {
  padding: 16px;
  border: 1px solid #ddd;
  border-radius: 8px;
}
</style>
```

`scoped`를 붙이면 스타일이 현재 컴포넌트에만 적용되도록 처리된다.

---

## 전역 CSS와 scoped CSS 나누기

권장 기준:

| 스타일 종류 | 위치 |
| --- | --- |
| reset, body, CSS 변수 | 전역 CSS |
| 공통 레이아웃 class | 전역 CSS |
| 컴포넌트 내부 스타일 | scoped CSS |
| 페이지별 특별 스타일 | 해당 페이지 컴포넌트 |

처음에는 전역 CSS와 scoped CSS만 잘 나누어도 충분하다.

---

## CSS 변수

색상, 간격, 폰트 크기 같은 값을 CSS 변수로 관리할 수 있다.

```css
:root {
  --color-primary: #2563eb;
  --color-danger: #dc2626;
  --space-3: 12px;
  --space-4: 16px;
}
```

사용:

```css
.button {
  padding: var(--space-3) var(--space-4);
  background: var(--color-primary);
}
```

작은 디자인 시스템을 만들 때 유용하다.

---

## class 바인딩과 함께 사용

Vue에서는 상태에 따라 class를 바꾸는 일이 많다.

```vue
<button class="button" :class="{ active: isActive }">
  선택
</button>
```

```css
.button {
  background: white;
}

.button.active {
  background: #2563eb;
  color: white;
}
```

동적인 스타일도 가능하면 inline style보다 class로 표현하는 것이 유지보수하기 쉽다.

---

## CSS Modules

CSS Modules는 class 이름 충돌을 더 강하게 막는 방식이다.

```vue
<template>
  <button :class="$style.button">저장</button>
</template>

<style module>
.button {
  color: white;
  background: #2563eb;
}
</style>
```

초보자는 scoped CSS부터 익히고, 프로젝트에서 필요할 때 CSS Modules를 도입해도 된다.

---

## Sass

Sass를 사용하면 변수, 중첩, mixin 같은 기능을 쓸 수 있다.

```bash
npm install -D sass
```

```vue
<style scoped lang="scss">
.card {
  padding: 16px;

  &__title {
    font-weight: 700;
  }
}
</style>
```

요즘은 CSS 자체 기능도 좋아졌기 때문에 Sass가 반드시 필요한 것은 아니다. 팀 스타일에 따라 선택한다.

---

## Tailwind CSS

Tailwind CSS는 유틸리티 class로 스타일을 작성하는 도구다.

```vue
<button class="rounded bg-blue-600 px-4 py-2 text-white">
  저장
</button>
```

장점:

- 빠르게 UI를 만들 수 있다.
- 디자인 토큰을 설정으로 관리할 수 있다.
- class 이름을 새로 짓는 부담이 줄어든다.

주의점:

- HTML이 길어질 수 있다.
- 팀이 Tailwind 방식에 익숙해야 한다.

---

## UI 라이브러리

실무에서는 UI 라이브러리를 사용할 수도 있다.

예:

- Vuetify
- Element Plus
- Naive UI
- PrimeVue
- Quasar

UI 라이브러리는 버튼, 모달, 테이블, 폼 같은 컴포넌트를 제공한다. 관리자 페이지처럼 빠르게 기능을 만들어야 하는 프로젝트에 유용하다.

하지만 디자인 자유도가 필요하거나 번들 크기, 커스터마이징 요구가 크다면 신중히 선택해야 한다.

---

## 선택 기준

| 프로젝트 상황 | 추천 |
| --- | --- |
| 학습용 작은 앱 | 전역 CSS + scoped CSS |
| 브랜드 디자인이 중요한 앱 | 직접 CSS 또는 Sass |
| 빠른 개발이 필요한 관리자 페이지 | UI 라이브러리 |
| 유틸리티 기반 팀 문화 | Tailwind CSS |
| class 충돌을 강하게 막고 싶음 | CSS Modules |

처음 Vue를 배우는 단계에서는 전역 CSS와 scoped CSS를 기본으로 시작하는 것이 가장 좋다.

---

## 자주 하는 실수

### 모든 스타일을 전역 CSS에 넣음

컴포넌트별 스타일은 해당 `.vue` 파일의 scoped CSS로 두면 관리하기 쉽다.

### 모든 값을 inline style로 처리함

상태에 따른 시각적 변화는 class 바인딩으로 처리하는 것이 좋다.

### UI 라이브러리부터 도입함

학습 초반에는 Vue의 기본 컴포넌트 구조와 CSS 흐름을 먼저 익히자.

## 이번 장 요약

- Vue는 스타일링 방식을 강제하지 않는다.
- 초보자는 전역 CSS와 scoped CSS부터 익히는 것이 좋다.
- CSS 변수로 색상과 간격을 관리할 수 있다.
- 동적 스타일은 class 바인딩으로 처리하면 유지보수하기 쉽다.
- Tailwind CSS와 UI 라이브러리는 프로젝트 성격에 따라 선택한다.
