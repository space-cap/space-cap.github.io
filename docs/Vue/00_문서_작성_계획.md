# Vue.js 초보자 학습 문서 작성 계획서

> 작성 기준일: 2026-05-20  
> 목표: Vue.js를 처음 배우는 사람이 웹 기초에서 출발해 Vue 애플리케이션 제작, 상태 관리, 라우팅, 테스트, 배포까지 단계적으로 익힐 수 있는 문서 묶음을 만든다.

---

## 1. 문서 작성 방향

이 문서는 한 파일에 모든 내용을 몰아넣지 않고, 책의 장과 절처럼 작은 문서로 나누어 작성한다. 각 장은 독립적으로 읽을 수 있어야 하며, 앞 장의 개념을 자연스럽게 이어받아 다음 장의 실습으로 연결되도록 구성한다.

초보자를 위한 설명을 우선한다. 전문 용어는 처음 등장할 때 쉬운 말로 풀어 쓰고, 코드 예제는 짧게 시작한 뒤 점진적으로 확장한다. 단순한 문법 설명에 그치지 않고 "왜 이 기능이 필요한가", "언제 사용하면 좋은가", "초보자가 자주 실수하는 부분은 무엇인가"를 함께 정리한다.

공식 문서는 Vue 3 기준으로 작성한다. Vue 2는 유지보수 종료 상태이므로 별도 마이그레이션 장에서만 다룬다. 새 프로젝트 생성은 Vue 공식 Quick Start에서 권장하는 `npm create vue@latest`와 Vite 기반 흐름을 기본으로 삼는다.

---

## 2. 예상 독자

- HTML, CSS, JavaScript를 조금 배웠지만 프레임워크는 처음인 사람
- jQuery나 정적 HTML 위주로 작업하다가 Vue로 넘어오려는 사람
- Vue 프로젝트 구조, 컴포넌트, 라우팅, 상태 관리, 배포까지 전체 흐름을 알고 싶은 사람
- 실무 Vue 코드를 읽고 수정할 수 있는 수준까지 성장하고 싶은 사람

---

## 3. 학습 목표

문서 전체를 따라가면 독자는 다음을 할 수 있어야 한다.

- Vue가 왜 만들어졌고 어떤 문제를 해결하는지 설명할 수 있다.
- CDN 방식과 Vite 프로젝트 방식의 차이를 이해한다.
- `createApp`, 템플릿 문법, 반응성, 이벤트, 조건부 렌더링, 리스트 렌더링을 사용할 수 있다.
- `.vue` 단일 파일 컴포넌트 구조를 이해하고 컴포넌트를 나눌 수 있다.
- Props, Emit, Slot, Provide/Inject를 활용해 컴포넌트 사이 데이터를 주고받을 수 있다.
- Composition API와 Options API의 차이를 알고, 초보자 관점에서 적절히 선택할 수 있다.
- Vue Router로 페이지를 나누고, Pinia로 상태를 관리할 수 있다.
- API 통신, 폼 처리, 에러 처리, 로딩 상태를 구현할 수 있다.
- 테스트, 접근성, 성능, 보안, 배포의 기본 원칙을 이해한다.
- 작은 Vue 프로젝트를 처음부터 끝까지 완성할 수 있다.

## 5. 각 문서의 기본 형식

각 장은 다음 형식을 기본으로 작성한다.

```md
# 장 제목

## 이번 장에서 배울 것

## 왜 필요한가

## 핵심 개념

## 예제 코드

## 자주 하는 실수

## 작은 실습

## 정리

## 다음 장으로
```

필요한 경우 `심화`, `실무 팁`, `체크리스트`, `용어 정리` 섹션을 추가한다.

## 8. 문서 작성 원칙

- 한 문서에는 하나의 핵심 주제만 담는다.
- 처음 등장하는 용어는 반드시 쉬운 말로 설명한다.
- 예제는 복사해서 실행 가능한 형태로 작성한다.
- Composition API와 `<script setup>`을 기본 흐름으로 사용하되, Options API도 비교 설명한다.
- Vue CLI는 유지보수 모드이므로 새 프로젝트의 기본 설치 방법으로 다루지 않고, 기존 프로젝트 이해용으로만 짧게 설명한다.
- Vue 2 관련 내용은 초보자용 본문에 섞지 않고, 마이그레이션 장에서 따로 다룬다.
- 각 장 마지막에는 "이번 장 요약"과 "다음 장에서 할 일"을 넣는다.

## 10. 완료 기준

이 문서 묶음은 다음 조건을 만족하면 1차 완성으로 본다.

- 초보자가 `01`번부터 순서대로 읽으며 Vue 앱을 직접 실행할 수 있다.
- 각 핵심 문법마다 최소 하나 이상의 실행 가능한 예제가 있다.
- 실습 프로젝트가 최소 3개 이상 포함되어 있다.
- Vue Router, Pinia, API 통신, 테스트, 배포가 각각 별도 문서로 정리되어 있다.
- Vue 2와 Vue 3의 차이, Vue CLI와 create-vue/Vite의 차이가 혼동되지 않게 설명되어 있다.
- 마지막 문서에서 다음 학습 방향을 제시한다.
