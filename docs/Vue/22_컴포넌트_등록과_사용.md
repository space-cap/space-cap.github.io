# 컴포넌트 등록과 사용

## 이번 장에서 배울 것

컴포넌트를 만들었다면 다른 컴포넌트에서 가져와 사용해야 한다. Vue에서는 컴포넌트를 지역 등록 또는 전역 등록 방식으로 사용할 수 있다.

이 문서에서는 초보자에게 가장 중요한 지역 등록을 중심으로 설명한다.

---

## 지역 등록

`<script setup>`을 사용하는 SFC에서는 컴포넌트를 import하면 템플릿에서 바로 사용할 수 있다.

`src/components/AppButton.vue`

```vue
<template>
  <button class="button">
    <slot>버튼</slot>
  </button>
</template>
```

`src/App.vue`

```vue
<script setup>
import AppButton from './components/AppButton.vue'
</script>

<template>
  <AppButton>저장</AppButton>
</template>
```

`AppButton`은 `App.vue` 안에서만 사용할 수 있다. 다른 컴포넌트에서 쓰려면 그 파일에서도 import해야 한다.

---

## 컴포넌트 이름 규칙

Vue SFC에서는 컴포넌트 이름에 PascalCase를 권장한다.

```text
AppButton
UserProfile
TodoItem
```

템플릿에서도 PascalCase로 쓰면 일반 HTML 태그와 구분하기 쉽다.

```html
<UserProfile />
```

---

## 폴더 구조 예시

작은 프로젝트에서는 아래 정도면 충분하다.

```text
src/
├─ App.vue
└─ components/
   ├─ AppHeader.vue
   ├─ AppButton.vue
   └─ TodoItem.vue
```

프로젝트가 커지면 기능별 폴더를 만들 수도 있다.

```text
src/
└─ components/
   ├─ common/
   │  └─ BaseButton.vue
   └─ todo/
      ├─ TodoList.vue
      └─ TodoItem.vue
```

처음부터 복잡하게 나누기보다, 컴포넌트가 많아질 때 정리해도 된다.

---

## 전역 등록

전역 등록은 한 번 등록한 컴포넌트를 앱 어디에서나 사용할 수 있게 하는 방식이다.

`src/main.js`

```js
import { createApp } from 'vue'
import App from './App.vue'
import BaseButton from './components/BaseButton.vue'

const app = createApp(App)

app.component('BaseButton', BaseButton)

app.mount('#app')
```

이제 모든 컴포넌트에서 `<BaseButton />`을 사용할 수 있다.

---

## 지역 등록과 전역 등록 비교

| 구분 | 지역 등록 | 전역 등록 |
| --- | --- | --- |
| 사용 범위 | import한 컴포넌트 안 | 앱 전체 |
| 의존성 파악 | 쉽다 | 많아지면 어렵다 |
| 초보자 추천 | 기본 선택 | 공통 UI에 제한적으로 |
| 예 | `TodoItem`, `UserProfile` | `BaseButton`, `BaseIcon` |

초보자는 지역 등록을 기본으로 사용하자. 전역 등록은 정말 자주 쓰는 공통 컴포넌트에만 제한적으로 사용하면 된다.

---

## 부모와 자식 컴포넌트

컴포넌트를 import해서 사용하는 쪽을 부모 컴포넌트, 사용되는 쪽을 자식 컴포넌트라고 부른다.

```text
App.vue
└─ TodoList.vue
   └─ TodoItem.vue
```

여기서 `App.vue`는 `TodoList.vue`의 부모이고, `TodoList.vue`는 `TodoItem.vue`의 부모다.

부모가 자식에게 데이터를 줄 때는 Props를 사용하고, 자식이 부모에게 사건을 알릴 때는 Emit을 사용한다.

---

## 자주 하는 실수

### import 경로를 잘못 씀

```js
import TodoItem from './TodoItem.vue'
```

파일이 `src/components/TodoItem.vue`에 있다면 `App.vue`에서는 보통 이렇게 써야 한다.

```js
import TodoItem from './components/TodoItem.vue'
```

### 컴포넌트 파일명과 import 이름이 헷갈림

파일명과 import 이름을 맞추면 읽기 쉽다.

```js
import UserProfile from './components/UserProfile.vue'
```

### 모든 컴포넌트를 전역 등록함

전역 등록은 편하지만 많아질수록 어디서 온 컴포넌트인지 찾기 어렵다. 기본은 지역 등록이다.

---

## 작은 실습

다음 컴포넌트를 만들어보자.

- `src/components/AppHeader.vue`
- `src/components/AppFooter.vue`

그리고 `App.vue`에서 두 컴포넌트를 import해 사용해보자.

```vue
<script setup>
import AppHeader from './components/AppHeader.vue'
import AppFooter from './components/AppFooter.vue'
</script>

<template>
  <AppHeader />
  <main>본문</main>
  <AppFooter />
</template>
```

---

## 이번 장 요약

- `<script setup>`에서는 import한 컴포넌트를 템플릿에서 바로 사용할 수 있다.
- 컴포넌트 이름은 PascalCase를 권장한다.
- 기본은 지역 등록이다.
- 전역 등록은 공통 컴포넌트에 제한적으로 사용한다.
