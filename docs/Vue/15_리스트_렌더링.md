# 리스트 렌더링

## 이번 장에서 배울 것

리스트 렌더링은 배열 데이터를 반복해서 화면에 출력하는 기능이다. 게시글 목록, 상품 목록, Todo 목록, 메뉴 등에서 거의 항상 사용한다.

Vue에서는 `v-for`를 사용한다.

---

## v-for 기본

```vue
<script setup>
import { ref } from 'vue'

const fruits = ref(['사과', '바나나', '포도'])
</script>

<template>
  <ul>
    <li v-for="fruit in fruits" :key="fruit">
      {{ fruit }}
    </li>
  </ul>
</template>
```

`fruit in fruits`는 `fruits` 배열에서 하나씩 꺼내 `fruit`라는 이름으로 사용한다는 뜻이다.

---

## 객체 배열 렌더링

실무에서는 문자열 배열보다 객체 배열을 더 많이 사용한다.

```vue
<script setup>
import { ref } from 'vue'

const posts = ref([
  { id: 1, title: 'Vue 시작하기', author: 'Kim' },
  { id: 2, title: '컴포넌트 이해하기', author: 'Lee' }
])
</script>

<template>
  <article v-for="post in posts" :key="post.id">
    <h2>{{ post.title }}</h2>
    <p>작성자: {{ post.author }}</p>
  </article>
</template>
```

---

## index 사용하기

두 번째 값으로 index를 받을 수 있다.

```html
<li v-for="(fruit, index) in fruits" :key="fruit">
  {{ index + 1 }}. {{ fruit }}
</li>
```

index는 0부터 시작하므로 화면에 번호로 표시할 때는 `index + 1`을 자주 사용한다.

---

## key가 중요한 이유

`v-for`를 사용할 때는 `:key`를 함께 쓰는 습관을 들이자.

```html
<li v-for="todo in todos" :key="todo.id">
  {{ todo.title }}
</li>
```

`key`는 Vue가 각 항목을 구분할 수 있게 도와준다. 항목이 추가, 삭제, 정렬될 때 화면을 안정적으로 갱신하는 데 필요하다.

가능하면 데이터의 고유 id를 사용한다.

```html
:key="todo.id"
```

## 목록 추가하기

```vue
<script setup>
import { ref } from 'vue'

const newTodo = ref('')
const todos = ref([])

function addTodo() {
  if (!newTodo.value.trim()) {
    return
  }

  todos.value.push({
    id: Date.now(),
    title: newTodo.value
  })

  newTodo.value = ''
}
</script>

<template>
  <form @submit.prevent="addTodo">
    <input v-model="newTodo">
    <button type="submit">추가</button>
  </form>

  <ul>
    <li v-for="todo in todos" :key="todo.id">
      {{ todo.title }}
    </li>
  </ul>
</template>
```

## 목록 삭제하기

`filter`를 사용해 삭제할 항목을 제외한 새 배열을 만든다.

```js
function removeTodo(id) {
  todos.value = todos.value.filter((todo) => todo.id !== id)
}
```

템플릿:

```html
<li v-for="todo in todos" :key="todo.id">
  {{ todo.title }}
  <button @click="removeTodo(todo.id)">삭제</button>
</li>
```

## 목록 필터링하기

목록을 필터링할 때는 `computed`를 사용하면 좋다.

```vue
<script setup>
import { computed, ref } from 'vue'

const keyword = ref('')
const posts = ref([
  { id: 1, title: 'Vue 시작하기' },
  { id: 2, title: 'React와 비교하기' },
  { id: 3, title: 'Vue Router 배우기' }
])

const filteredPosts = computed(() => {
  return posts.value.filter((post) =>
    post.title.includes(keyword.value)
  )
})
</script>

<template>
  <input v-model="keyword" placeholder="검색">

  <ul>
    <li v-for="post in filteredPosts" :key="post.id">
      {{ post.title }}
    </li>
  </ul>
</template>
```

## 객체 반복하기

객체의 속성을 반복할 수도 있다.

```vue
<script setup>
const user = {
  name: 'Kim',
  age: 20,
  job: 'Developer'
}
</script>

<template>
  <ul>
    <li v-for="(value, key) in user" :key="key">
      {{ key }}: {{ value }}
    </li>
  </ul>
</template>
```

다만 화면 목록은 배열로 다루는 경우가 더 많다.

---

## 자주 하는 실수

### key를 index로만 사용함

```html
<li v-for="(todo, index) in todos" :key="index">
```

항목이 추가, 삭제, 정렬될 수 있다면 index보다 고유 id를 사용하는 것이 좋다.

### v-if와 v-for를 같은 요소에 함께 사용함

목록을 조건에 따라 걸러야 한다면 `computed`로 필터링된 배열을 만든다.

```js
const activeTodos = computed(() => {
  return todos.value.filter((todo) => !todo.done)
})
```

### 배열을 직접 바꾸고도 ref의 .value를 잊음

```js
todos.value = todos.value.filter((todo) => todo.id !== id)
```

`ref` 배열은 JavaScript에서 `.value`를 통해 접근한다.

## 작은 실습

상품 목록을 만들어보자.

- 상품은 `id`, `name`, `price`를 가진 객체 배열이다.
- `v-for`로 상품 이름과 가격을 출력한다.
- 삭제 버튼을 누르면 해당 상품이 사라진다.
- 상품이 하나도 없으면 "상품이 없습니다."를 보여준다.

---

## 이번 장 요약

- `v-for`는 배열을 반복해서 화면에 출력한다.
- 객체 배열은 `item.id` 같은 고유값을 `key`로 사용한다.
- 항목 삭제에는 `filter`를 자주 사용한다.
- 필터링된 목록은 `computed`로 만드는 것이 좋다.
