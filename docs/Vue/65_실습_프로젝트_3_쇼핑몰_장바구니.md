# 실습 프로젝트 3: 쇼핑몰 장바구니

## 이번 프로젝트에서 만들 것

세 번째 실습 프로젝트는 쇼핑몰 장바구니다. 이 프로젝트는 Pinia 상태 관리, computed, 컴포넌트 설계, 수량 변경, 총액 계산을 연습하기 좋다.

---

## 학습 목표

이 프로젝트를 마치면 다음을 할 수 있어야 한다.

- Pinia store를 만든다.
- 여러 컴포넌트에서 같은 store를 사용한다.
- 상품 목록에서 장바구니에 상품을 추가한다.
- 장바구니 수량을 변경한다.
- 총 개수와 총 가격을 계산한다.
- store 상태를 localStorage에 저장한다.

---

## 완성 기능

- 상품 목록
- 장바구니 추가

- 총 상품 개수 표시

## Cart Store 만들기

`src/stores/cart.js`

```js
import { computed, ref, watch } from 'vue'
import { defineStore } from 'pinia'

export const useCartStore = defineStore('cart', () => {
  const savedItems = localStorage.getItem('cart-items')
  const items = ref(savedItems ? JSON.parse(savedItems) : [])

  const totalCount = computed(() => {
    return items.value.reduce((sum, item) => sum + item.quantity, 0)
  })

  const totalPrice = computed(() => {
    return items.value.reduce(
      (sum, item) => sum + item.price * item.quantity,
      0
    )
  })

  function addItem(product) {
    const found = items.value.find((item) => item.id === product.id)

    if (found) {
      found.quantity++
      return
    }

    items.value.push({
      id: product.id,
      name: product.name,
      price: product.price,
      quantity: 1
    })
  }

  function increase(id) {
    const item = items.value.find((cartItem) => cartItem.id === id)
    if (item) {
      item.quantity++
    }
  }

  function decrease(id) {
    const item = items.value.find((cartItem) => cartItem.id === id)

    if (!item) {
      return
    }

    if (item.quantity <= 1) {
      removeItem(id)
      return
    }

    item.quantity--
  }

  function removeItem(id) {
    items.value = items.value.filter((item) => item.id !== id)
  }

  function clearCart() {
    items.value = []
  }

  watch(
    items,
    (newItems) => {
      localStorage.setItem('cart-items', JSON.stringify(newItems))
    },
    { deep: true }
  )

  return {
    items,
    totalCount,
    totalPrice,
    addItem,
    increase,
    decrease,
    removeItem,
    clearCart
  }
})
```

## 상품 카드 컴포넌트

`ProductCard.vue`

```vue
<script setup>
import { formatPrice } from '../utils/format'

defineProps({
  product: {
    type: Object,
    required: true
  }
})

const emit = defineEmits(['add-cart'])
</script>

<template>
  <article class="product-card">
    <h2>{{ product.name }}</h2>
    <p>{{ formatPrice(product.price) }}</p>
    <p>재고: {{ product.stock }}</p>
    <button
      type="button"
      :disabled="product.stock === 0"
      @click="emit('add-cart', product)"
    >
      장바구니 담기
    </button>
  </article>
</template>
```

## 상품 목록 화면

```vue
<script setup>
import ProductCard from '../components/ProductCard.vue'
import { products } from '../data/products'
import { useCartStore } from '../stores/cart'

const cart = useCartStore()
</script>

<template>
  <main>
    <h1>상품 목록</h1>

    <p>장바구니: {{ cart.totalCount }}개</p>

    <section>
      <ProductCard
        v-for="product in products"
        :key="product.id"
        :product="product"
        @add-cart="cart.addItem"
      />
    </section>
  </main>
</template>
```

```vue
import { formatPrice } from '../utils/format'

defineProps({

    type: Object,

<template>
  <li>
    <strong>{{ item.name }}</strong>
    <span>{{ formatPrice(item.price) }}</span>
    <span>{{ item.quantity }}개</span>

    <button @click="emit('decrease', item.id)">-</button>
    <button @click="emit('increase', item.id)">+</button>
    <button @click="emit('remove', item.id)">삭제</button>
  </li>
</template>
```

## 장바구니 화면

```vue
<script setup>
import CartItem from '../components/CartItem.vue'
import { useCartStore } from '../stores/cart'
import { formatPrice } from '../utils/format'

const cart = useCartStore()
</script>

<template>
  <main>
    <h1>장바구니</h1>

    <p v-if="cart.items.length === 0">장바구니가 비어 있습니다.</p>

    <template v-else>
      <ul>
        <CartItem
          v-for="item in cart.items"
          :key="item.id"
          :item="item"
          @increase="cart.increase"
          @decrease="cart.decrease"
          @remove="cart.removeItem"
        />
      </ul>

      <p>총 개수: {{ cart.totalCount }}개</p>
      <p>총 금액: {{ formatPrice(cart.totalPrice) }}</p>

      <button @click="cart.clearCart">장바구니 비우기</button>
    </template>
  </main>
</template>
```

## 확장 과제

---

## 점검 체크리스트

- 여러 컴포넌트에서 같은 장바구니 상태를 본다.
- 상품을 추가하면 총 개수가 증가한다.
- 수량 감소 시 0이 되면 상품이 제거된다.
- 새로고침해도 장바구니가 유지된다.
- 총 금액이 정확하게 계산된다.
- 지역 상태와 전역 상태가 적절히 나뉘어 있다.
