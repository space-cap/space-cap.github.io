# 커스텀 디렉티브

## 이번 장에서 배울 것

Vue에는 `v-if`, `v-for`, `v-model`, `v-show` 같은 기본 디렉티브가 있다. 커스텀 디렉티브는 개발자가 직접 만드는 `v-` 문법이다.

커스텀 디렉티브는 주로 **일반 DOM 요소에 직접 접근해야 하는 로직**을 재사용할 때 사용한다.

---

## 언제 사용할까?

Vue에서는 가능한 한 상태와 템플릿으로 화면을 표현하는 것이 좋다. 커스텀 디렉티브는 다음처럼 DOM 직접 조작이 자연스러운 경우에 사용한다.

- 입력 칸 자동 포커스
- 요소 외부 클릭 감지
- 특정 요소에 스크롤 동작 적용
- DOM 기반 외부 라이브러리 연결
- 간단한 강조 효과 적용

일반적인 화면 구성은 컴포넌트와 Props, Slot으로 해결하는 것이 더 좋다.

---

## 첫 커스텀 디렉티브: v-focus

`<script setup>`에서는 `v`로 시작하는 camelCase 변수를 만들면 템플릿에서 디렉티브로 사용할 수 있다.

```vue
<script setup>
const vFocus = {
  mounted(el) {
    el.focus()
  }
}
</script>

<template>
  <input v-focus placeholder="자동 포커스">
</template>
```

`vFocus`는 템플릿에서 `v-focus`로 사용한다.

---

## 디렉티브 훅

커스텀 디렉티브는 컴포넌트 생명주기와 비슷한 훅을 가질 수 있다.

```js
const vExample = {
  created(el, binding) {},
  beforeMount(el, binding) {},
  mounted(el, binding) {},
  beforeUpdate(el, binding) {},
  updated(el, binding) {},
  beforeUnmount(el, binding) {},
  unmounted(el, binding) {}
}
```

자주 쓰는 것은 `mounted`, `updated`, `unmounted`다.

| 훅 | 실행 시점 |
| --- | --- |
| `mounted` | 요소가 DOM에 붙은 뒤 |
| `updated` | 바인딩 값이나 컴포넌트 업데이트 뒤 |
| `unmounted` | 요소가 사라진 뒤 |

---

## binding.value 사용하기

디렉티브에 값을 전달할 수 있다.

```vue
<script setup>
const vColor = {
  mounted(el, binding) {
    el.style.color = binding.value
  },
  updated(el, binding) {
    el.style.color = binding.value
  }
}
</script>

<template>
  <p v-color="'blue'">파란 글자</p>
</template>
```

`binding.value`에는 디렉티브에 전달한 값이 들어간다.

---

## 함수 축약형

`mounted`와 `updated`에서 같은 일을 한다면 함수로 짧게 쓸 수 있다.

```vue
<script setup>
const vColor = (el, binding) => {
  el.style.color = binding.value
}
</script>

<template>
  <p v-color="'red'">빨간 글자</p>
</template>
```

이 함수는 요소가 붙을 때와 업데이트될 때 모두 호출된다.

---

## 전역 디렉티브 등록

여러 컴포넌트에서 사용할 디렉티브라면 앱 전체에 등록할 수 있다.

`src/main.js`

```js
import { createApp } from 'vue'
import App from './App.vue'

const app = createApp(App)

app.directive('focus', {
  mounted(el) {
    el.focus()
  }
})

app.mount('#app')
```

이제 모든 컴포넌트에서 사용할 수 있다.

```html
<input v-focus>
```

## 커스텀 디렉티브와 컴포넌트

커스텀 디렉티브는 일반 HTML 요소에 사용하는 것이 좋다.

```html
<input v-focus>
```

컴포넌트에 직접 붙이면 루트 요소에 적용되는데, 루트 요소가 여러 개인 컴포넌트에서는 예상과 다를 수 있다.

```html
<!-- 권장하지 않음 -->
<MyInput v-focus />
```

컴포넌트 내부 DOM을 제어해야 한다면 컴포넌트 자체에서 처리하거나 Props로 옵션을 받는 편이 명확하다.

---

## Composable과 커스텀 디렉티브 차이

| 구분 | Composable | 커스텀 디렉티브 |
| --- | --- | --- |
| 목적 | 상태 로직 재사용 | DOM 조작 재사용 |
| 사용 위치 | `<script setup>` | `<template>` |
| 예 | `useMouse()` | `v-focus` |
| 추천 상황 | 데이터와 상태 중심 | 요소 직접 조작 중심 |

DOM 조작이 아니라 상태 로직이라면 Composable이 더 적합하다.

---

## 자주 하는 실수

### 상태 표현을 디렉티브로 해결하려 함

class 변경, 조건부 표시, 리스트 출력은 기본 디렉티브와 바인딩으로 처리한다.

```html
<p :class="{ active: isActive }"></p>
```

### unmounted에서 정리하지 않음

이벤트 리스너를 직접 붙였다면 `unmounted`에서 제거해야 한다.

### 컴포넌트에 디렉티브를 붙여 내부 input에 적용되길 기대함

디렉티브는 컴포넌트 내부의 원하는 요소까지 자동으로 들어가지 않는다.

---

## 작은 실습

`v-focus` 디렉티브를 전역으로 등록해보자.

요구사항:

- `main.js`에서 `app.directive('focus', ...)` 등록
- `App.vue`의 input에 `v-focus` 적용
- 페이지가 열리면 input에 자동 포커스가 들어오는지 확인

---

## 이번 장 요약

- 커스텀 디렉티브는 직접 만드는 `v-` 문법이다.
- DOM 직접 조작이 필요한 경우에만 사용하는 것이 좋다.
- `<script setup>`에서는 `vFocus`를 `v-focus`로 사용할 수 있다.
- 전역 등록은 `app.directive()`로 한다.
- 상태 로직 재사용은 Composable, DOM 조작 재사용은 커스텀 디렉티브가 어울린다.
