# 비동기 컴포넌트

## 이번 장에서 배울 것

비동기 컴포넌트는 컴포넌트를 처음부터 모두 불러오지 않고, 필요할 때 나중에 불러오는 기능이다.

큰 화면, 모달, 차트, 에디터처럼 무거운 컴포넌트를 지연 로딩할 때 유용하다.

---

## 왜 필요할까?

작은 앱에서는 모든 컴포넌트를 한 번에 불러와도 문제가 거의 없다. 하지만 앱이 커지면 처음 로딩할 JavaScript 양이 많아진다.

비동기 컴포넌트를 사용하면 특정 컴포넌트를 별도 파일로 나누고, 실제로 필요해지는 시점에 가져올 수 있다.

예:

- 관리자 차트 화면
- 설정 모달
- Markdown 에디터
- 지도 컴포넌트
- 드물게 열리는 도움말 패널

---

## defineAsyncComponent 기본

Vue에서는 `defineAsyncComponent`를 사용한다.

```vue
<script setup>
import { defineAsyncComponent } from 'vue'

const HeavyChart = defineAsyncComponent(() =>
  import('./components/HeavyChart.vue')
)
</script>

<template>
  <HeavyChart />
</template>
```

`HeavyChart.vue`는 필요할 때 동적으로 import된다.

---

## 조건부 렌더링과 함께 사용하기

비동기 컴포넌트는 `v-if`와 함께 쓰면 더 효과가 분명하다.

```vue
<script setup>
import { defineAsyncComponent, ref } from 'vue'

const showChart = ref(false)

const HeavyChart = defineAsyncComponent(() =>
  import('./components/HeavyChart.vue')
)
</script>

<template>
  <button @click="showChart = true">차트 보기</button>

  <HeavyChart v-if="showChart" />
</template>
```

사용자가 버튼을 눌러 차트를 볼 때 컴포넌트를 불러온다.

---

## 로딩 컴포넌트와 에러 컴포넌트

조금 더 자세한 옵션을 줄 수 있다.

```vue
<script setup>
import { defineAsyncComponent } from 'vue'
import LoadingBox from './components/LoadingBox.vue'
import ErrorBox from './components/ErrorBox.vue'

const AsyncPanel = defineAsyncComponent({
  loader: () => import('./components/SettingsPanel.vue'),
  loadingComponent: LoadingBox,
  errorComponent: ErrorBox,
  delay: 200,
  timeout: 3000
})
</script>

<template>
  <AsyncPanel />
</template>
```

| 옵션 | 의미 |
| --- | --- |
| `loader` | 실제 컴포넌트를 import하는 함수 |
| `loadingComponent` | 로딩 중 보여줄 컴포넌트 |
| `errorComponent` | 불러오기 실패 시 보여줄 컴포넌트 |
| `delay` | 로딩 표시 전 대기 시간 |
| `timeout` | 제한 시간 |

---

## 라우터와 코드 분할

Vue Router를 사용할 때도 비슷한 방식으로 페이지 컴포넌트를 지연 로딩할 수 있다.

```js
const routes = [
  {
    path: '/admin',
    component: () => import('./pages/AdminPage.vue')
  }
]
```

이 내용은 Vue Router 장에서 더 자세히 다룬다.

---

## 언제 사용하면 좋을까?

| 상황 | 추천 |
| --- | --- |
| 앱 처음부터 꼭 필요한 컴포넌트 | 일반 import |
| 가끔 열리는 모달 | 비동기 컴포넌트 고려 |
| 무거운 차트/에디터/지도 | 비동기 컴포넌트 추천 |
| 라우트별 페이지 | 라우터 지연 로딩 추천 |

모든 컴포넌트를 비동기로 만들 필요는 없다. 처음 화면에 꼭 필요한 컴포넌트는 일반 import가 더 단순하다.

---

## Suspense와의 관계

Vue에는 비동기 의존성을 다룰 수 있는 `Suspense`도 있다. 비동기 컴포넌트와 함께 사용할 수 있지만, 초보 단계에서는 먼저 `defineAsyncComponent`의 기본 사용법을 익히면 충분하다.

`Suspense`는 내장 컴포넌트 장에서 다시 다룬다.

---

## 자주 하는 실수

### 작은 컴포넌트까지 모두 비동기로 만듦

비동기 컴포넌트는 로딩 경계와 코드 분할이 필요한 경우에 사용한다. 작은 버튼이나 카드까지 모두 비동기로 만들면 코드가 복잡해질 수 있다.

### import 경로를 잘못 작성함

동적 import도 경로가 정확해야 한다.

```js
import('./components/SettingsPanel.vue')
```

### 로딩 상태를 고려하지 않음

네트워크나 번들 로딩 시간이 있을 수 있다. 무거운 컴포넌트라면 로딩 UI를 준비하는 것이 좋다.

---

## 작은 실습

`HelpPanel.vue`을 만든 뒤 버튼을 눌렀을 때만 불러오도록 만들어보자.

```vue
<script setup>
import { defineAsyncComponent, ref } from 'vue'

const showHelp = ref(false)
const HelpPanel = defineAsyncComponent(() =>
  import('./components/HelpPanel.vue')
)
</script>

<template>
  <button @click="showHelp = !showHelp">도움말</button>
  <HelpPanel v-if="showHelp" />
</template>
```

---

## 이번 장 요약

- 비동기 컴포넌트는 필요한 시점에 컴포넌트를 불러오는 기능이다.
- `defineAsyncComponent`와 동적 `import()`를 사용한다.
- 무거운 컴포넌트, 드물게 쓰는 화면, 라우트 페이지에 유용하다.
- 모든 컴포넌트를 비동기로 만들 필요는 없다.
