# 이벤트 처리

## 이번 장에서 배울 것

이벤트 처리는 사용자의 행동에 반응하는 기능이다. 버튼 클릭, 폼 제출, 입력, 키보드 입력 같은 동작을 Vue에서 처리하는 방법을 배운다.

---

## v-on과 @

이벤트를 연결할 때는 `v-on`을 사용한다.

```html
<button v-on:click="save">저장</button>
```

짧게 쓰면 `@`다.

```html
<button @click="save">저장</button>
```

실무에서는 `@click`처럼 짧은 문법을 많이 사용한다.

---

## 메서드 연결하기

```vue
<script setup>
import { ref } from 'vue'

const count = ref(0)

function increase() {
  count.value++
}
</script>

<template>
  <p>{{ count }}</p>
  <button @click="increase">증가</button>
</template>
```

버튼을 클릭하면 `increase` 함수가 실행된다.

---

## 인라인 이벤트

짧은 동작은 템플릿에 직접 작성할 수도 있다.

```html
<button @click="count++">증가</button>
```

간단한 예제에서는 편하지만, 로직이 길어지면 함수로 분리하는 것이 좋다.

---

## 인자 전달하기

이벤트 함수에 값을 전달할 수 있다.

```vue
<script setup>
function removeTodo(id) {
  console.log('삭제할 id:', id)
}
</script>

<template>
  <button @click="removeTodo(1)">삭제</button>
</template>
```

목록에서는 다음처럼 자주 사용한다.

```html
<button @click="removeTodo(todo.id)">삭제</button>
```

---

## 이벤트 객체 사용하기

브라우저 이벤트 객체가 필요하면 `$event`를 전달한다.

```vue
<script setup>
function handleClick(event) {
  console.log(event.target)
}
</script>

<template>
  <button @click="handleClick($event)">확인</button>
</template>
```

인자와 이벤트를 함께 전달할 수도 있다.

```html
<button @click="selectItem(item.id, $event)">선택</button>
```

## 이벤트 수식어

Vue는 자주 쓰는 이벤트 처리를 수식어로 제공한다.

### .prevent

폼 제출의 기본 새로고침을 막는다.

```html
<form @submit.prevent="save">
  <button type="submit">저장</button>
</form>
```

### .stop

이벤트가 부모 요소로 전파되는 것을 막는다.

```html
<div @click="open">
  <button @click.stop="deleteItem">삭제</button>
</div>
```

### .once

이벤트를 한 번만 실행한다.

```html
<button @click.once="initialize">한 번만 실행</button>
```

---

## 키 이벤트

키보드 이벤트도 처리할 수 있다.

```html
<input @keyup.enter="search" placeholder="Enter로 검색">
```

자주 쓰는 키 수식어:

| 수식어 | 의미 |
| --- | --- |
| `.enter` | Enter 키 |
| `.esc` | Escape 키 |
| `.tab` | Tab 키 |
| `.delete` | Delete 또는 Backspace |

---

## 폼 제출 예제

```vue
<script setup>
import { ref } from 'vue'

const title = ref('')

function save() {
  if (!title.value.trim()) {
    alert('제목을 입력하세요.')
    return
  }

  alert(`저장: ${title.value}`)
  title.value = ''
}
</script>

<template>
  <form @submit.prevent="save">
    <input v-model="title" placeholder="제목">
    <button type="submit">저장</button>
  </form>
</template>
```

`@submit.prevent` 덕분에 페이지가 새로고침되지 않는다.

---

## 자주 하는 실수

### 함수 이름 뒤에 괄호를 무조건 붙임

인자가 없으면 아래처럼 써도 된다.

```html
<button @click="save">저장</button>
```

인자가 있으면 괄호를 사용한다.

```html
<button @click="removeTodo(todo.id)">삭제</button>
```

### form에서 prevent를 빼먹음

폼 제출 시 화면이 새로고침된다면 `.prevent`를 확인한다.

```html
<form @submit.prevent="save">
```

### 이벤트 함수가 너무 많은 일을 함

이벤트 함수는 사용자 행동에 반응하는 입구다. 복잡한 계산은 별도 함수나 `computed`로 나누면 읽기 좋다.

---

## 작은 실습

아래 기능을 만들어보자.

- 입력 칸에 할 일을 입력한다.
- Enter 키를 누르면 Todo가 추가된다.
- 추가 버튼을 눌러도 Todo가 추가된다.
- 빈 값이면 추가하지 않는다.

힌트:

```html
<input v-model="newTodo" @keyup.enter="addTodo">
<button @click="addTodo">추가</button>
```

---

## 이번 장 요약

- 이벤트는 `v-on` 또는 `@`로 연결한다.
- 간단한 동작은 인라인으로 작성할 수 있다.
- 복잡한 동작은 함수로 분리한다.
- `.prevent`, `.stop`, `.once` 같은 이벤트 수식어가 있다.
- 키 이벤트에는 `.enter` 같은 키 수식어를 사용할 수 있다.
