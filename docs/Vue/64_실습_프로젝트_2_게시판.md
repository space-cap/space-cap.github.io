# 실습 프로젝트 2: 게시판

## 이번 프로젝트에서 만들 것

두 번째 실습 프로젝트는 게시판이다. 게시판은 Vue Router, API 통신, 동적 라우트, 폼 처리, 로딩/에러 상태를 연습하기 좋은 프로젝트다.

---

## 학습 목표

이 프로젝트를 마치면 다음을 할 수 있어야 한다.

- Vue Router로 페이지를 나눈다.
- 게시글 목록과 상세 페이지를 만든다.
- 동적 라우트 `/posts/:id`를 사용한다.
- API 함수를 분리한다.
- 로딩, 에러, 빈 상태를 처리한다.
- 게시글 작성 폼을 만든다.
- 작성 후 상세 페이지 또는 목록으로 이동한다.

---

## 완성 기능

- 게시글 목록

## 라우트 구성

```js
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  {
    path: '/',
    redirect: '/posts'
  },
  {
    path: '/posts',
    name: 'post-list',
    component: () => import('../views/PostListView.vue')
  },
  {
    path: '/posts/new',
    name: 'post-create',
    component: () => import('../views/PostCreateView.vue')
  },
  {
    path: '/posts/:id',
    name: 'post-detail',
    component: () => import('../views/PostDetailView.vue')
  },
  {
    path: '/:pathMatch(.*)*',
    name: 'not-found',
    component: () => import('../views/NotFoundView.vue')
  }
]

export default createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes
})
```

`/posts/new`가 `/posts/:id`보다 앞에 있어야 `new`가 id로 처리되지 않는다.

## API 함수 만들기

실제 서버가 없으면 JSON Server, MSW, 임시 mock 함수 등을 사용할 수 있다. 여기서는 API 함수 형태만 잡는다.

`src/api/posts.js`

```js
const API_BASE_URL = import.meta.env.VITE_API_BASE_URL || ''

export async function fetchPosts(keyword = '') {
  const query = keyword
    ? `?keyword=${encodeURIComponent(keyword)}`
    : ''

  const response = await fetch(`${API_BASE_URL}/posts${query}`)

  if (!response.ok) {
    throw new Error('게시글 목록을 불러오지 못했습니다.')
  }

  return await response.json()
}

export async function fetchPost(id) {
  const response = await fetch(`${API_BASE_URL}/posts/${id}`)

  if (!response.ok) {
    throw new Error('게시글을 불러오지 못했습니다.')
  }

  return await response.json()
}

export async function createPost(post) {
  const response = await fetch(`${API_BASE_URL}/posts`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(post)
  })

  if (!response.ok) {
    throw new Error('게시글 작성에 실패했습니다.')
  }

  return await response.json()
}
```

## 게시글 목록 화면

`PostListView.vue`

```vue
<script setup>
import { onMounted, ref } from 'vue'
import { RouterLink } from 'vue-router'
import { fetchPosts } from '../api/posts'

const posts = ref([])
const loading = ref(false)
const error = ref(null)
const keyword = ref('')

async function loadPosts() {
  loading.value = true
  error.value = null

  try {
    posts.value = await fetchPosts(keyword.value)
  } catch (err) {
    error.value = err
  } finally {
    loading.value = false
  }
}

onMounted(loadPosts)
</script>

<template>
  <main>
    <h1>게시글</h1>

    <form @submit.prevent="loadPosts">
      <input v-model.trim="keyword" placeholder="검색어">
      <button type="submit">검색</button>
    </form>

    <RouterLink to="/posts/new">글쓰기</RouterLink>

    <p v-if="loading">불러오는 중...</p>
    <p v-else-if="error">{{ error.message }}</p>
    <p v-else-if="posts.length === 0">게시글이 없습니다.</p>

    <ul v-else>
      <li v-for="post in posts" :key="post.id">
        <RouterLink :to="`/posts/${post.id}`">
          {{ post.title }}
        </RouterLink>
      </li>
    </ul>
  </main>
</template>
```

## 게시글 상세 화면

```vue
<script setup>
import { onMounted, ref } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { fetchPost } from '../api/posts'

const route = useRoute()
const router = useRouter()

const post = ref(null)
const loading = ref(false)
const error = ref(null)

async function loadPost() {
  loading.value = true
  error.value = null

  try {
    post.value = await fetchPost(route.params.id)
  } catch (err) {
    error.value = err
  } finally {
    loading.value = false
  }
}

onMounted(loadPost)
</script>

<template>
  <main>
    <p v-if="loading">불러오는 중...</p>
    <p v-else-if="error">{{ error.message }}</p>

    <article v-else-if="post">
      <h1>{{ post.title }}</h1>
      <p>{{ post.content }}</p>
      <button @click="router.push('/posts')">목록</button>
    </article>
  </main>
</template>
```

## 게시글 작성 화면

```vue
<script setup>
import { reactive, ref } from 'vue'
import { useRouter } from 'vue-router'
import { createPost } from '../api/posts'

const router = useRouter()

const form = reactive({
  title: '',
  content: ''
})

const error = ref('')
const submitting = ref(false)

function validate() {
  if (!form.title.trim()) {
    error.value = '제목을 입력하세요.'
    return false
  }

  if (!form.content.trim()) {
    error.value = '내용을 입력하세요.'
    return false
  }

  error.value = ''
  return true
}

async function submit() {
  if (!validate()) {
    return
  }

  submitting.value = true

  try {
    const post = await createPost(form)
    router.push(`/posts/${post.id}`)
  } catch (err) {
    error.value = err.message
  } finally {
    submitting.value = false
  }
}
</script>

<template>
  <main>
    <h1>글쓰기</h1>

    <form @submit.prevent="submit">
      <input v-model.trim="form.title" placeholder="제목">
      <textarea v-model.trim="form.content" placeholder="내용"></textarea>
      <p v-if="error">{{ error }}</p>
      <button type="submit" :disabled="submitting">
        {{ submitting ? '저장 중...' : '저장' }}
      </button>
    </form>
  </main>
</template>
```

- 글 작성 시 빈 값 검증이 동작한다.
