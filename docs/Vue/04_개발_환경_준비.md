# 개발 환경 준비

## 이번 장에서 배울 것

이번 장에서는 Vue 프로젝트를 만들고 실행하기 위해 필요한 개발 환경을 준비한다.

필요한 도구는 크게 네 가지다.

- Node.js
- 패키지 매니저
- 코드 편집기
- 브라우저 개발자 도구

---

## Node.js 설치

Vue 프로젝트는 브라우저에서 실행되지만, 프로젝트를 만들고 개발 서버를 실행하려면 Node.js가 필요하다.

Node.js는 JavaScript를 브라우저 밖에서도 실행할 수 있게 해주는 도구다. Vue 프로젝트에서는 다음 작업에 사용된다.

- 프로젝트 생성
- 패키지 설치
- 개발 서버 실행
- 빌드
- 테스트

Node.js는 공식 사이트에서 LTS 버전을 설치하는 것을 권장한다.

공식 사이트:

<https://nodejs.org/>

설치 후 터미널에서 확인한다.

```bash
node -v
npm -v
```

버전 번호가 출력되면 설치가 된 것이다.

---

## npm이란?

`npm`은 Node.js와 함께 설치되는 패키지 매니저다. 패키지 매니저는 필요한 라이브러리를 설치하고 실행 명령을 관리한다.

Vue 프로젝트에서는 다음 명령을 자주 사용한다.

```bash
npm install
npm run dev
npm run build
```

| 명령 | 의미 |
| --- | --- |
| `npm install` | 프로젝트에 필요한 패키지를 설치한다. |
| `npm run dev` | 개발 서버를 실행한다. |
| `npm run build` | 배포용 파일을 만든다. |

처음에는 npm만 사용해도 충분하다. pnpm, yarn, bun 같은 다른 도구는 나중에 필요할 때 배워도 된다.

---

## VS Code 설치

Vue 개발에는 Visual Studio Code를 많이 사용한다.

공식 사이트:

<https://code.visualstudio.com/>

VS Code를 설치했다면 Vue 공식 확장도 설치한다.

확장 이름:

```text
Vue - Official
```

이 확장은 `.vue` 파일의 문법 강조, 자동 완성, 타입 확인 등을 도와준다.

---

## 브라우저 준비

Vue 앱은 브라우저에서 확인한다. Chrome, Edge, Firefox 중 하나를 사용하면 된다.

브라우저 개발자 도구도 자주 사용한다.

| 기능 | 설명 |
| --- | --- |
| Elements | 화면 HTML과 CSS 확인 |
| Console | JavaScript 로그와 에러 확인 |
| Network | API 요청과 응답 확인 |
| Application | localStorage, 쿠키 등 확인 |

개발자 도구는 보통 `F12` 또는 `Ctrl + Shift + I`로 열 수 있다.

---

## Vue DevTools

Vue DevTools는 Vue 앱의 컴포넌트 구조와 상태를 확인할 수 있는 브라우저 확장이다.

초반에는 없어도 실습할 수 있지만, 컴포넌트가 많아지면 매우 유용하다.

확인할 수 있는 것:

- 컴포넌트 트리
- 컴포넌트 Props
- 컴포넌트 상태
- Pinia Store
- 이벤트 흐름

디버깅 장에서 다시 자세히 다룬다.

## 터미널 사용하기

Vue 프로젝트를 만들고 실행하려면 터미널을 사용해야 한다.

Windows에서는 다음 중 하나를 사용할 수 있다.

- PowerShell
- Windows Terminal
- VS Code 터미널

VS Code에서 터미널을 여는 단축키는 보통 다음과 같다.

```text
Ctrl + `
```

터미널에서 현재 폴더를 확인하려면 다음 명령을 사용한다.

```bash
pwd
```

Windows PowerShell에서는 다음 명령도 사용할 수 있다.

```powershell
Get-Location
```

Vue 실습을 위한 폴더를 하나 만든다.


## 자주 발생하는 문제

### node 명령을 찾을 수 없다고 나온다

Node.js가 설치되지 않았거나, 설치 후 터미널을 다시 열지 않았을 가능성이 있다. 설치 후 터미널을 완전히 닫고 다시 열어본다.

### npm install이 오래 걸린다

처음 설치할 때는 여러 패키지를 내려받기 때문에 시간이 걸릴 수 있다. 네트워크 상태에 따라 속도가 달라진다.

### 권한 오류가 나온다

회사 PC나 제한된 환경에서는 권한 문제가 생길 수 있다. 이 경우 관리자 권한 터미널이 필요한지, 사내 보안 정책이 있는지 확인해야 한다.

## 개발 환경 체크리스트

다음 항목을 확인하자.

- `node -v` 명령이 동작한다.
- `npm -v` 명령이 동작한다.
- VS Code가 설치되어 있다.
- VS Code에 `Vue - Official` 확장을 설치했다.
- Chrome 또는 Edge 같은 브라우저가 준비되어 있다.
- 터미널에서 폴더 이동과 명령 실행을 할 수 있다.

## 작은 실습

터미널에서 아래 명령을 실행해보자.

```bash
node -v
npm -v
```

출력 예시는 다음과 비슷하다.

```text
v22.12.0
10.9.0
```

버전 숫자는 환경마다 다를 수 있다. 중요한 것은 명령이 정상적으로 실행되는 것이다.

## 이번 장 요약

- Vue 프로젝트 개발에는 Node.js와 npm이 필요하다.
- 편집기는 VS Code와 `Vue - Official` 확장을 권장한다.
- 브라우저 개발자 도구는 에러 확인과 디버깅에 꼭 필요하다.
- 터미널 사용에 익숙해지면 Vue 프로젝트 실행이 훨씬 쉬워진다.
