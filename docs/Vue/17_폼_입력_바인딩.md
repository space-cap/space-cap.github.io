# 폼 입력 바인딩

## 이번 장에서 배울 것

폼 입력 바인딩은 입력 요소의 값과 Vue 상태를 연결하는 기능이다. Vue에서는 `v-model`을 사용해 input, textarea, checkbox, radio, select를 쉽게 다룰 수 있다.

---

## v-model 기본

```vue
<script setup>
import { ref } from 'vue'

const message = ref('')
</script>

<template>
  <input v-model="message" placeholder="입력하세요">
  <p>입력한 값: {{ message }}</p>
</template>
```

입력 칸에 글자를 쓰면 `message` 값이 바뀌고, 화면의 문장도 함께 바뀐다.

---

## textarea

여러 줄 입력에는 `textarea`를 사용한다.

```vue
<script setup>
import { ref } from 'vue'

const content = ref('')
</script>

<template>
  <textarea v-model="content" placeholder="내용"></textarea>
  <p style="white-space: pre-line">{{ content }}</p>
</template>
```

`textarea` 안에 `{{ content }}`를 넣는 방식은 사용하지 않는다. `v-model`을 사용한다.

---

## checkbox: boolean 값

체크박스 하나는 보통 boolean 값과 연결한다.

```vue
<script setup>
import { ref } from 'vue'

const agreed = ref(false)
</script>

<template>
  <label>
    <input type="checkbox" v-model="agreed">
    약관에 동의합니다.
  </label>

  <p>동의 여부: {{ agreed }}</p>
</template>
```

---

## checkbox: 배열 값

여러 체크박스를 하나의 배열에 연결할 수 있다.

```vue
<script setup>
import { ref } from 'vue'

const selectedSkills = ref([])
</script>

<template>
  <label>
    <input type="checkbox" value="HTML" v-model="selectedSkills">
    HTML
  </label>
  <label>
    <input type="checkbox" value="CSS" v-model="selectedSkills">
    CSS
  </label>
  <label>
    <input type="checkbox" value="Vue" v-model="selectedSkills">
    Vue
  </label>

  <p>선택: {{ selectedSkills }}</p>
</template>
```

체크한 값들이 배열에 들어간다.

---

## radio

라디오는 여러 선택지 중 하나만 고를 때 사용한다.

```vue
<script setup>
import { ref } from 'vue'

const level = ref('beginner')
</script>

<template>
  <label>
    <input type="radio" value="beginner" v-model="level">
    초급
  </label>
  <label>
    <input type="radio" value="intermediate" v-model="level">
    중급
  </label>

  <p>선택한 레벨: {{ level }}</p>
</template>
```

## select

```vue
<script setup>
import { ref } from 'vue'

const category = ref('')
</script>

<template>
  <select v-model="category">
    <option disabled value="">카테고리를 선택하세요</option>
    <option value="frontend">프론트엔드</option>
    <option value="backend">백엔드</option>
    <option value="design">디자인</option>
  </select>

  <p>선택: {{ category }}</p>
</template>
```

초기값이 어떤 option과도 맞지 않으면 선택되지 않은 상태가 될 수 있다. 안내용 disabled option을 두면 사용자가 이해하기 쉽다.

---

## 동적 option

선택지를 배열로 관리할 수 있다.

```vue
<script setup>
import { ref } from 'vue'

const selected = ref('vue')
const options = ref([
  { label: 'Vue', value: 'vue' },
  { label: 'React', value: 'react' },
  { label: 'Svelte', value: 'svelte' }
])
</script>

<template>
  <select v-model="selected">
    <option
      v-for="option in options"
      :key="option.value"
      :value="option.value"
    >
      {{ option.label }}
    </option>
  </select>
</template>
```

## 수식어

`v-model`에는 수식어를 붙일 수 있다.

### .trim

앞뒤 공백을 제거한다.

```html
<input v-model.trim="name">
```

### .number

입력 값을 숫자로 변환하려고 시도한다.

```html
<input v-model.number="age" type="number">
```

### .lazy

입력할 때마다 갱신하지 않고 change 이벤트 시점에 갱신한다.

```html
<input v-model.lazy="message">
```

## 한국어 입력과 v-model

한국어처럼 조합형 입력이 필요한 언어에서는 글자를 조합하는 중간 상태가 있다. 일반적인 폼에서는 `v-model`로 충분하지만, 입력 중간 상태마다 즉시 반응해야 하는 검색 UI라면 `@input`을 직접 사용할 수도 있다.

초보 단계에서는 대부분 `v-model`을 사용하면 된다.

---

## 자주 하는 실수

### textarea에 보간법을 사용함

```html
<!-- 잘못된 예 -->
<textarea>{{ content }}</textarea>
```

```html
<!-- 올바른 예 -->
<textarea v-model="content"></textarea>
```

### checkbox 배열에 value를 빼먹음

여러 체크박스를 배열에 연결할 때는 각 checkbox에 `value`가 있어야 한다.

### 숫자 입력을 문자열로 처리함

`type="number"`를 사용해도 값이 문자열로 들어올 수 있다. 숫자가 필요하면 `.number`를 고려한다.

```html
<input v-model.number="quantity" type="number">
```

## 이번 장 요약

- `v-model`은 입력 요소와 상태를 연결한다.
- text input, textarea, checkbox, radio, select에 사용할 수 있다.
- checkbox 하나는 boolean, 여러 개는 배열과 연결할 수 있다.
- `.trim`, `.number`, `.lazy` 수식어를 사용할 수 있다.
