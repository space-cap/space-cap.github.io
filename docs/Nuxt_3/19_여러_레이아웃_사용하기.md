# 여러 레이아웃 사용하기

## 이번 장에서 배울 것

- 여러 레이아웃이 필요한 상황
- `admin.vue`, `blank.vue` 같은 레이아웃 만들기
- `definePageMeta`로 페이지별 레이아웃 지정하기

## 왜 여러 레이아웃이 필요할까

모든 페이지가 같은 화면 구조를 가지지는 않는다.

예를 들어 다음 페이지들을 생각해 보자.

- 일반 사용자 페이지
- 관리자 페이지
- 로그인 페이지
- 오류 페이지

일반 페이지에는 헤더와 푸터가 필요할 수 있다. 관리자 페이지에는 왼쪽 사이드바가 필요할 수 있다. 로그인 페이지는 화면을 단순하게 보여 주고 싶을 수 있다.

이럴 때 여러 레이아웃을 사용한다.

## 기본 레이아웃

먼저 기본 레이아웃을 만든다.

```txt
layouts/
  default.vue
```

```vue
<template>
  <div>
    <header>
      <NuxtLink to="/">홈</NuxtLink>
      <NuxtLink to="/about">소개</NuxtLink>
    </header>

    <main>
      <slot />
    </main>
  </div>
</template>
```

대부분의 페이지는 이 기본 레이아웃을 사용한다.

## 관리자 레이아웃 만들기

관리자 페이지 전용 레이아웃을 만든다.

```txt
layouts/
  default.vue
  admin.vue
```

`layouts/admin.vue`를 작성한다.

```vue
<template>
  <div class="admin-layout">
    <aside>
      <h2>관리자</h2>
      <NuxtLink to="/admin">대시보드</NuxtLink>
      <NuxtLink to="/admin/users">사용자</NuxtLink>
    </aside>

    <main>
      <slot />
    </main>
  </div>
</template>
```

## 페이지에서 레이아웃 지정하기

관리자 페이지에서 `definePageMeta`를 사용해 레이아웃을 지정한다.

```vue
<script setup>
definePageMeta({
  layout: 'admin'
})
</script>

<template>
  <section>
    <h1>관리자 대시보드</h1>
    <p>관리자 레이아웃을 사용하는 페이지입니다.</p>
  </section>
</template>
```

`layout: 'admin'`은 `layouts/admin.vue`를 사용하겠다는 뜻이다.

## 빈 레이아웃 만들기

로그인 페이지처럼 헤더나 메뉴가 필요 없는 화면에는 빈 레이아웃을 만들 수 있다.

```txt
layouts/
  blank.vue
```

```vue
<template>
  <main>
    <slot />
  </main>
</template>
```

로그인 페이지에서 적용한다.

```vue
<script setup>
definePageMeta({
  layout: 'blank'
})
</script>

<template>
  <section>
    <h1>로그인</h1>
    <form>
      <input type="email" placeholder="이메일" />
      <input type="password" placeholder="비밀번호" />
      <button type="submit">로그인</button>
    </form>
  </section>
</template>
```

## 레이아웃 이름 규칙

레이아웃 파일 이름이 곧 레이아웃 이름이 된다.

```txt
layouts/default.vue  -> default
layouts/admin.vue    -> admin
layouts/blank.vue    -> blank
```

`default`는 기본값이므로 페이지마다 따로 지정하지 않아도 된다.

## 레이아웃을 쓰지 않는 페이지

특정 페이지에서 레이아웃을 사용하지 않도록 설정할 수도 있다.

```vue
<script setup>
definePageMeta({
  layout: false
})
</script>
```

하지만 초보 단계에서는 레이아웃을 아예 끄기보다 `blank` 같은 단순한 레이아웃을 만들어 쓰는 편이 이해하기 쉽다.

## 자주 하는 실수

`definePageMeta`의 `layout` 값과 파일 이름이 맞지 않으면 원하는 레이아웃이 적용되지 않는다.

예를 들어 `layouts/admin-layout.vue` 파일을 만들었다면 레이아웃 이름도 그에 맞게 사용해야 한다. 처음에는 단순하게 `admin.vue`, `blank.vue`처럼 짧은 이름을 쓰는 것이 좋다.

## 정리

Nuxt에서는 `layouts` 폴더에 여러 레이아웃을 만들 수 있다. 페이지에서는 `definePageMeta({ layout: '이름' })`으로 사용할 레이아웃을 지정한다.
