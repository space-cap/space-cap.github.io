# 학습 전에 알아야 할 기초

## 이번 장에서 배울 것

- Nuxt를 배우기 전에 필요한 기본 지식
- HTML, CSS, JavaScript에서 꼭 알아야 할 내용
- Vue와 Node.js를 어느 정도 알고 있어야 하는지

## 완벽히 알고 시작할 필요는 없다

Nuxt를 배우기 전에 모든 웹 기술을 완벽하게 알아야 하는 것은 아니다. 하지만 아주 기본적인 개념은 알고 있어야 문서를 따라오기 쉽다.

이 장은 시험처럼 외우기 위한 목록이 아니라, 앞으로 막힐 때 무엇을 다시 찾아보면 되는지 알려 주는 지도에 가깝다.

## HTML 기초

HTML은 화면의 구조를 만든다.

Nuxt에서도 결국 화면은 HTML로 렌더링된다. Vue 컴포넌트의 `<template>` 안에 쓰는 코드도 HTML과 매우 비슷하다.

다음 정도는 알고 있으면 좋다.

- `div`, `span`, `p`, `h1`, `ul`, `li`, `a`, `button`, `form`, `input`
- 태그의 포함 관계
- `class`, `id`, `href`, `src`, `alt` 같은 속성
- 시맨틱 태그의 기본 개념

특히 링크와 폼은 Nuxt에서 자주 등장한다. 페이지 이동, 로그인, 검색, 게시글 작성 같은 기능이 모두 이 기초 위에 있다.

## CSS 기초

CSS는 화면의 모양을 만든다.

Nuxt에서는 일반 CSS, scoped CSS, CSS Modules, Tailwind CSS, UI 라이브러리 등 여러 스타일링 방식을 사용할 수 있다. 처음에는 다음 개념만 알고 있어도 충분하다.

- 선택자
- 클래스 기반 스타일
- 박스 모델
- flex
- grid 기초
- 반응형 화면

초보 단계에서는 예쁜 디자인보다 구조가 깨지지 않는 화면을 만드는 것이 더 중요하다.

## JavaScript 기초

Nuxt는 JavaScript 또는 TypeScript로 작성한다. 처음에는 JavaScript 문법을 먼저 익히는 것이 좋다.

다음 개념은 자주 사용된다.

- 변수와 상수: `let`, `const`
- 함수와 화살표 함수
- 객체와 배열
- 조건문과 반복문
- 배열 메서드: `map`, `filter`, `find`
- 비동기 처리: `Promise`, `async`, `await`
- 모듈: `import`, `export`

Nuxt에서 데이터를 가져올 때는 비동기 처리가 계속 등장한다. `async`와 `await`의 기본 흐름은 꼭 익숙해지는 것이 좋다.

## Vue 기초

Nuxt는 Vue 위에서 동작한다. 따라서 Vue를 조금 알고 있으면 훨씬 편하다.

다음 내용을 알고 있으면 좋다.

- 단일 파일 컴포넌트
- `<template>`, `<script setup>`, `<style>`
- `ref`, `computed`, `watch`
- props와 emit
- slot
- 컴포넌트 분리
- Vue Router의 기본 개념

Vue를 완전히 마스터하지 않아도 Nuxt를 시작할 수 있다. 다만 Nuxt 문서를 읽다가 화면 컴포넌트 문법이 헷갈리면 Vue 기초를 함께 복습하는 것이 좋다.

## Node.js와 패키지 매니저

Nuxt 프로젝트는 Node.js 환경에서 개발한다.

Node.js를 깊게 알 필요는 없지만 다음은 알아야 한다.

- Node.js는 브라우저 밖에서 JavaScript를 실행하는 환경이다.
- npm, pnpm, yarn, bun은 패키지를 설치하고 명령을 실행하는 도구다.
- `package.json`에는 프로젝트 정보와 실행 명령어가 들어 있다.
- `node_modules`에는 설치된 패키지가 들어 있다.

처음에는 npm을 기준으로 학습해도 충분하다. 나중에 프로젝트나 팀의 기준에 맞춰 pnpm, yarn, bun을 사용할 수 있다.

## 터미널 기초

Nuxt 프로젝트를 만들고 실행하려면 터미널 명령을 사용한다.

자주 쓰는 명령은 다음과 같다.

```bash
node -v
npm -v
npm install
npm run dev
npm run build
```

명령어를 완벽히 외울 필요는 없다. 하지만 현재 폴더가 어디인지, 명령을 어디에서 실행해야 하는지는 확인할 수 있어야 한다.

## 정리

Nuxt를 배우기 전에 HTML, CSS, JavaScript, Vue, Node.js의 기초를 조금 알고 있으면 좋다. 부족한 부분이 있어도 괜찮다. Nuxt를 배우면서 필요한 개념을 다시 만나고, 그때마다 조금씩 익히면 된다.
