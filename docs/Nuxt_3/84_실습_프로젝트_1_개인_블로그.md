# 실습 프로젝트 1: 개인 블로그

## 이번 프로젝트에서 만들 것

Nuxt Content를 사용해 Markdown 기반 개인 블로그를 만든다.

이 프로젝트에서 연습할 내용은 다음과 같다.

- Nuxt Content 설치
- Markdown 글 작성
- 블로그 목록 페이지
- 블로그 상세 페이지
- 글마다 SEO 설정
- 없는 글 404 처리

## 목표 화면

만들 화면은 단순하다.

```txt
/blog
  블로그 글 목록

/blog/hello-nuxt
  글 상세 페이지
```

처음에는 디자인보다 구조를 이해하는 것이 중요하다.

## 1단계: Nuxt Content 설치

```bash
npx nuxt module add content
```

`nuxt.config.ts`에 모듈이 등록되었는지 확인한다.

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/content']
})
```

## 2단계: 콘텐츠 폴더 만들기

```txt
content/
  blog/
    hello-nuxt.md
    data-fetching.md
```

`content/blog/hello-nuxt.md`

```md
---
title: 'Nuxt 3 시작하기'
description: 'Nuxt 3로 첫 블로그를 만드는 방법을 알아봅니다.'
date: '2026-05-20'
tags:
  - nuxt
  - beginner
---

# Nuxt 3 시작하기

Nuxt 3는 Vue 기반의 웹 애플리케이션 프레임워크입니다.
```

## 3단계: collection 정의하기

`content.config.ts`

```ts
import { defineCollection, defineContentConfig } from '@nuxt/content'
import { z } from 'zod'

export default defineContentConfig({
  collections: {
    blog: defineCollection({
      type: 'page',
      source: 'blog/*.md',
      schema: z.object({
        title: z.string(),
        description: z.string(),
        date: z.string(),
        tags: z.array(z.string()).default([])
      })
    })
  }
})
```

collection은 Markdown 파일을 어떤 구조의 콘텐츠로 다룰지 정한다.

## 4단계: 블로그 목록 페이지

`pages/blog/index.vue`

```vue
<script setup>
const { data: posts } = await useAsyncData('blog-posts', () => {
  return queryCollection('blog')
    .order('date', 'DESC')
    .all()
})

useSeoMeta({
  title: '블로그',
  description: 'Nuxt 학습 블로그 글 목록입니다.'
})
</script>

<template>
  <main>
    <h1>블로그</h1>

    <article v-for="post in posts" :key="post.path">
      <h2>
        <NuxtLink :to="post.path">
          {{ post.title }}
        </NuxtLink>
      </h2>
      <p>{{ post.description }}</p>
      <time>{{ post.date }}</time>
    </article>
  </main>
</template>
```

## 5단계: 블로그 상세 페이지

`pages/blog/[slug].vue`

```vue
<script setup>
const route = useRoute()
const slug = route.params.slug

const { data: post } = await useAsyncData(`blog-${slug}`, () => {
  return queryCollection('blog')
    .path(`/blog/${slug}`)
    .first()
})

if (!post.value) {
  throw createError({
    statusCode: 404,
    statusMessage: '글을 찾을 수 없습니다.'
  })
}

useSeoMeta({
  title: () => post.value?.title || '블로그',
  description: () => post.value?.description || '블로그 글입니다.'
})
</script>

<template>
  <main>
    <ContentRenderer :value="post" />
  </main>
</template>
```

## 6단계: 태그 표시하기

목록 페이지에 태그를 표시한다.

```vue
<ul>
  <li v-for="tag in post.tags" :key="tag">
    #{{ tag }}
  </li>
</ul>
```

태그 필터 기능은 다음 단계로 남겨 두어도 좋다.

## 7단계: 배포 전략

개인 블로그는 정적 배포에 잘 어울린다.

```bash
npm run generate
```

또는 배포 플랫폼에 맞게 프리렌더링을 설정할 수 있다.

GitHub Pages에 배포한다면 `github_pages` preset과 `NUXT_APP_BASE_URL`을 확인한다.

## 체크리스트

- `/blog`에서 글 목록이 보이는가?
- 글 제목을 누르면 상세 페이지로 이동하는가?
- 없는 글 주소는 404가 되는가?
- 글마다 title과 description이 설정되는가?
- Markdown 내용이 정상 렌더링되는가?

## 정리

개인 블로그 프로젝트에서는 Nuxt Content, 파일 기반 라우팅, 동적 라우트, SEO, 404 처리를 한 번에 연습할 수 있다. 정적 배포와도 잘 어울리는 첫 실습 프로젝트다.
