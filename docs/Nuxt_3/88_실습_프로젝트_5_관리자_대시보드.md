# 실습 프로젝트 5: 관리자 대시보드

## 이번 프로젝트에서 만들 것

관리자 전용 레이아웃과 대시보드 화면을 만든다.

이 프로젝트에서 연습할 내용은 다음과 같다.

- 관리자 레이아웃
- 관리자 권한 미들웨어
- 통계 카드
- 사용자 테이블
- 필터와 검색
- 차트 영역 설계

## 목표 화면

```txt
/admin
  관리자 홈

/admin/users
  사용자 관리

/admin/settings
  설정
```

모든 `/admin` 페이지는 관리자 권한이 있어야 접근할 수 있다.

## 1단계: 관리자 레이아웃

`layouts/admin.vue`

```vue
<template>
  <div>
    <aside>
      <h1>관리자</h1>
      <nav>
        <NuxtLink to="/admin">대시보드</NuxtLink>
        <NuxtLink to="/admin/users">사용자</NuxtLink>
        <NuxtLink to="/admin/settings">설정</NuxtLink>
      </nav>
    </aside>

    <main>
      <slot />
    </main>
  </div>
</template>
```

## 2단계: 관리자 미들웨어

`middleware/admin.ts`

```ts
export default defineNuxtRouteMiddleware(async () => {
  const user = useState('auth-user', () => null)

  if (!user.value) {
    try {
      user.value = await $fetch('/api/auth/me')
    } catch {
      return navigateTo('/login')
    }
  }

  if (user.value?.role !== 'admin') {
    throw createError({
      statusCode: 403,
      statusMessage: '관리자 권한이 필요합니다.'
    })
  }
})
```

학습용 예제에서는 `/api/auth/me`가 `role: 'admin'`을 반환한다고 가정한다.

## 3단계: 관리자 페이지 공통 설정

각 관리자 페이지에 레이아웃과 미들웨어를 지정한다.

```vue
<script setup>
definePageMeta({
  layout: 'admin',
  middleware: 'admin'
})
</script>
```

반복이 많다면 나중에 페이지 구조나 Nuxt layer 전략을 더 고민할 수 있다.

## 4단계: 대시보드 페이지

`pages/admin/index.vue`

```vue
<script setup>
definePageMeta({

const stats = [
```

## 5단계: 사용자 API

`server/api/admin/users.get.ts`

```ts
export default defineEventHandler((event) => {
  const session = getCookie(event, 'session')

  if (session !== 'demo-session') {
    throw createError({
      statusCode: 401,
      statusMessage: '로그인이 필요합니다.'
    })
  }

  return [
    { id: 1, name: '홍길동', email: 'user@example.com', role: 'admin' },
    { id: 2, name: '김철수', email: 'kim@example.com', role: 'user' }
  ]
})
```

실제 프로젝트에서는 서버에서 사용자 역할을 조회하고 관리자 권한을 검증해야 한다.

## 6단계: 사용자 관리 페이지

`pages/admin/users.vue`

```vue
<script setup>
definePageMeta({
  layout: 'admin',
  middleware: 'admin'
})

const keyword = ref('')

const { data: users } = await useFetch('/api/admin/users', {
  default: () => []
})

const filteredUsers = computed(() => {
  if (!keyword.value) {
    return users.value
  }

  return users.value.filter((user) => {
    return user.name.includes(keyword.value)
      || user.email.includes(keyword.value)
  })
})
</script>

<template>
  <section>
    <h1>사용자 관리</h1>

    <input v-model="keyword" placeholder="사용자 검색" />

    <table>
      <thead>
        <tr>
          <th>이름</th>
          <th>이메일</th>
          <th>역할</th>
        </tr>
      </thead>
      <tbody>
        <tr v-for="user in filteredUsers" :key="user.id">
          <td>{{ user.name }}</td>
          <td>{{ user.email }}</td>
          <td>{{ user.role }}</td>
        </tr>
      </tbody>
    </table>
  </section>
</template>
```

## 7단계: 차트 영역

처음에는 차트 라이브러리를 바로 설치하지 않아도 된다.

대신 차트가 들어갈 구조를 먼저 만든다.

```vue
<section>
  <h2>방문자 추이</h2>
  <div>
    차트가 들어갈 영역
  </div>
</section>
```

실제 차트가 필요해지면 Chart.js, ECharts 같은 라이브러리를 검토한다. 차트 라이브러리는 무거울 수 있으므로 관리자 페이지에서만 lazy loading하는 전략도 좋다.
