# 레이아웃 기초

## 이번 장에서 배울 것

- 레이아웃이 무엇인지
- `layouts/default.vue`를 만드는 방법
- `<NuxtLayout>`과 `<slot />`의 역할
- 페이지에 공통 화면 구조를 적용하는 방법

## 레이아웃이란

레이아웃은 여러 페이지가 함께 사용하는 화면의 큰 틀이다.

예를 들어 대부분의 웹사이트에는 공통으로 반복되는 영역이 있다.

- 상단 헤더
- 메뉴
- 본문 영역
- 하단 푸터

이런 구조를 모든 페이지마다 반복해서 작성하면 불편하다. 레이아웃을 사용하면 공통 구조를 한곳에 모아 관리할 수 있다.

## layouts 폴더 만들기

프로젝트 루트에 `layouts` 폴더를 만들고 `default.vue` 파일을 만든다.

```txt
layouts/
  default.vue
```

`layouts/default.vue`는 기본 레이아웃이다.

```vue
<template>
  <div>
    <header>
      <NuxtLink to="/">홈</NuxtLink>
      <NuxtLink to="/about">소개</NuxtLink>
    </header>

    <main>
      <slot />
    </main>

    <footer>
      <p>Nuxt 3 학습 문서 예제</p>
    </footer>
  </div>
</template>
```

여기서 `<slot />`은 각 페이지의 내용이 들어갈 자리다.

## app.vue에서 NuxtLayout 사용하기

레이아웃을 사용하려면 `app.vue`에서 `<NuxtLayout>`으로 `<NuxtPage>`를 감싼다.

```vue
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

이렇게 하면 현재 페이지가 기본 레이아웃의 `<slot />` 위치에 들어간다.

## 페이지 작성하기

`pages/index.vue`를 작성한다.

```vue
<template>
  <section>
    <h1>홈</h1>
    <p>기본 레이아웃 안에 표시되는 홈 페이지입니다.</p>
  </section>
</template>
```

`pages/about.vue`를 작성한다.

```vue
<template>
  <section>
    <h1>소개</h1>
    <p>이 페이지도 같은 헤더와 푸터를 사용합니다.</p>
  </section>
</template>
```

두 페이지 모두 같은 레이아웃 안에서 표시된다.

## 레이아웃을 사용하는 이유

레이아웃을 사용하면 공통 코드를 줄일 수 있다.

헤더 메뉴를 수정해야 할 때 모든 페이지를 고칠 필요가 없다. `layouts/default.vue`만 수정하면 된다.

또 페이지마다 공통 디자인을 유지하기 쉬워진다. 블로그, 관리자 페이지, 로그인 페이지처럼 화면 구조가 다른 경우에도 레이아웃을 나누어 관리할 수 있다.

## app.vue만 사용해도 되는 경우

아주 작은 앱이라면 `layouts` 폴더 없이 `app.vue`에 바로 공통 구조를 작성해도 된다.

```vue
<template>
  <div>
    <header>공통 헤더</header>
    <NuxtPage />
  </div>
</template>
```

하지만 페이지 종류가 늘어나고 레이아웃이 여러 개 필요해질 가능성이 있다면 `layouts` 폴더를 사용하는 것이 좋다.

## 자주 하는 실수

레이아웃 파일에서 `<slot />`을 빼먹으면 페이지 내용이 표시되지 않는다.

또 `app.vue`에서 `<NuxtLayout>`을 사용하지 않으면 `layouts/default.vue`가 적용되지 않을 수 있다. 레이아웃을 만들었다면 `app.vue` 구조도 함께 확인해야 한다.

## 정리

레이아웃은 여러 페이지가 공유하는 화면의 큰 틀이다. `layouts/default.vue`에 공통 구조를 만들고, `app.vue`에서 `<NuxtLayout>`과 `<NuxtPage>`를 함께 사용하면 페이지 내용이 레이아웃 안에 표시된다.
