# 에러 페이지와 404 처리

## 이번 장에서 배울 것

- Nuxt에서 에러 페이지가 동작하는 방식
- `error.vue`로 에러 화면 만들기
- `createError`로 404 처리하기
- `clearError`로 에러 상태를 정리하는 방법

## 404란

404는 사용자가 요청한 페이지를 찾을 수 없다는 뜻의 HTTP 상태 코드다.

예를 들어 존재하지 않는 게시글 주소로 이동하면 404 화면을 보여 주는 것이 자연스럽다.

```txt
/posts/999999
```

이 주소에 해당하는 글이 없다면 "페이지를 찾을 수 없습니다"라는 화면을 보여 줄 수 있다.

## error.vue 만들기

Nuxt에서는 프로젝트 루트에 `error.vue` 파일을 만들면 기본 에러 페이지를 바꿀 수 있다.

```txt
error.vue
app.vue
pages/
```

간단한 `error.vue` 예시는 다음과 같다.

```vue
<script setup>
const props = defineProps({
  error: Object
})

const handleError = () => {
  clearError({ redirect: '/' })
}
</script>

<template>
  <main>
    <h1>{{ error?.statusCode }}</h1>
    <p>{{ error?.statusMessage || '오류가 발생했습니다.' }}</p>
    <button @click="handleError">홈으로 돌아가기</button>
  </main>
</template>
```

`clearError`는 현재 에러 상태를 정리한다. `redirect`를 함께 사용하면 에러를 정리한 뒤 특정 주소로 이동할 수 있다.

## createError 사용하기

페이지에서 직접 404를 발생시키고 싶다면 `createError`를 사용할 수 있다.

예를 들어 게시글을 찾지 못했을 때 다음처럼 처리한다.

```vue
<script setup>
const route = useRoute()

const posts = [
  { id: '1', title: '첫 번째 글' },
  { id: '2', title: '두 번째 글' }
]

const post = posts.find((item) => item.id === route.params.id)

if (!post) {
  throw createError({
    statusCode: 404,
    statusMessage: '게시글을 찾을 수 없습니다.'
  })
}
</script>

<template>
  <main>
    <h1>{{ post.title }}</h1>
  </main>
</template>
```

서버 렌더링 중에 이 오류가 발생하면 Nuxt는 에러 페이지를 렌더링한다.

## showError

`showError`를 사용하면 에러 페이지를 표시할 수 있다.

```js
showError({
  statusCode: 500,
  statusMessage: '처리 중 오류가 발생했습니다.'
})
```

다만 일반적인 페이지 로직에서는 `throw createError(...)`를 사용하는 방식이 더 자주 권장된다.

## 잘못된 동적 라우트 처리

동적 라우트에서는 잘못된 값이 들어올 수 있다.

`/posts/abc`처럼 숫자가 아닌 값이 들어오면 404로 처리하고 싶을 수 있다.

```vue
<script setup>
definePageMeta({
  validate(route) {
    return typeof route.params.id === 'string' && /^\d+$/.test(route.params.id)
  }
})
</script>
```

`validate`가 `false`를 반환하면 Nuxt는 유효하지 않은 라우트로 처리한다.

## 에러 화면에서 주의할 점

에러 화면은 앱이 정상적으로 렌더링되지 못했을 때도 보일 수 있다. 그래서 너무 복잡한 로직을 넣지 않는 것이 좋다.

에러 페이지는 사용자가 다음 행동을 할 수 있게 도와야 한다.

- 홈으로 이동
- 이전 페이지로 돌아가기
- 다시 시도하기
- 문의 안내 보기

초보 단계에서는 홈으로 돌아가는 버튼만 있어도 충분하다.

## 자주 하는 실수

데이터가 없는데도 바로 속성에 접근하면 오류가 난다.

```vue
<h1>{{ post.title }}</h1>
```

`post`가 없을 수도 있다면 먼저 확인하거나, 없는 경우 `createError`로 처리해야 한다.

## 정리

Nuxt에서는 `error.vue`로 전체 에러 페이지를 만들 수 있다. 페이지나 서버 로직에서 `createError`를 던지면 상태 코드와 메시지를 가진 에러를 처리할 수 있다.
