# 이미지 최적화

## 이번 장에서 배울 것

- 이미지 최적화가 필요한 이유
- Nuxt Image와 `<NuxtImg>`의 기본 사용법
- `public` 폴더 이미지 사용
- lazy loading과 responsive image의 기본

## 왜 이미지 최적화가 필요할까

웹 페이지에서 이미지가 차지하는 용량은 매우 크다.

이미지가 너무 크거나 최적화되지 않으면 다음 문제가 생긴다.

- 첫 화면 로딩이 느려진다.
- 모바일 데이터 사용량이 늘어난다.
- 검색 엔진의 성능 평가에 불리할 수 있다.
- 사용자가 페이지를 떠날 가능성이 커진다.

그래서 이미지는 크기, 형식, 로딩 시점을 신경 써야 한다.

## Nuxt Image란

Nuxt Image는 Nuxt에서 이미지 최적화를 쉽게 적용할 수 있게 도와주는 모듈이다.

설치 명령은 다음과 같다.

```bash
npx nuxi@latest module add image
```

설치 후 `nuxt.config.ts`에 모듈이 등록된다.

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/image']
})
```

## NuxtImg 사용하기

`<NuxtImg>`는 기본 `<img>` 태그를 대체하듯 사용할 수 있는 컴포넌트다.

```vue
<template>
  <NuxtImg src="/images/logo.png" alt="사이트 로고" />
</template>
```

기본 provider를 사용할 때 `/images/logo.png`처럼 접근하는 이미지는 `public/images/logo.png`에 둔다.

```txt
public/
  images/
    logo.png
```

## 크기 지정하기

이미지의 표시 크기를 알 수 있다면 `width`와 `height`를 지정한다.

```vue
<template>
  <NuxtImg
    src="/images/profile.png"
    width="160"
    height="160"
    alt="프로필 이미지"
  />
</template>
```

크기를 지정하면 브라우저가 레이아웃 공간을 미리 계산할 수 있어 화면이 덜 흔들린다.

## 반응형 이미지

화면 크기에 따라 다른 이미지 크기를 제공하려면 `sizes`를 사용할 수 있다.

```vue
<template>
  <NuxtImg
    src="/images/hero.png"
    sizes="100vw sm:640px md:768px lg:1024px"
    alt="메인 이미지"
  />
</template>
```

이렇게 하면 브라우저가 화면 조건에 맞는 이미지 후보를 선택할 수 있다.

## lazy loading

아래쪽에 있는 이미지는 처음부터 모두 불러오지 않아도 된다.

```vue
<template>
  <NuxtImg
    src="/images/post-cover.png"
    alt="게시글 커버"
    loading="lazy"
  />
</template>
```

`loading="lazy"`는 이미지가 화면 가까이 올 때 로딩하도록 브라우저에 힌트를 준다.

첫 화면의 핵심 이미지는 lazy로 두지 않는 것이 좋다. 중요한 이미지는 빨리 보여야 하기 때문이다.

## alt 속성

`alt`는 이미지 대체 텍스트다.

이미지를 볼 수 없는 환경이나 스크린 리더에서 중요한 역할을 한다.

```vue
<NuxtImg src="/images/chart.png" alt="월별 매출 증가 그래프" />
```

단순 장식 이미지는 빈 alt를 사용할 수 있다.

```vue
<NuxtImg src="/images/decorative-line.png" alt="" />
```

하지만 의미가 있는 이미지는 내용을 설명하는 alt를 작성해야 한다.

## 원격 이미지

외부 도메인의 이미지를 최적화하려면 provider나 domains 설정이 필요할 수 있다.

프로젝트에서 외부 이미지가 많다면 Nuxt Image 공식 문서의 provider 설정을 확인해야 한다.

초보 단계에서는 먼저 `public` 폴더의 로컬 이미지를 `<NuxtImg>`로 다루는 방식부터 익히자.

## 자주 하는 실수

원본 이미지가 너무 큰데 화면에서는 작게 보여 주는 실수가 많다.

예를 들어 4000px 이미지를 200px 아바타로 보여 주면 불필요한 용량을 낭비한다.

또 `alt`를 모두 비워 두는 것도 좋지 않다. 의미 있는 이미지에는 대체 텍스트를 작성해야 한다.

## 정리

Nuxt Image의 `<NuxtImg>`는 Nuxt에서 이미지를 최적화하고 다루기 위한 컴포넌트다. 이미지 크기, `alt`, lazy loading, responsive sizes를 함께 고려하면 성능과 접근성을 모두 개선할 수 있다.
