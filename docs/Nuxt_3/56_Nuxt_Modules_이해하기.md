# Nuxt Modules 이해하기

## 이번 장에서 배울 것

- Nuxt Module이 무엇인지
- 모듈을 설치하고 등록하는 방법
- `modules` 설정의 역할
- 모듈을 선택할 때 확인할 점

## Nuxt Module이란

Nuxt Module은 Nuxt 앱에 기능을 추가하는 확장 도구다.

Nuxt의 핵심 기능만으로도 많은 것을 만들 수 있지만, 실제 프로젝트에서는 다음 기능이 필요해질 수 있다.

- 이미지 최적화
- Markdown 콘텐츠 관리
- 다국어 처리
- 아이콘 사용
- 폰트 최적화
- 상태 관리
- SEO 도구
- UI 컴포넌트

이런 기능을 매번 직접 설정하면 번거롭다. Nuxt Module은 이런 반복 작업을 줄여 준다.

## 모듈이 하는 일

Nuxt 모듈은 프로젝트가 실행되거나 빌드될 때 Nuxt 설정을 확장한다.

예를 들어 모듈은 다음 일을 할 수 있다.

- 플러그인 자동 등록
- 컴포넌트 자동 등록
- composable 자동 import
- 서버 라우트 추가
- Vite 설정 변경
- CSS 추가
- 빌드 설정 확장

초보자 입장에서는 "Nuxt 프로젝트에 특정 기능을 쉽게 붙여 주는 설치형 확장"이라고 이해하면 된다.

## 모듈 설치 명령

Nuxt는 모듈을 쉽게 추가할 수 있는 명령을 제공한다.

```bash
npx nuxt module add pinia
```

이 명령은 보통 다음 일을 해 준다.

- 필요한 패키지 설치
- `package.json` 갱신
- `nuxt.config.ts`의 `modules` 배열 갱신

모듈 문서에 따라 `npx nuxi@latest module add ...` 형태를 안내하는 경우도 있다. 실제 프로젝트에서는 해당 모듈의 공식 설치 문서를 확인하는 것이 좋다.

## nuxt.config.ts에 등록하기

수동으로 모듈을 등록할 때는 `nuxt.config.ts`의 `modules` 배열에 넣는다.

```ts
export default defineNuxtConfig({
  modules: [
    '@pinia/nuxt',
    '@nuxt/image'
  ]
})
```

Nuxt 2에서 사용하던 `buildModules`는 Nuxt 3에서는 사용하지 않는다. Nuxt 3에서는 `modules`에 등록한다.

## 옵션과 함께 등록하기

모듈에 옵션이 필요하면 `nuxt.config.ts`에서 설정한다.

```ts
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: ['ko', 'en'],
    defaultLocale: 'ko'
  }
})
```

모듈마다 옵션 이름과 구조가 다르다. 설치 후에는 공식 문서에서 설정 예시를 확인해야 한다.

## 로컬 모듈

직접 만든 모듈을 프로젝트 안에 둘 수도 있다.

```txt
modules/
  hello.ts
```

`modules` 폴더 안의 로컬 모듈은 자동으로 등록될 수 있다.

하지만 초보 단계에서는 외부 모듈을 사용하는 것부터 익히는 것이 좋다. 직접 모듈을 만드는 일은 나중에 Nuxt 내부 구조를 더 잘 알게 된 뒤 다루어도 충분하다.

## 모듈을 고를 때 확인할 점

모듈을 설치하기 전에 다음을 확인하자.

- Nuxt 3와 호환되는가?
- 최근에도 유지보수되고 있는가?
- 공식 문서가 충분한가?
- SSR 환경에서 문제가 없는가?
- 필요한 기능만 제공하는가?
- 프로젝트 규모에 비해 너무 무겁지 않은가?

모듈은 편리하지만 의존성도 늘린다. 필요한 이유가 분명할 때 추가하는 것이 좋다.

## 자주 하는 실수

비슷한 역할의 모듈을 여러 개 설치하는 실수를 조심해야 한다.

예를 들어 UI 라이브러리를 여러 개 동시에 설치하면 스타일과 컴포넌트 규칙이 섞여 유지보수가 어려워진다.

또 모듈 설치 후 개발 서버를 재시작하지 않아 설정이 적용되지 않는 경우가 있다. 모듈을 추가했다면 개발 서버를 다시 실행하는 습관이 좋다.

## 정리

Nuxt Module은 Nuxt 앱에 기능을 추가하는 확장 도구다. 설치 명령으로 추가하거나 `nuxt.config.ts`의 `modules` 배열에 직접 등록한다. 모듈을 선택할 때는 호환성, 유지보수 상태, SSR 지원, 필요성을 함께 확인해야 한다.
