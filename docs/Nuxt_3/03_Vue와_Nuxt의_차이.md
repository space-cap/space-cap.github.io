# Vue와 Nuxt의 차이

## 이번 장에서 배울 것

- Vue와 Nuxt의 역할 차이
- Vue 프로젝트와 Nuxt 프로젝트의 구조 차이
- 어떤 상황에서 Nuxt를 선택하면 좋은지

## Vue는 화면을 만드는 도구

Vue는 사용자 인터페이스를 만들기 위한 JavaScript 프레임워크다. 버튼, 입력 폼, 목록, 모달 같은 화면 요소를 컴포넌트로 나누고, 데이터가 바뀌면 화면도 자동으로 바뀌게 만들 수 있다.

Vue의 핵심 관심사는 화면이다.

- 데이터를 화면에 보여 주기
- 사용자 이벤트 처리하기
- 컴포넌트로 화면 나누기
- 반응형 상태 관리하기

Vue만으로도 충분히 훌륭한 웹 앱을 만들 수 있다. 특히 한 페이지 안에서 동작하는 앱이나, 기존 서비스의 일부 화면을 점진적으로 바꾸는 작업에 잘 어울린다.

## Nuxt는 애플리케이션 구조를 제공하는 도구

Nuxt는 Vue를 기반으로 한다. 즉 Nuxt 앱의 화면도 결국 Vue 컴포넌트로 만든다.

하지만 Nuxt는 Vue보다 더 넓은 범위를 다룬다.

- 페이지 주소 만들기
- 공통 레이아웃 관리하기
- 서버에서 HTML 렌더링하기
- 데이터를 SSR에 맞게 가져오기
- API 서버 만들기
- SEO 메타 태그 관리하기
- 빌드와 배포 방식 정리하기

Vue가 "화면을 어떻게 만들까?"에 집중한다면, Nuxt는 "서비스 전체를 어떤 구조로 만들까?"까지 도와준다.

## 라우팅 방식의 차이

Vue 프로젝트에서는 보통 Vue Router를 직접 설치하고 라우트 목록을 작성한다.

```js
const routes = [
  { path: '/', component: Home },
  { path: '/about', component: About }
]
```

Nuxt에서는 `pages` 폴더 안에 파일을 만들면 주소가 자동으로 생긴다.

```txt
pages/
  index.vue    -> /
  about.vue    -> /about
```

처음에는 이 차이가 작아 보이지만, 페이지가 많아질수록 파일 기반 라우팅은 구조를 이해하기 쉽게 만든다.

## 렌더링 방식의 차이

일반적인 Vue SPA는 브라우저에서 JavaScript가 실행된 뒤 화면을 만든다. 이 방식을 클라이언트 사이드 렌더링, 줄여서 CSR이라고 부른다.

Nuxt는 기본적으로 서버에서 먼저 HTML을 만든 뒤 브라우저로 보낼 수 있다. 이 방식을 서버 사이드 렌더링, 줄여서 SSR이라고 부른다.

SSR을 사용하면 사용자는 더 빨리 내용이 있는 화면을 볼 수 있고, 검색 엔진도 페이지 내용을 더 잘 읽을 수 있다.

## 서버 기능의 차이

Vue는 기본적으로 프론트엔드 화면을 만드는 도구다. API 서버가 필요하면 Express, Spring Boot, Laravel 같은 별도 백엔드를 만들거나 외부 API를 사용한다.

Nuxt 3는 `server/api` 폴더 안에 서버 API를 만들 수 있다.

```txt
server/
  api/
    hello.get.ts -> /api/hello
```

이 기능 덕분에 간단한 API는 Nuxt 프로젝트 안에서 바로 만들 수 있다. 물론 규모가 커지면 별도 백엔드와 함께 쓰는 방식도 가능하다.

## 언제 Vue만 써도 괜찮을까

다음과 같은 경우에는 Vue만으로도 충분할 수 있다.

- 한 페이지 안에서 대부분의 기능이 동작하는 앱
- 검색 엔진 노출이 중요하지 않은 내부 관리자 도구
- 기존 서버 템플릿에 일부 인터랙션만 추가하는 경우
- 백엔드와 프론트엔드 구조를 명확히 나누고 싶은 경우

## 언제 Nuxt가 좋을까

다음과 같은 경우에는 Nuxt가 좋은 선택이다.

- 여러 페이지가 있는 웹사이트
- 검색 엔진 노출이 중요한 서비스
- 블로그, 문서, 커머스, 랜딩 페이지
- 서버 렌더링과 정적 생성을 함께 쓰고 싶은 경우
- 프론트엔드와 간단한 API를 한 프로젝트에서 시작하고 싶은 경우

## 정리

Vue는 화면을 만드는 데 집중하고, Nuxt는 Vue를 이용해 실제 웹 애플리케이션을 만드는 전체 구조를 제공한다.

Nuxt를 배우면 Vue 컴포넌트를 페이지, 라우팅, 서버, SEO, 배포까지 연결하는 방법을 익히게 된다.
