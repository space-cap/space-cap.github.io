# 웹 렌더링 방식 이해하기

## 이번 장에서 배울 것

- CSR, SSR, SSG의 차이
- 하이드레이션이 무엇인지
- Nuxt에서 렌더링 방식을 왜 알아야 하는지

## 렌더링이란

렌더링은 데이터를 사용자가 볼 수 있는 화면으로 바꾸는 과정이다.

예를 들어 게시글 제목과 본문 데이터가 있을 때, 이것을 HTML로 만들어 브라우저에 보여 주는 과정이 렌더링이다.

Nuxt를 배울 때 렌더링 방식을 이해해야 하는 이유는 간단하다. Nuxt 코드는 서버에서도 실행될 수 있고 브라우저에서도 실행될 수 있기 때문이다.

## CSR

CSR은 Client-Side Rendering의 줄임말이다. 브라우저에서 JavaScript를 실행해 화면을 만드는 방식이다.

흐름은 대략 이렇다.

1. 브라우저가 거의 비어 있는 HTML을 받는다.
2. JavaScript 파일을 내려받는다.
3. 브라우저에서 JavaScript가 실행된다.
4. JavaScript가 HTML 요소를 만들고 화면을 채운다.

CSR은 화면 전환이 부드럽고 앱처럼 동작하기 좋다. 하지만 처음 화면을 보기까지 시간이 걸릴 수 있고, 검색 엔진이 내용을 읽기 어려운 경우가 있다.

## SSR

SSR은 Server-Side Rendering의 줄임말이다. 서버에서 먼저 HTML을 만든 뒤 브라우저에 보내는 방식이다.

흐름은 대략 이렇다.

1. 브라우저가 페이지를 요청한다.
2. 서버가 Vue 컴포넌트를 실행해 HTML을 만든다.
3. 완성된 HTML을 브라우저로 보낸다.
4. 브라우저는 HTML을 먼저 보여 준다.
5. 이후 JavaScript가 연결되어 화면이 동작 가능해진다.

Nuxt는 기본적으로 Universal Rendering을 사용한다. 이는 서버에서 먼저 렌더링하고, 브라우저에서도 Vue 앱으로 이어서 동작하게 만드는 방식이다.

## 하이드레이션

하이드레이션은 서버에서 받은 HTML에 브라우저의 JavaScript 기능을 연결하는 과정이다.

서버가 만든 HTML은 처음에는 정적인 결과물이다. 버튼이 보이더라도 아직 클릭 이벤트가 연결되지 않았을 수 있다. 브라우저가 JavaScript를 내려받고 Vue 앱을 연결하면 버튼 클릭, 입력, 화면 갱신 같은 기능이 살아난다.

이 과정을 하이드레이션이라고 부른다.

## SSG

SSG는 Static Site Generation의 줄임말이다. 페이지를 사용자가 요청할 때마다 서버에서 만드는 것이 아니라, 빌드할 때 미리 HTML 파일로 만들어 두는 방식이다.

블로그 글, 문서 사이트, 회사 소개 페이지처럼 내용이 자주 바뀌지 않는 페이지에 잘 어울린다.

SSG의 장점은 빠르고 배포가 단순하다는 것이다. 이미 만들어진 HTML 파일을 전달하면 되기 때문이다.

## 하이브리드 렌더링

Nuxt는 페이지마다 다른 렌더링 전략을 사용할 수 있다.

예를 들어 다음처럼 나눌 수 있다.

- 메인 페이지는 미리 생성
- 블로그 글은 정적으로 생성
- 관리자 페이지는 클라이언트에서만 렌더링
- 사용자별 대시보드는 서버에서 매번 렌더링

이처럼 한 애플리케이션 안에서 페이지별로 렌더링 방식을 다르게 선택하는 흐름을 하이브리드 렌더링이라고 볼 수 있다.

## 초보자가 기억할 기준

처음에는 다음 기준만 기억해도 충분하다.

- CSR: 브라우저가 화면을 만든다.
- SSR: 서버가 먼저 화면을 만든다.
- SSG: 빌드할 때 화면을 미리 만들어 둔다.
- 하이드레이션: 서버가 만든 화면에 브라우저 동작을 연결한다.

## 자주 하는 실수

가장 흔한 실수는 서버에서도 실행되는 코드 안에서 브라우저 전용 기능을 바로 사용하는 것이다.

예를 들어 `window`, `document`, `localStorage`는 브라우저에만 있다. SSR 중에는 서버에서 코드가 실행될 수 있으므로 이런 값을 바로 사용하면 오류가 날 수 있다.

이런 코드는 클라이언트에서만 실행되도록 처리해야 한다. 이 내용은 뒤에서 플러그인, 미들웨어, 인증을 다룰 때 다시 배운다.

## 정리

Nuxt를 잘 이해하려면 코드가 서버에서 실행되는지, 브라우저에서 실행되는지 구분하는 감각이 필요하다.

Nuxt는 기본적으로 서버에서 HTML을 만들고 브라우저에서 이어서 동작하게 하는 Universal Rendering을 사용한다. 필요에 따라 CSR, SSG, 하이브리드 렌더링도 선택할 수 있다.
