# 파일 기반 라우팅

## 이번 장에서 배울 것

- 파일 기반 라우팅이 무엇인지
- `pages` 폴더와 URL의 관계
- `NuxtPage`의 역할
- 여러 페이지를 만드는 방법

## 라우팅이란

라우팅은 주소에 따라 어떤 화면을 보여 줄지 정하는 일이다.

예를 들어 사용자가 `/about` 주소로 이동하면 소개 페이지를 보여 주고, `/posts` 주소로 이동하면 게시글 목록을 보여 주는 것이 라우팅이다.

일반 Vue 프로젝트에서는 Vue Router에 라우트 목록을 직접 작성하는 경우가 많다. Nuxt는 조금 다르다. `pages` 폴더의 파일 구조를 보고 라우트를 자동으로 만든다.

## pages 폴더와 URL

Nuxt에서 `pages` 폴더 안에 `.vue` 파일을 만들면 주소가 자동으로 생성된다.

```txt
pages/
  index.vue
  about.vue
  contact.vue
```

위 구조는 다음 주소와 연결된다.

```txt
pages/index.vue    -> /
pages/about.vue    -> /about
pages/contact.vue  -> /contact
```

이처럼 파일 이름과 폴더 구조가 URL이 되는 방식을 파일 기반 라우팅이라고 한다.

## NuxtPage

페이지를 화면에 보여 주려면 `app.vue`에 `<NuxtPage />`가 있어야 한다.

```vue
<template>
  <NuxtPage />
</template>
```

`<NuxtPage />`는 현재 주소에 맞는 페이지 컴포넌트를 렌더링하는 자리다.

예를 들어 브라우저 주소가 `/about`이면 `pages/about.vue`가 이 위치에 나타난다.

## 첫 번째 여러 페이지 만들기

먼저 `pages/index.vue`를 만든다.

```vue
<template>
  <main>
    <h1>홈</h1>
    <p>첫 화면입니다.</p>
  </main>
</template>
```

그다음 `pages/about.vue`를 만든다.

```vue
<template>
  <main>
    <h1>소개</h1>
    <p>Nuxt 파일 기반 라우팅을 배우고 있습니다.</p>
  </main>
</template>
```

브라우저에서 `/`와 `/about`을 각각 열어 보면 다른 페이지가 보인다.

## 폴더를 사용한 경로

폴더를 만들면 더 깊은 주소를 만들 수 있다.

```txt
pages/
  posts/
    index.vue
    popular.vue
```

이 구조는 다음 주소와 연결된다.

```txt
pages/posts/index.vue    -> /posts
pages/posts/popular.vue  -> /posts/popular
```

`index.vue`는 해당 폴더의 기본 페이지 역할을 한다.

## 파일 기반 라우팅의 장점

파일 기반 라우팅은 페이지가 많아질수록 장점이 커진다.

- 주소 구조를 폴더만 보고 이해할 수 있다.
- 라우트 설정 파일을 길게 작성하지 않아도 된다.
- 페이지 파일을 추가하면 라우트가 자동으로 생긴다.
- 코드 분할이 자연스럽게 적용된다.

초보자에게도 좋은 방식이다. "어떤 주소가 어떤 파일인지"를 찾기 쉽기 때문이다.

## 자주 하는 실수

가장 흔한 실수는 `pages` 폴더를 만들고도 `app.vue`에 `<NuxtPage />`를 넣지 않는 것이다.

또 하나는 `pages` 폴더를 `src` 같은 다른 폴더 안에 잘못 만드는 경우다. 기본 구조에서는 프로젝트 루트에 `pages` 폴더를 만든다.

## 정리

Nuxt는 `pages` 폴더의 파일 구조를 보고 라우트를 자동으로 만든다. `pages/index.vue`는 `/`, `pages/about.vue`는 `/about`이 된다. 현재 주소에 맞는 페이지는 `<NuxtPage />` 위치에 렌더링된다.
