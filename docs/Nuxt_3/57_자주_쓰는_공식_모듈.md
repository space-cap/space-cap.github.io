# 자주 쓰는 공식 모듈

## 이번 장에서 배울 것

- Nuxt에서 자주 쓰는 모듈 종류
- 각 모듈이 해결하는 문제
- 처음부터 설치하지 않아도 되는 이유
- 프로젝트 성격에 맞는 모듈 선택 기준

## 모든 모듈을 설치할 필요는 없다

Nuxt 생태계에는 많은 모듈이 있다.

하지만 프로젝트를 시작하자마자 많은 모듈을 설치하는 것은 좋지 않다. 설치한 모듈이 많아질수록 설정, 업데이트, 충돌 가능성도 늘어난다.

먼저 Nuxt의 기본 기능으로 시작하고, 필요가 분명해질 때 모듈을 추가하는 것이 좋다.

## 자주 쓰는 모듈 목록

Nuxt 프로젝트에서 자주 고려하는 모듈은 다음과 같다.

| 모듈 | 목적 |
| --- | --- |
| `@pinia/nuxt` | 상태 관리 |
| `@nuxt/image` | 이미지 최적화 |
| `@nuxt/content` | Markdown 콘텐츠 관리 |
| `@nuxtjs/i18n` | 다국어 처리 |
| `@nuxt/icon` | 아이콘 사용 |
| `@nuxt/fonts` | 웹폰트 최적화 |
| `@nuxt/eslint` | ESLint 통합 |
| `@nuxtjs/sitemap` | sitemap 생성 |
| `@nuxt/ui` | UI 컴포넌트 |

이 목록은 절대적인 필수 목록이 아니다. 프로젝트 목표에 따라 필요한 모듈만 고른다.

## Pinia

Pinia는 상태 관리에 사용한다.

```bash
npx nuxt module add pinia
```

장바구니, 사용자 정보, 관리자 설정처럼 여러 페이지에서 공유하는 상태가 많아지면 Pinia가 유용하다.

간단한 상태는 Nuxt의 `useState`로 충분할 수 있다.

## Nuxt Image

Nuxt Image는 이미지 최적화에 사용한다.

```bash
npx nuxt module add image
```

`<NuxtImg>`와 `<NuxtPicture>`를 사용해 이미지 크기, lazy loading, provider 기반 최적화를 적용할 수 있다.

이미지가 많은 블로그, 쇼핑몰, 포트폴리오 사이트에 특히 유용하다.

## Nuxt Content

Nuxt Content는 Markdown 기반 콘텐츠를 다룰 때 사용한다.

```bash
npx nuxt module add content
```

문서 사이트, 블로그, 가이드, 릴리스 노트처럼 파일 기반 콘텐츠가 많은 프로젝트에 잘 어울린다.

## Nuxt i18n

`@nuxtjs/i18n`은 다국어 처리를 위한 모듈이다.

```bash
npx nuxi@latest module add i18n
```

한국어, 영어, 일본어처럼 여러 언어를 지원해야 할 때 사용한다.

다국어 URL, 번역 메시지, 현재 언어 전환 같은 기능을 제공한다.

## Nuxt Icon

Nuxt Icon은 Iconify 기반 아이콘을 Nuxt에서 쉽게 사용할 수 있게 해 준다.

```bash
npx nuxt module add icon
```

설치 후 보통 `<Icon>` 컴포넌트로 아이콘을 사용할 수 있다.

```vue
<template>
  <Icon name="lucide:search" />
</template>
```

아이콘을 직접 SVG로 매번 복사하는 것보다 관리하기 쉽다.

## Nuxt Fonts

Nuxt Fonts는 웹폰트 로딩을 최적화하는 모듈이다.

```bash
npx nuxt module add fonts
```

CSS에서 `font-family`를 사용하면 Nuxt Fonts가 필요한 폰트를 감지하고 처리할 수 있다.

폰트는 성능에 큰 영향을 줄 수 있으므로, 운영 사이트에서는 최적화가 중요하다.

## Sitemap과 SEO 모듈

검색 노출이 중요한 사이트라면 sitemap 모듈을 고려한다.

```bash
npx nuxt module add @nuxtjs/sitemap
```

sitemap은 검색 엔진에게 사이트의 주요 URL 목록을 알려 준다.

블로그, 문서 사이트, 쇼핑몰처럼 공개 페이지가 많은 사이트에 유용하다.

## 선택 기준

처음 프로젝트에서는 다음 순서로 생각해 보자.

1. 상태가 복잡한가? 그러면 Pinia를 고려한다.
2. 이미지가 많은가? 그러면 Nuxt Image를 고려한다.
3. Markdown 콘텐츠가 많은가? 그러면 Nuxt Content를 고려한다.
4. 여러 언어를 지원해야 하는가? 그러면 i18n을 고려한다.
5. 검색 노출이 중요한가? 그러면 sitemap과 SEO 관련 모듈을 고려한다.

## 자주 하는 실수

유명한 모듈이라는 이유만으로 설치하는 실수가 많다.

모듈은 문제를 해결하기 위해 설치해야 한다. 아직 그 문제가 없다면 설치하지 않아도 된다.

또 모듈을 설치한 뒤 `nuxt.config.ts` 설정을 확인하지 않아 제대로 동작하지 않는 경우도 있다.

## 정리

Nuxt 모듈은 특정 문제를 빠르게 해결해 주는 도구다. Pinia, Image, Content, i18n, Icon, Fonts, Sitemap 같은 모듈은 자주 쓰이지만 모든 프로젝트에 필요한 것은 아니다. 프로젝트 목표에 맞게 선택해야 한다.
