# 개발 환경 준비

## 이번 장에서 배울 것

- Nuxt 3 개발에 필요한 도구
- Node.js와 패키지 매니저 확인 방법
- VS Code 추천 확장
- 터미널에서 기본 명령 확인하기

## 필요한 도구

Nuxt 3를 개발하려면 기본적으로 다음 도구가 필요하다.

- Node.js
- 패키지 매니저
- 코드 에디터
- 터미널
- 웹 브라우저

처음 배우는 단계에서는 Node.js, npm, VS Code, Chrome 또는 Edge 조합으로 시작하면 충분하다.

## Node.js 설치

Nuxt는 Node.js 환경에서 프로젝트를 만들고 개발 서버를 실행한다.

Node.js는 공식 사이트에서 LTS 버전을 설치하는 것을 권장한다. LTS는 Long Term Support의 줄임말로, 장기 지원 버전이라는 뜻이다.

설치 후 터미널에서 다음 명령을 실행한다.

```bash
node -v
```

버전이 출력되면 Node.js가 설치된 것이다.

```bash
v20.0.0
```

실제 버전 숫자는 설치 시점에 따라 다를 수 있다.

## npm 확인

Node.js를 설치하면 보통 npm도 함께 설치된다.

다음 명령으로 npm 버전을 확인한다.

```bash
npm -v
```

숫자가 출력되면 npm을 사용할 수 있다.

Nuxt는 npm뿐 아니라 pnpm, yarn, bun도 사용할 수 있다. 하지만 이 문서에서는 초보자를 위해 npm을 기준으로 설명한다.

## 코드 에디터 준비

코드 에디터는 VS Code를 추천한다. Nuxt와 Vue 개발에 필요한 확장이 많고, 초보자가 자료를 찾기도 쉽다.

추천 확장은 다음과 같다.

- Vue - Official
- ESLint
- Prettier
- GitLens

`Vue - Official` 확장은 Vue 단일 파일 컴포넌트의 문법 강조, 자동 완성, 타입 확인을 도와준다.

## 브라우저 준비

개발 중에는 브라우저 개발자 도구를 자주 사용한다.

Chrome 또는 Edge에서 다음 기능을 자주 보게 된다.

- Elements: HTML과 CSS 확인
- Console: 로그와 오류 확인
- Network: API 요청 확인
- Application: 쿠키, 로컬 스토리지 확인

Nuxt를 배우면서 오류가 나면 터미널과 브라우저 콘솔을 함께 확인하는 습관을 들이는 것이 좋다.

## 작업 폴더 만들기

프로젝트를 만들기 전에 학습용 폴더를 하나 준비한다.

예를 들어 다음과 같은 구조를 사용할 수 있다.

```txt
study/
  nuxt/
```

터미널에서 해당 폴더로 이동한 뒤 Nuxt 프로젝트를 만들면 된다.

```bash
cd study/nuxt
```

## 자주 하는 실수

Node.js가 설치되어 있는데도 명령이 실행되지 않는 경우가 있다.

이럴 때는 다음을 확인한다.

- 터미널을 완전히 닫았다가 다시 열었는지
- `node -v` 명령이 동작하는지
- 너무 오래된 Node.js 버전을 사용하고 있지 않은지
- 프로젝트 폴더가 아닌 다른 폴더에서 명령을 실행하고 있지 않은지

## 정리

Nuxt 3 개발을 시작하려면 Node.js, npm, VS Code, 브라우저, 터미널이 필요하다. 설치가 끝났다면 `node -v`와 `npm -v`로 환경을 확인한다.
