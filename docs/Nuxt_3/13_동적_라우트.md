# 동적 라우트

## 이번 장에서 배울 것

- 동적 라우트가 필요한 이유
- `[id].vue` 파일 이름의 의미
- `useRoute`로 주소 값을 읽는 방법
- 동적 라우트 검증의 기본

## 동적 라우트란

모든 페이지 주소가 고정되어 있는 것은 아니다.

게시글 상세 페이지를 생각해 보자.

```txt
/posts/1
/posts/2
/posts/3
```

주소의 앞부분 `/posts/`는 같지만 뒤의 숫자는 게시글마다 달라진다. 이런 주소를 처리하려면 동적 라우트가 필요하다.

## [id].vue 만들기

Nuxt에서는 파일 이름을 대괄호로 감싸면 동적 라우트가 된다.

```txt
pages/
  posts/
    [id].vue
```

이 파일은 다음 주소를 처리한다.

```txt
/posts/1
/posts/hello
/posts/100
```

여기서 `id`는 주소에서 바뀌는 값의 이름이다.

## route.params 읽기

`pages/posts/[id].vue`에서 주소의 `id` 값을 읽어 보자.

```vue
<script setup>
const route = useRoute()
</script>

<template>
  <main>
    <h1>게시글 상세</h1>
    <p>게시글 ID: {{ route.params.id }}</p>
  </main>
</template>
```

`/posts/3`으로 이동하면 `route.params.id` 값은 `3`이 된다.

## 숫자처럼 보여도 문자열이다

주소에서 읽은 값은 보통 문자열이다.

`/posts/3`의 `3`은 숫자처럼 보이지만 실제로는 문자열 `"3"`으로 다루는 것이 안전하다.

숫자 계산이 필요하다면 직접 변환해야 한다.

```js
const postId = Number(route.params.id)
```

변환할 때는 잘못된 값이 들어올 가능성도 함께 생각해야 한다.

## 동적 라우트로 게시글 흉내 내기

간단한 게시글 데이터를 만들어 보자.

```vue
<script setup>
const route = useRoute()

const posts = [
  { id: '1', title: '첫 번째 글' },
  { id: '2', title: '두 번째 글' }
]

const post = computed(() => {
  return posts.find((item) => item.id === route.params.id)
})
</script>

<template>
  <main>
    <template v-if="post">
      <h1>{{ post.title }}</h1>
      <p>게시글 ID: {{ post.id }}</p>
    </template>

    <template v-else>
      <h1>글을 찾을 수 없습니다.</h1>
    </template>
  </main>
</template>
```

나중에는 이 데이터를 실제 API에서 가져오게 된다.

## 라우트 검증

동적 라우트는 아무 값이나 받을 수 있다. `/posts/abc`도 `[id].vue`에 연결된다.

숫자 ID만 허용하고 싶다면 `definePageMeta`의 `validate`를 사용할 수 있다.

```vue
<script setup>
definePageMeta({
  validate(route) {
    return typeof route.params.id === 'string' && /^\d+$/.test(route.params.id)
  }
})
</script>
```

`validate`가 `false`를 반환하면 Nuxt는 해당 페이지를 유효하지 않은 라우트로 처리한다.

## 자주 하는 실수

동적 라우트에서 가장 흔한 실수는 값이 항상 있다고 믿는 것이다.

사용자는 잘못된 주소를 직접 입력할 수 있다. 따라서 상세 페이지에서는 데이터가 없을 때의 화면도 준비해야 한다.

## 정리

Nuxt에서 `[id].vue`처럼 대괄호를 사용하면 동적 라우트를 만들 수 있다. 주소의 값은 `useRoute()`의 `route.params`에서 읽는다.
