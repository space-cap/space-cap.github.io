# 개발 서버와 빌드 명령어

## 이번 장에서 배울 것

- `npm run dev`의 역할
- `npm run build`와 `npm run preview`의 차이
- `npm run generate`가 언제 쓰이는지
- 개발 모드와 운영 모드의 차이

## package.json의 scripts

Nuxt 프로젝트의 실행 명령은 `package.json`에 들어 있다.

보통 다음과 같은 형태다.

```json
{
  "scripts": {
    "dev": "nuxt dev",
    "build": "nuxt build",
    "generate": "nuxt generate",
    "preview": "nuxt preview"
  }
}
```

우리가 터미널에서 실행하는 `npm run dev`는 `scripts` 안의 `dev` 명령을 실행한다.

## npm run dev

`npm run dev`는 개발 서버를 실행한다.

```bash
npm run dev
```

개발 서버는 코드를 작성하면서 바로 확인하기 위한 서버다.

특징은 다음과 같다.

- 파일을 수정하면 화면이 자동으로 갱신된다.
- 오류 메시지를 개발자가 보기 쉽게 보여 준다.
- 최종 배포용으로 최적화된 상태는 아니다.
- 로컬 개발 환경에서 사용한다.

처음 Nuxt를 배울 때 가장 자주 사용하는 명령이다.

## npm run build

`npm run build`는 운영 환경에서 실행할 수 있도록 앱을 빌드한다.

```bash
npm run build
```

빌드는 개발 중인 코드를 실제 서비스에 가까운 형태로 변환하는 과정이다.

빌드 과정에서는 다음과 같은 일이 일어난다.

- 필요한 파일을 묶는다.
- 사용하지 않는 코드를 줄인다.
- 서버 실행에 필요한 결과물을 만든다.
- 배포 환경에 맞게 최적화한다.

빌드에 성공하면 코드 문법 오류나 설정 문제를 미리 발견할 수 있다.

## npm run preview

`npm run preview`는 빌드된 결과물을 로컬에서 확인한다.

```bash
npm run build
npm run preview
```

`dev`는 개발용 서버이고, `preview`는 빌드 결과 확인용 서버다.

배포 전에 `build`와 `preview`를 실행해 보면 개발 서버에서는 몰랐던 문제를 찾을 수 있다.

## npm run generate

`npm run generate`는 정적 사이트를 생성할 때 사용한다.

```bash
npm run generate
```

정적 사이트는 서버에서 매번 HTML을 만드는 대신, 빌드 시점에 HTML 파일을 미리 만들어 두는 방식이다.

블로그, 문서 사이트, 회사 소개 페이지처럼 사용자마다 내용이 크게 달라지지 않는 사이트에 잘 어울린다.

다만 로그인 사용자별 화면이나 실시간 데이터가 중요한 서비스는 정적 생성만으로 충분하지 않을 수 있다.

## dev와 build의 차이

개발할 때는 보통 `dev`만 실행하면 된다.

하지만 배포 전에는 반드시 `build`를 확인하는 것이 좋다.

| 명령 | 목적 | 사용하는 시점 |
| --- | --- | --- |
| `npm run dev` | 개발 서버 실행 | 코드를 작성하는 동안 |
| `npm run build` | 운영용 결과물 생성 | 배포 전 |
| `npm run preview` | 빌드 결과 확인 | 배포 전 최종 확인 |
| `npm run generate` | 정적 사이트 생성 | 정적 배포가 필요할 때 |

## 자주 하는 실수

개발 서버에서 잘 보인다고 해서 배포도 반드시 성공하는 것은 아니다.

개발 서버는 개발자 편의를 위해 느슨하게 동작하거나 빠른 피드백을 우선한다. 운영 빌드는 더 엄격하게 코드를 확인할 수 있다.

그래서 다음 습관이 좋다.

```bash
npm run build
```

새 기능을 어느 정도 만든 뒤에는 빌드를 한 번 실행해 보는 것이 좋다.

## 정리

`npm run dev`는 개발 중에 사용하고, `npm run build`는 운영용 결과물을 만들 때 사용한다. `npm run preview`는 빌드 결과를 로컬에서 확인하는 명령이고, `npm run generate`는 정적 사이트를 만들 때 사용한다.
