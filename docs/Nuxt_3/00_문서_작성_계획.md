# Nuxt 3 초보자 학습 문서 작성 계획서

> 작성 기준일: 2026-05-20  
> 목표: Nuxt 3를 처음 배우는 사람도 웹 애플리케이션의 탄생 배경, 설치, 기본 문법, 라우팅, 데이터 통신, 서버 기능, 배포와 실무 프로젝트까지 차근차근 익힐 수 있도록 여러 문서로 나누어 정리한다.

---

## 1. 문서 작성 방향

이 문서는 Nuxt 3 학습 자료 전체를 만들기 위한 계획서다. 한 문서에 모든 내용을 몰아넣지 않고, 책의 목차처럼 작은 문서로 나누어 작성한다.

각 문서는 독립적으로 읽을 수 있어야 하지만, 전체 순서를 따라가면 하나의 학습 흐름이 되도록 구성한다. 초반에는 Nuxt가 왜 만들어졌는지, Vue와 어떤 관계인지, SSR과 SSG가 왜 필요한지부터 설명한다. 이후 설치, 폴더 구조, 페이지, 레이아웃, 컴포넌트, 데이터 가져오기, 서버 API, 인증, 상태 관리, 배포, 테스트, 성능 최적화 순서로 확장한다.

초보자를 위해 어려운 용어는 처음 등장할 때 쉬운 말로 풀어쓴다. 예제 코드는 처음에는 작고 단순하게 시작하고, 뒤로 갈수록 실제 서비스에 가까운 구조로 확장한다.

---

## 2. 예상 독자

- HTML, CSS, JavaScript를 조금 알고 있고 Vue 또는 Nuxt를 처음 배우는 사람
- Vue는 배웠지만 Nuxt의 라우팅, SSR, 서버 API, 배포 흐름이 낯선 사람
- 블로그, 게시판, 관리자 페이지, 쇼핑몰 같은 웹 서비스를 직접 만들어 보고 싶은 사람
- Nuxt 3 프로젝트 구조와 실무 개발 흐름을 처음부터 끝까지 이해하고 싶은 사람

---

## 3. 학습 목표

문서 전체를 따라가면 독자는 다음을 할 수 있어야 한다.

- Nuxt가 왜 만들어졌고 Vue와 어떤 관계인지 설명할 수 있다.
- CSR, SSR, SSG, ISR의 차이를 초보자 관점에서 이해할 수 있다.
- Nuxt 3 프로젝트를 설치하고 개발 서버를 실행할 수 있다.
- `pages`, `layouts`, `components`, `composables`, `plugins`, `server` 폴더의 역할을 이해할 수 있다.
- 파일 기반 라우팅으로 페이지를 만들고 동적 라우트를 구성할 수 있다.
- `useFetch`, `useAsyncData`, `$fetch`로 데이터를 가져올 수 있다.
- Nitro 기반 서버 라우트와 API를 만들 수 있다.
- Pinia, 쿠키, 세션, 토큰을 활용한 상태 관리와 인증 흐름을 이해할 수 있다.
- SEO, 메타 태그, 이미지 최적화, 성능 최적화의 기본을 적용할 수 있다.
- 테스트, 린팅, 빌드, 배포, 운영 환경 설정까지 경험할 수 있다.
- 작은 실습 프로젝트를 Nuxt 3로 직접 완성할 수 있다.

## 8. 문서 작성 원칙

- 초보자를 기준으로 설명한다.
- 한 문서에는 하나의 큰 주제만 담는다.
- 문서 제목만 보아도 무엇을 배우는지 알 수 있게 한다.
- 어려운 용어는 쉬운 말로 먼저 설명하고, 공식 용어를 나중에 연결한다.
- 예제 코드는 처음에는 짧게, 뒤로 갈수록 실무 구조에 가깝게 만든다.
- 각 장 끝에는 반드시 짧은 정리와 다음 장 안내를 둔다.
- Nuxt 3 기준으로 작성하고, Nuxt 2 내용은 비교가 필요한 경우에만 짧게 다룬다.
- 보안, 성능, 배포 같은 실무 주제는 입문자가 겁먹지 않도록 작은 사례부터 설명한다.

## 10. 최종 목표

이 문서 묶음의 최종 목표는 단순히 Nuxt 문법을 나열하는 것이 아니다. 독자가 Nuxt 3로 실제 웹 서비스를 만들 때 필요한 흐름을 이해하고, 새로운 프로젝트를 시작할 때 무엇을 어디에 작성해야 하는지 스스로 판단할 수 있게 만드는 것이다.

따라서 문서는 다음 순서의 경험을 제공해야 한다.

1. Nuxt가 필요한 이유를 이해한다.
2. 프로젝트를 직접 만든다.
3. 페이지와 화면 구조를 만든다.
4. 데이터를 가져오고 서버 API를 만든다.
5. 로그인과 상태 관리를 적용한다.
6. SEO, 성능, 보안을 챙긴다.
7. 테스트하고 배포한다.
8. 실습 프로젝트로 전체 흐름을 복습한다.
