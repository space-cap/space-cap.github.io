- Nuxt Content 기반 블로그 폴더 구조

## 만들 블로그 구조

이번 장에서는 다음 구조를 목표로 한다.

```txt
content/
  blog/
    hello-nuxt.md
    data-fetching.md

pages/
  blog/
    index.vue
    [slug].vue

content.config.ts
```

`content/blog`에는 Markdown 글을 두고, `pages/blog`에는 실제 페이지를 만든다.

## collection schema

`content.config.ts`

```ts
import { defineCollection, defineContentConfig } from '@nuxt/content'
import { z } from 'zod'

export default defineContentConfig({
  collections: {
    blog: defineCollection({
      type: 'page',
      source: 'blog/*.md',
      schema: z.object({
        title: z.string(),
        description: z.string(),
        date: z.string(),
        tags: z.array(z.string()).default([])
      })
    })
  }
})
```

schema를 정의하면 글마다 필요한 메타 정보를 일정하게 유지할 수 있다.

## 블로그 목록 페이지

`pages/blog/index.vue`

```vue
<script setup>
const { data: posts } = await useAsyncData('blog-posts', () => {
  return queryCollection('blog')
    .order('date', 'DESC')
    .all()
})

useSeoMeta({
  title: '블로그',
  description: 'Nuxt 학습 블로그 글 목록입니다.'
})
</script>

<template>
  <main>
    <h1>블로그</h1>

    <article v-for="post in posts" :key="post.path">
      <h2>
        <NuxtLink :to="post.path">
          {{ post.title }}
        </NuxtLink>
      </h2>
      <p>{{ post.description }}</p>
      <time>{{ post.date }}</time>
    </article>
  </main>
</template>
```

목록 페이지는 날짜순으로 글을 보여 준다.

## 블로그 상세 페이지

`pages/blog/[slug].vue`

```vue
<script setup>
const route = useRoute()
const slug = route.params.slug

const { data: post } = await useAsyncData(`blog-${slug}`, () => {
  return queryCollection('blog')
    .path(`/blog/${slug}`)
    .first()
})

if (!post.value) {
  throw createError({
    statusCode: 404,
    statusMessage: '글을 찾을 수 없습니다.'
  })
}

useSeoMeta({
  title: () => post.value?.title || '블로그',
  description: () => post.value?.description || '블로그 글입니다.'
})
</script>

<template>
  <main>
    <ContentRenderer :value="post" />
  </main>
</template>
```

글이 없으면 404로 처리하고, 글이 있으면 Markdown을 렌더링한다.

## 태그 표시하기

목록 페이지에서 태그를 보여 줄 수 있다.

```vue
<template>
  <article v-for="post in posts" :key="post.path">
    <h2>{{ post.title }}</h2>

    <ul>
      <li v-for="tag in post.tags" :key="tag">
        {{ tag }}
      </li>
    </ul>
  </article>
</template>
```

처음에는 태그 표시만 하고, 나중에 태그별 필터 페이지를 만들 수 있다.

## 검색 기능 방향

간단한 검색은 목록을 가져온 뒤 클라이언트에서 필터링할 수 있다.

```vue
<script setup>
const keyword = ref('')

const filteredPosts = computed(() => {
  if (!posts.value) {
    return []
  }

  return posts.value.filter((post) => {
    return post.title.includes(keyword.value)
      || post.description.includes(keyword.value)
  })
})
</script>
```

글이 많아지면 서버 쿼리나 전문 검색 도구를 고려해야 한다.

## 블로그에서 챙길 SEO

블로그는 검색 노출이 중요한 경우가 많다.

다음 항목을 챙기자.

- 글마다 고유한 title
- 글마다 고유한 description
- 없는 글은 404 처리
- sitemap에 글 상세 URL 포함
- 공유 이미지 설정
- 날짜와 태그 같은 구조화된 정보 관리

## 자주 하는 실수

목록 페이지는 잘 만들었지만 상세 페이지 SEO를 잊는 경우가 많다.

블로그에서 검색에 노출되는 핵심은 보통 상세 글이다. 글마다 title과 description을 설정하고, 없는 글은 404로 처리해야 한다.

## 정리

Nuxt Content 기반 블로그는 `content/blog`의 Markdown 파일과 `pages/blog`의 목록/상세 페이지로 구성할 수 있다. `queryCollection`으로 글을 조회하고, `<ContentRenderer>`로 렌더링하며, frontmatter를 SEO와 목록 정보에 활용한다.
