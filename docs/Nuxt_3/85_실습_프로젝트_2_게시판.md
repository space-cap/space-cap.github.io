# 실습 프로젝트 2: 게시판

## 이번 프로젝트에서 만들 것

Nuxt의 `server/api`를 사용해 간단한 게시판을 만든다.

이 프로젝트에서 연습할 내용은 다음과 같다.

- 게시글 목록 조회
- 게시글 상세 조회
- 게시글 작성
- 게시글 수정
- 게시글 삭제
- 서버 API와 페이지 연결
- 폼 검증과 에러 처리

## 목표 화면

```txt
/posts
  게시글 목록

/posts/new
  게시글 작성

/posts/1
  게시글 상세

/posts/1/edit
  게시글 수정
```

## 1단계: 임시 데이터 만들기

처음에는 DB 없이 메모리 배열로 시작한다.

`server/utils/posts.ts`

```ts
export type Post = {
  id: number
  title: string
  content: string
}

export const posts: Post[] = [
  {
    id: 1,
    title: '첫 번째 글',
    content: '게시판 실습을 시작합니다.'
  }
]
```

개발 서버를 재시작하면 메모리 데이터는 초기화된다. 학습용으로만 사용한다.

## 2단계: 목록 API

`server/api/posts/index.get.ts`

```ts
export default defineEventHandler(() => {
  return posts
})
```

`server/utils/posts.ts`의 `posts`는 server 영역에서 자동 import될 수 있다.

## 3단계: 상세 API

`server/api/posts/[id].get.ts`

```ts
export default defineEventHandler((event) => {
  const id = Number(getRouterParam(event, 'id'))
  const post = posts.find((item) => item.id === id)

  if (!post) {
    throw createError({
      statusCode: 404,
      statusMessage: '게시글을 찾을 수 없습니다.'
    })
  }

  return post
})
```

## 4단계: 작성 API

`server/api/posts/index.post.ts`

```ts
export default defineEventHandler(async (event) => {
  const body = await readBody(event)

  if (!body.title || !body.content) {
    throw createError({
      statusCode: 400,
      statusMessage: '제목과 내용은 필수입니다.'
    })
  }

  const post = {
    id: Date.now(),
    title: body.title,
    content: body.content
  }

  posts.unshift(post)

  setResponseStatus(event, 201)

  return post
})
```

## 5단계: 게시글 목록 페이지

`pages/posts/index.vue`

```vue
<script setup>
const { data: posts, status, error } = await useFetch('/api/posts', {
  default: () => []
})

useSeoMeta({
  title: '게시판',
  description: 'Nuxt 게시판 실습 글 목록입니다.'
})
</script>

<template>
  <main>
    <h1>게시판</h1>
    <NuxtLink to="/posts/new">글쓰기</NuxtLink>

    <p v-if="status === 'pending'">불러오는 중...</p>
    <p v-else-if="error">게시글을 불러오지 못했습니다.</p>
    <p v-else-if="posts.length === 0">게시글이 없습니다.</p>

    <ul v-else>
      <li v-for="post in posts" :key="post.id">
        <NuxtLink :to="`/posts/${post.id}`">
          {{ post.title }}
        </NuxtLink>
      </li>
    </ul>
  </main>
</template>
```

## 6단계: 작성 페이지

`pages/posts/new.vue`

```vue
<script setup>
const title = ref('')
const content = ref('')
const errorMessage = ref('')

const submit = async () => {
  errorMessage.value = ''

  try {
    const post = await $fetch('/api/posts', {
      method: 'POST',
      body: {
        title: title.value,
        content: content.value
      }
    })

    await navigateTo(`/posts/${post.id}`)
  } catch {
    errorMessage.value = '게시글 작성에 실패했습니다.'
  }
}
</script>

<template>
  <main>
    <h1>글쓰기</h1>

    <form @submit.prevent="submit">
      <input v-model="title" placeholder="제목" />
      <textarea v-model="content" placeholder="내용" />
      <p v-if="errorMessage">{{ errorMessage }}</p>
      <button type="submit">저장</button>
    </form>
  </main>
</template>
```

## 7단계: 상세 페이지

`pages/posts/[id].vue`

```vue
<script setup>
const route = useRoute()

const { data: post, error } = await useFetch(`/api/posts/${route.params.id}`)

if (error.value || !post.value) {
  throw createError({
    statusCode: 404,
    statusMessage: '게시글을 찾을 수 없습니다.'
  })
}

useSeoMeta({
  title: () => post.value?.title || '게시글',
  description: () => post.value?.content?.slice(0, 80) || '게시글 상세'
})
</script>

<template>
  <main>
    <h1>{{ post.title }}</h1>
    <p>{{ post.content }}</p>
    <NuxtLink :to="`/posts/${post.id}/edit`">수정</NuxtLink>
  </main>
</template>
```

## 8단계: 수정과 삭제

수정 API:

```txt
server/api/posts/[id].put.ts
```

삭제 API:

```txt
server/api/posts/[id].delete.ts
```

구조는 상세 API와 비슷하다. ID로 게시글을 찾고, 없으면 404를 반환한다. 수정은 body를 읽어 값을 바꾸고, 삭제는 배열에서 제거한다.
