# 페이지네이션과 검색

## 이번 장에서 배울 것

- query string으로 검색 조건을 표현하는 방법
- `useFetch`에서 query를 사용하는 방법
- 검색어 변경 시 데이터를 다시 가져오는 방법
- 페이지 번호와 검색 조건을 URL에 반영하는 방법

## 페이지네이션과 검색이 필요한 이유

게시글이나 상품이 많아지면 한 번에 모든 데이터를 보여 줄 수 없다.

그래서 보통 다음 기능이 필요하다.

- 페이지 번호
- 검색어
- 카테고리
- 정렬 조건

이런 조건은 URL query string으로 표현하면 좋다.

```txt
/posts?page=2&q=nuxt
```

이 주소는 "게시글 목록에서 2페이지를 보고 있고, 검색어는 nuxt"라는 의미로 읽을 수 있다.

## query string 읽기

`useRoute`로 현재 query 값을 읽을 수 있다.

```vue
<script setup>
const route = useRoute()

const page = computed(() => Number(route.query.page || 1))
const keyword = computed(() => String(route.query.q || ''))
</script>
```

query 값은 문자열이거나 없을 수 있다. 숫자로 써야 한다면 직접 변환한다.

## useFetch에 query 전달하기

`useFetch`의 `query` 옵션에 검색 조건을 넣을 수 있다.

```vue
<script setup>
const route = useRoute()

const page = computed(() => Number(route.query.page || 1))
const keyword = computed(() => String(route.query.q || ''))

const { data, status, error } = await useFetch('/api/posts', {
  query: {
    page,
    q: keyword
  },
  default: () => ({
    items: [],
    total: 0
  })
})
</script>
```

`page`나 `keyword`가 바뀌면 `useFetch`가 새 조건으로 다시 요청할 수 있다.

## 검색 폼 만들기

검색 입력값을 별도 상태로 둔다.

```vue
<script setup>
const route = useRoute()
const router = useRouter()

const searchText = ref(String(route.query.q || ''))

const submitSearch = () => {
  router.push({
    path: '/posts',
    query: {
      ...route.query,
      page: 1,
      q: searchText.value || undefined
    }
  })
}
</script>

<template>
  <form @submit.prevent="submitSearch">
    <input v-model="searchText" placeholder="검색어" />
    <button type="submit">검색</button>
  </form>
</template>
```

검색 버튼을 누르면 URL query가 바뀐다. URL이 바뀌면 `useFetch`가 새로운 조건으로 데이터를 가져온다.

## 페이지 이동 버튼 만들기

페이지 번호도 query로 관리한다.

```vue
<script setup>
const route = useRoute()
const router = useRouter()

const page = computed(() => Number(route.query.page || 1))

const movePage = (nextPage) => {
  router.push({
    path: '/posts',
    query: {
      ...route.query,
      page: nextPage
    }
  })
}
</script>

<template>
  <button :disabled="page <= 1" @click="movePage(page - 1)">
    이전
  </button>
  <span>{{ page }} 페이지</span>
  <button @click="movePage(page + 1)">
    다음
  </button>
</template>
```

페이지 번호를 URL에 남기면 새로고침해도 같은 페이지를 볼 수 있고, 다른 사람에게 링크를 공유하기도 쉽다.

## 전체 예시

```vue
<script setup>
const route = useRoute()
const router = useRouter()

const page = computed(() => Number(route.query.page || 1))
const keyword = computed(() => String(route.query.q || ''))
const searchText = ref(keyword.value)

const { data, status, error } = await useFetch('/api/posts', {
  query: {
    page,
    q: keyword
  },
  default: () => ({
    items: [],
    total: 0
  })
})

const submitSearch = () => {
  router.push({
    path: '/posts',
    query: {
      page: 1,
      q: searchText.value || undefined
    }
  })
}

const movePage = (nextPage) => {
  router.push({
    path: '/posts',
    query: {
      ...route.query,
      page: nextPage
    }
  })
}
</script>

<template>
  <section>
    <h1>게시글</h1>

    <form @submit.prevent="submitSearch">
      <input v-model="searchText" placeholder="검색어" />
      <button type="submit">검색</button>
    </form>

    <p v-if="status === 'pending'">불러오는 중...</p>
    <p v-else-if="error">게시글을 불러오지 못했습니다.</p>
    <p v-else-if="data.items.length === 0">검색 결과가 없습니다.</p>

    <ul v-else>
      <li v-for="post in data.items" :key="post.id">
        {{ post.title }}
      </li>
    </ul>

    <div>
      <button :disabled="page <= 1" @click="movePage(page - 1)">
        이전
      </button>
      <span>{{ page }} 페이지</span>
      <button @click="movePage(page + 1)">
        다음
      </button>
    </div>
  </section>
</template>
```

## 자주 하는 실수

검색 조건을 컴포넌트 내부 상태로만 관리하면 새로고침했을 때 조건이 사라진다.

검색어, 페이지 번호, 정렬처럼 사용자가 공유하거나 다시 방문할 수 있어야 하는 조건은 URL query에 넣는 것이 좋다.

## 정리

페이지네이션과 검색 조건은 URL query string으로 관리하면 좋다. `useRoute`로 query를 읽고, `useRouter`로 query를 바꾸며, `useFetch`의 `query` 옵션으로 API 요청 조건을 전달할 수 있다.
