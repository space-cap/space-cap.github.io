# 실습 프로젝트 4: 쇼핑몰 상품 목록

## 이번 프로젝트에서 만들 것

상품 목록, 검색, 카테고리 필터, 페이지네이션을 만든다.

이 프로젝트에서 연습할 내용은 다음과 같다.

- query string 기반 검색 조건
- `useFetch`의 query 옵션
- 서버 API에서 query 처리
- 빈 상태와 로딩 상태
- 상품 카드 컴포넌트
- URL에 검색 조건 유지

## 목표 화면

```txt
/products
  상품 목록
  검색어 입력
  카테고리 필터
  페이지네이션
```

검색 조건은 URL에 남긴다.

```txt
/products?q=shirt&category=clothes&page=2
```

## 1단계: 상품 데이터 만들기

`server/utils/products.ts`

```ts
export type Product = {
  id: number
  name: string
  category: string
  price: number
}

export const products: Product[] = [
  { id: 1, name: '검은 티셔츠', category: 'clothes', price: 19000 },
  { id: 2, name: '흰 운동화', category: 'shoes', price: 59000 },
  { id: 3, name: '가죽 가방', category: 'bags', price: 89000 }
]
```

## 2단계: 상품 목록 API

`server/api/products.get.ts`

```ts
export default defineEventHandler((event) => {
  const query = getQuery(event)

  const q = String(query.q || '')
  const category = String(query.category || '')
  const page = Number(query.page || 1)
  const pageSize = 10

  let filtered = products

  if (q) {
    filtered = filtered.filter((product) => {
      return product.name.includes(q)
    })
  }

  if (category) {
    filtered = filtered.filter((product) => {
      return product.category === category
    })
  }

  const start = (page - 1) * pageSize
  const items = filtered.slice(start, start + pageSize)

  return {
    items,
    total: filtered.length,
    page,
    pageSize
  }
})
```

## 4단계: 목록 페이지 상태

`pages/products/index.vue`

```vue
<script setup>
const route = useRoute()
const router = useRouter()

const keyword = computed(() => String(route.query.q || ''))
const category = computed(() => String(route.query.category || ''))
const page = computed(() => Number(route.query.page || 1))

const searchText = ref(keyword.value)

const { data, status, error } = await useFetch('/api/products', {
  query: {
    q: keyword,
    category,
    page
  },
  default: () => ({
    items: [],
    total: 0,
    page: 1,
    pageSize: 10
  })
})
</script>
```

## 5단계: 검색과 필터

```vue
<script setup>
const submitSearch = () => {
  router.push({
    path: '/products',
    query: {
      ...route.query,
      q: searchText.value || undefined,
      page: 1
    }
  })
}

const changeCategory = (nextCategory) => {
  router.push({
    path: '/products',
    query: {
      ...route.query,
      category: nextCategory || undefined,
      page: 1
    }
  })
}
</script>
```

## 6단계: 템플릿 작성

```vue
<template>
  <main>
    <h1>상품 목록</h1>

    <form @submit.prevent="submitSearch">
      <input v-model="searchText" placeholder="상품 검색" />
      <button type="submit">검색</button>
    </form>

    <div>
      <button @click="changeCategory('')">전체</button>
      <button @click="changeCategory('clothes')">의류</button>
      <button @click="changeCategory('shoes')">신발</button>
      <button @click="changeCategory('bags')">가방</button>
    </div>

    <p v-if="status === 'pending'">불러오는 중...</p>
    <p v-else-if="error">상품을 불러오지 못했습니다.</p>
    <p v-else-if="data.items.length === 0">상품이 없습니다.</p>

    <div v-else>
      <ProductCard
        v-for="product in data.items"
        :key="product.id"
        :product="product"
      />
    </div>
  </main>
</template>
```

## 7단계: 페이지네이션

```vue
<script setup>
const totalPages = computed(() => {
  return Math.ceil(data.value.total / data.value.pageSize)
})

const movePage = (nextPage) => {
  router.push({
    path: '/products',
    query: {
      ...route.query,
      page: nextPage
    }
  })
}
</script>

<template>
  <div>
    <button :disabled="page <= 1" @click="movePage(page - 1)">
      이전
    </button>
    <span>{{ page }} / {{ totalPages }}</span>
    <button :disabled="page >= totalPages" @click="movePage(page + 1)">
      다음
    </button>
  </div>
</template>
```

## 체크리스트

- 검색어가 URL query에 남는가?
- 카테고리 변경 시 목록이 다시 요청되는가?
- 페이지 이동 후 새로고침해도 같은 조건이 유지되는가?
- 상품이 없을 때 빈 상태가 보이는가?
- 서버 API에서 query 값을 안전하게 기본 처리하는가?

## 정리

쇼핑몰 상품 목록 프로젝트에서는 검색, 필터, 페이지네이션을 URL query와 연결하는 법을 연습한다. 실무에서 목록 화면은 매우 자주 등장하므로 꼭 익숙해져야 하는 패턴이다.
