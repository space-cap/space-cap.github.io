- 전역 CSS와 scoped CSS의 차이

- 초보자에게 추천하는 스타일링 흐름

## Nuxt에서 스타일을 작성하는 방법

Nuxt는 스타일링 방식이 유연하다. 프로젝트 성격에 따라 여러 방법을 선택할 수 있다.

대표적인 방법은 다음과 같다.

- 컴포넌트의 `<style>` 블록
- scoped CSS
- 전역 CSS
- CSS Modules
- Sass 같은 CSS 전처리기
- Tailwind CSS 같은 CSS 프레임워크
- Nuxt UI 같은 UI 라이브러리

처음에는 전역 CSS와 scoped CSS만 알아도 충분하다.

## 컴포넌트 안에 스타일 작성하기

Vue 단일 파일 컴포넌트에서는 `<style>` 블록에 CSS를 작성할 수 있다.

```vue
<template>
  <section class="hero">
    <h1>Nuxt 3</h1>
    <p>스타일링을 배워 봅니다.</p>
  </section>
</template>

<style>
.hero {
  padding: 40px;
}
</style>
```

이 방식은 간단하지만, 스타일이 전역으로 적용될 수 있다. 같은 클래스 이름을 다른 곳에서도 쓰면 영향을 줄 수 있다.

## scoped CSS

`scoped`를 붙이면 해당 컴포넌트에만 스타일이 적용된다.

```vue
<template>
  <article class="card">
    <h2>게시글 제목</h2>
    <p>게시글 설명입니다.</p>
  </article>
</template>

<style scoped>
.card {
  border: 1px solid #ddd;
  padding: 16px;
}
</style>
```

초보자에게는 scoped CSS가 이해하기 쉽다. 컴포넌트와 스타일을 한 파일에서 함께 볼 수 있기 때문이다.

## 전역 CSS

사이트 전체에 적용할 스타일은 전역 CSS로 관리한다.

예를 들어 기본 폰트, body 여백, 링크 색상 같은 설정은 전역 CSS에 두기 좋다.

```txt
assets/
  css/
    main.css
```

`assets/css/main.css`

```css
body {
  margin: 0;
  font-family: system-ui, sans-serif;
}

a {
  color: inherit;
}
```

`nuxt.config.ts`에 등록한다.

```ts
export default defineNuxtConfig({
  css: ['~/assets/css/main.css']
})
```

## CSS Modules

CSS Modules는 클래스 이름 충돌을 줄이기 위한 방식이다.

Nuxt에서도 사용할 수 있지만, 초보 단계에서 반드시 먼저 배울 필요는 없다. 컴포넌트 단위 스타일에는 scoped CSS만으로도 충분한 경우가 많다.

나중에 큰 프로젝트에서 스타일 충돌을 더 엄격하게 관리하고 싶을 때 CSS Modules를 살펴보면 된다.

## Sass 같은 전처리기

Sass는 CSS를 더 편하게 작성하게 해 주는 전처리기다.

변수, 중첩, mixin 같은 기능을 사용할 수 있다.

```vue
<style lang="scss" scoped>
$primary: #2563eb;

.button {
  background: $primary;

  &:hover {
    background: #1d4ed8;
  }
}
</style>
```

하지만 처음 Nuxt를 배우는 단계에서는 일반 CSS로 시작해도 충분하다.

## Tailwind CSS

Tailwind CSS는 미리 정의된 유틸리티 클래스를 조합해 스타일을 작성하는 방식이다.

```vue
<template>
  <button class="rounded bg-blue-600 px-4 py-2 text-white">
    저장
  </button>
</template>
```

빠르게 화면을 만들 수 있지만 클래스가 길어질 수 있다. 팀이나 프로젝트의 스타일링 취향에 따라 선택하면 된다.

## 초보자 추천 흐름

처음에는 다음 순서로 익히는 것을 추천한다.

1. 컴포넌트 안에서 scoped CSS 사용
2. 공통 기본값은 전역 CSS로 분리
3. 반복되는 UI는 컴포넌트로 분리
4. 필요해지면 Tailwind CSS나 UI 라이브러리 도입
5. 규모가 커지면 디자인 시스템이나 공통 컴포넌트 규칙 정리

처음부터 도구를 많이 붙이면 Nuxt 자체를 배우기 전에 설정에서 지칠 수 있다.

## 자주 하는 실수

전역 CSS에 너무 많은 스타일을 넣으면 어디서 어떤 스타일이 적용되는지 추적하기 어려워진다.

반대로 모든 스타일을 컴포넌트마다 따로 작성하면 버튼, 카드, 입력 폼 같은 UI가 페이지마다 조금씩 달라질 수 있다.

공통 스타일과 개별 스타일의 균형이 중요하다.

## 정리

Nuxt에서는 전역 CSS, scoped CSS, CSS Modules, 전처리기, CSS 프레임워크, UI 라이브러리 등 다양한 스타일링 방식을 사용할 수 있다. 처음에는 scoped CSS와 전역 CSS를 중심으로 시작하는 것이 좋다.
