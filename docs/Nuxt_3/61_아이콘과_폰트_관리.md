# 아이콘과 폰트 관리

## 이번 장에서 배울 것

- Nuxt에서 아이콘을 사용하는 방법
- Nuxt Icon의 기본 사용법
- 웹폰트를 관리하는 방법
- 폰트 로딩 성능을 고려하는 방법

## 아이콘과 폰트가 중요한 이유

아이콘과 폰트는 화면의 인상을 크게 좌우한다.

하지만 무분별하게 사용하면 성능에 영향을 줄 수 있다.

- 너무 많은 아이콘 라이브러리 설치
- 큰 폰트 파일 여러 개 로딩
- 사용하지 않는 굵기와 스타일 포함
- 외부 폰트 서버 요청 지연

Nuxt에서는 아이콘과 폰트를 모듈로 관리할 수 있다.

## Nuxt Icon 설치

Nuxt Icon은 Iconify 기반 아이콘을 Nuxt에서 쉽게 사용할 수 있게 해 준다.

```bash
npx nuxt module add icon
```

수동 등록은 다음처럼 한다.

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/icon']
})
```

## Icon 컴포넌트 사용하기

설치 후 `<Icon>` 컴포넌트를 사용할 수 있다.

```vue
<template>
  <button>
    <Icon name="lucide:search" />
    검색
  </button>
</template>
```

`name`에는 아이콘 컬렉션과 아이콘 이름을 함께 적는다.

```txt
lucide:search
lucide:user
lucide:settings
```

아이콘 이름은 Iconify 컬렉션에서 확인할 수 있다.

## 아이콘 사용 습관

아이콘은 의미를 빠르게 전달하는 데 도움이 된다.

하지만 아이콘만으로 의미를 전달하면 사용자가 이해하지 못할 수 있다.

중요한 버튼에는 텍스트를 함께 쓰는 것이 좋다.

```vue
<button>
  <Icon name="lucide:save" />
  저장
</button>
```

아이콘만 쓰는 버튼이라면 접근성 이름을 제공해야 한다.

```vue
<button aria-label="검색">
  <Icon name="lucide:search" />
</button>
```

## Nuxt Fonts 설치

Nuxt Fonts는 웹폰트 로딩을 최적화하는 모듈이다.

```bash
npx nuxt module add fonts
```

수동 등록은 다음처럼 한다.

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/fonts']
})
```

설정 없이도 CSS의 `font-family` 선언을 감지해 폰트를 처리할 수 있다.

```vue
<template>
  <div class="page">
    Nuxt Fonts 예시
  </div>
</template>

<style scoped>
.page {
  font-family: Roboto, sans-serif;
}
</style>
```

## 직접 폰트 파일 사용하기

외부 모듈을 쓰지 않고 직접 폰트를 제공할 수도 있다.

```txt
public/
  fonts/
    Pretendard.woff2
```

전역 CSS에 `@font-face`를 작성한다.

```css
@font-face {
  font-family: 'Pretendard';
  src: url('/fonts/Pretendard.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

body {
  font-family: 'Pretendard', system-ui, sans-serif;
}
```

직접 관리하는 방식은 단순하지만, 굵기와 스타일이 많아지면 관리가 복잡해질 수 있다.

## font-display

`font-display: swap`은 웹폰트가 늦게 로드될 때 먼저 기본 폰트로 텍스트를 보여 주고, 폰트가 준비되면 교체하도록 한다.

```css
font-display: swap;
```

텍스트가 보이지 않는 시간을 줄이는 데 도움이 된다.

## 폰트 최적화 습관

폰트는 필요한 것만 사용하는 것이 좋다.

- 필요한 굵기만 로드한다.
- 사용하지 않는 이탤릭 스타일은 빼도 된다.
- 가능하면 최신 브라우저에 적합한 `woff2` 형식을 사용한다.
- 본문 폰트와 제목 폰트를 과하게 나누지 않는다.
- 외부 폰트 요청이 많아지지 않게 관리한다.

폰트 선택은 디자인뿐 아니라 성능 문제이기도 하다.

## 자주 하는 실수

아이콘 라이브러리를 여러 개 설치하고 섞어 쓰면 번들 크기와 디자인 일관성에 문제가 생길 수 있다.

또 폰트의 모든 굵기를 한 번에 불러오는 실수도 흔하다.

```txt
100, 200, 300, 400, 500, 600, 700, 800, 900
```

실제로 필요한 굵기만 선택하는 것이 좋다.

## 정리

Nuxt Icon은 아이콘을 쉽게 사용할 수 있게 해 주고, Nuxt Fonts는 웹폰트 로딩을 최적화하는 데 도움을 준다. 아이콘은 의미와 접근성을 함께 고려하고, 폰트는 필요한 굵기와 형식만 사용해 성능을 챙겨야 한다.
