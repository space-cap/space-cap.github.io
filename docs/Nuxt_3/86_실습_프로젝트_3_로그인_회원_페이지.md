# 실습 프로젝트 3: 로그인 회원 페이지

## 이번 프로젝트에서 만들 것

쿠키 기반 로그인 흐름과 보호된 페이지를 만든다.

이 프로젝트에서 연습할 내용은 다음과 같다.

- 로그인 API
- 로그아웃 API
- 현재 사용자 API
- `useState` 사용자 상태
- 라우트 미들웨어
- 보호된 마이페이지

## 목표 화면

```txt
/login
  로그인 페이지

/mypage
  로그인한 사용자만 볼 수 있는 페이지
```

학습용 예제이므로 실제 DB 대신 고정된 계정을 사용한다.

## 1단계: 로그인 API

`server/api/auth/login.post.ts`

```ts
export default defineEventHandler(async (event) => {
  const body = await readBody(event)

  if (body.email !== 'user@example.com' || body.password !== 'password') {
    throw createError({
      statusCode: 401,
      statusMessage: '로그인 정보가 올바르지 않습니다.'
    })
  }

  setCookie(event, 'session', 'demo-session', {
    httpOnly: true,
    sameSite: 'lax',
    path: '/'
  })

  return {
    ok: true
  }
})
```

실제 서비스에서는 비밀번호 해시, DB 조회, 세션 저장소가 필요하다.

## 2단계: 현재 사용자 API

export default defineEventHandler((event) => {

## 4단계: 인증 composable 만들기

`composables/useAuth.ts`

```ts
export const useAuth = () => {
  const user = useState('auth-user', () => null)

  const fetchUser = async () => {
    user.value = await $fetch('/api/auth/me')
  }

  const login = async (email: string, password: string) => {
    await $fetch('/api/auth/login', {
      method: 'POST',
      body: {
        email,
        password
      }
    })

    await fetchUser()
  }

  const logout = async () => {
    await $fetch('/api/auth/logout', {
      method: 'POST'
    })

    user.value = null
  }

  return {
    user,
    fetchUser,
    login,
    logout
  }
}
```

## 5단계: 로그인 페이지

`pages/login.vue`

```vue
<script setup>
const route = useRoute()
const { login } = useAuth()

const email = ref('user@example.com')
const password = ref('password')
const errorMessage = ref('')

const submit = async () => {
  errorMessage.value = ''

  try {
    await login(email.value, password.value)

    const redirect = typeof route.query.redirect === 'string'
      ? route.query.redirect
      : '/mypage'

    await navigateTo(redirect)
  } catch {
    errorMessage.value = '로그인에 실패했습니다.'
  }
}
</script>

<template>
  <main>
    <h1>로그인</h1>

    <form @submit.prevent="submit">
      <input v-model="email" type="email" placeholder="이메일" />
      <input v-model="password" type="password" placeholder="비밀번호" />
      <p v-if="errorMessage">{{ errorMessage }}</p>
      <button type="submit">로그인</button>
    </form>
  </main>
</template>
```

## 6단계: 인증 미들웨어

`middleware/auth.ts`

```ts
export default defineNuxtRouteMiddleware(async (to) => {
  const { user, fetchUser } = useAuth()

  if (user.value) {
    return
  }

  try {
    await fetchUser()
  } catch {
    return navigateTo({
      path: '/login',
      query: {
        redirect: to.fullPath
      }
    })
  }
})
```

## 7단계: 마이페이지

`pages/mypage.vue`

```vue
<script setup>
definePageMeta({
  middleware: 'auth'
})

const { user, logout } = useAuth()

const handleLogout = async () => {
  await logout()
  await navigateTo('/login')
}
</script>

<template>
  <main>
    <h1>마이페이지</h1>
    <p>{{ user?.name }}님 안녕하세요.</p>
    <p>{{ user?.email }}</p>
    <button @click="handleLogout">로그아웃</button>
  </main>
</template>
```

## 8단계: 서버 API도 보호하기

페이지 미들웨어만으로는 충분하지 않다.

마이페이지 API를 만든다면 서버에서도 세션을 확인해야 한다.

```ts
export default defineEventHandler((event) => {
  const session = getCookie(event, 'session')

  if (session !== 'demo-session') {
    throw createError({
      statusCode: 401,
      statusMessage: '로그인이 필요합니다.'
    })
  }

  return {
    message: '보호된 데이터'
  }
})
```
