# i18n 다국어 처리

## 이번 장에서 배울 것

- i18n이 무엇인지
- Nuxt i18n 모듈 설치 방법
- 언어별 메시지를 작성하는 방법
- 언어별 라우팅의 기본 개념

## i18n이란

i18n은 internationalization의 줄임말이다.

단어가 길어서 첫 글자 `i`와 마지막 글자 `n` 사이의 18글자를 숫자로 줄여 i18n이라고 부른다.

웹 서비스에서 i18n은 여러 언어를 지원하는 구조를 의미한다.

예를 들어 같은 화면을 한국어와 영어로 보여 줄 수 있다.

```txt
ko: 안녕하세요
en: Hello
```

## 언제 i18n이 필요할까

다음 경우 i18n을 고려한다.

- 한국어와 영어를 함께 지원해야 한다.
- 국가별 URL이 필요하다.
- 날짜, 숫자, 통화 표시가 언어별로 달라야 한다.
- SEO에서 언어별 페이지를 구분해야 한다.

처음부터 필요하지 않다면 나중에 도입해도 된다. 다만 서비스가 커진 뒤 도입하면 텍스트를 분리하는 작업이 많아질 수 있다.

## Nuxt i18n 설치

Nuxt i18n 모듈을 설치한다.

```bash
npx nuxi@latest module add i18n
```

수동 등록은 다음처럼 한다.

```ts
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n']
})
```

## 기본 설정

`nuxt.config.ts`

```ts
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'ko', name: '한국어' },
      { code: 'en', name: 'English' }
    ],
    defaultLocale: 'ko'
  }
})
```

이 설정은 한국어와 영어를 지원하고, 기본 언어를 한국어로 둔다.

## 메시지 작성하기

간단한 메시지는 설정에 직접 작성할 수 있다.

```ts
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: ['ko', 'en'],
    defaultLocale: 'ko',
    vueI18n: './i18n.config.ts'
  }
})
```

`i18n.config.ts`

```ts
export default defineI18nConfig(() => ({
  legacy: false,
  locale: 'ko',
  messages: {
    ko: {
      welcome: '안녕하세요'
    },
    en: {
      welcome: 'Hello'
    }
  }
}))
```

컴포넌트에서 사용한다.

```vue
<script setup>
const { t } = useI18n()
</script>

<template>
  <h1>{{ t('welcome') }}</h1>
</template>
```

## 언어 전환 링크

현재 언어를 바꾸는 링크를 만들 수 있다.

```vue
<script setup>
const switchLocalePath = useSwitchLocalePath()
</script>

<template>
  <NuxtLink :to="switchLocalePath('ko')">한국어</NuxtLink>
  <NuxtLink :to="switchLocalePath('en')">English</NuxtLink>
</template>
```

Nuxt i18n은 라우팅 전략에 따라 `/en/about` 같은 언어별 주소를 만들 수 있다.

## SEO와 i18n

다국어 사이트에서는 검색 엔진이 언어별 페이지를 구분해야 한다.

예를 들어 한국어 페이지와 영어 페이지가 각각 있다면, 검색 엔진에게 서로 다른 언어 버전이라는 힌트를 제공해야 한다.

Nuxt i18n은 설정에 따라 언어별 링크와 라우팅을 도와줄 수 있다.

다국어 SEO는 생각보다 복잡하므로, 실제 서비스에서는 Nuxt i18n 공식 문서의 SEO 관련 설정도 함께 확인해야 한다.

## 텍스트를 하드코딩하지 않기

다국어를 지원하려면 템플릿에 직접 문장을 넣는 대신 번역 키를 사용하는 습관이 필요하다.

```vue
<!-- 다국어 전환이 어려움 -->
<h1>안녕하세요</h1>

<!-- 번역 키를 사용 -->
<h1>{{ t('welcome') }}</h1>
```

처음에는 번거롭게 느껴지지만, 언어가 늘어날수록 차이가 커진다.

## 자주 하는 실수

모든 텍스트를 한 파일에 몰아넣는 실수를 조심하자.

프로젝트가 커지면 페이지나 도메인별로 번역 파일을 나누는 것이 좋다.

또 날짜, 숫자, 통화는 단순 번역만으로 충분하지 않다. 지역별 표시 방식도 함께 고려해야 한다.

## 정리

i18n은 여러 언어를 지원하기 위한 구조다. Nuxt에서는 `@nuxtjs/i18n` 모듈을 사용해 언어 설정, 번역 메시지, 언어별 라우팅을 구성할 수 있다.
