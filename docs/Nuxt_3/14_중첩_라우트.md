# 중첩 라우트

## 이번 장에서 배울 것

- 중첩 라우트가 무엇인지
- 폴더 구조로 깊은 URL을 만드는 방법
- 부모 페이지와 자식 페이지의 관계
- `NuxtPage`를 중첩해서 사용하는 흐름

## 중첩 라우트란

중첩 라우트는 주소가 계층 구조를 가지는 라우트다.

예를 들어 관리자 페이지를 생각해 보자.

```txt
/admin
/admin/users
/admin/settings
```

세 주소는 모두 `admin`이라는 공통 영역 안에 있다. 이런 구조를 폴더와 페이지로 표현할 수 있다.

## 기본 폴더 구조

다음 구조를 만들어 보자.

```txt
pages/
  admin/
    index.vue
    users.vue
    settings.vue
```

이 구조는 다음 주소가 된다.

```txt
/admin           -> pages/admin/index.vue
/admin/users     -> pages/admin/users.vue
/admin/settings  -> pages/admin/settings.vue
```

이 방식은 단순한 중첩 주소를 만들 때 사용한다.

## 부모 페이지가 필요한 경우

공통 관리자 메뉴를 유지하면서 아래쪽 내용만 바꾸고 싶을 수 있다.

이럴 때는 부모 페이지 안에 다시 `<NuxtPage />`를 넣는다.

```txt
pages/
  admin.vue
  admin/
    index.vue
    users.vue
    settings.vue
```

`pages/admin.vue`는 `/admin` 하위 페이지들의 공통 틀이 된다.

```vue
<template>
  <section>
    <h1>관리자</h1>

    <nav>
      <NuxtLink to="/admin">홈</NuxtLink>
      <NuxtLink to="/admin/users">사용자</NuxtLink>
      <NuxtLink to="/admin/settings">설정</NuxtLink>
    </nav>

    <NuxtPage />
  </section>
</template>
```

`<NuxtPage />` 위치에 `admin/index.vue`, `admin/users.vue`, `admin/settings.vue`가 바뀌어 나타난다.

## 자식 페이지 작성하기

`pages/admin/index.vue`를 작성한다.

```vue
<template>
  <div>
    <h2>관리자 홈</h2>
    <p>관리자 첫 화면입니다.</p>
  </div>
</template>
```

`pages/admin/users.vue`를 작성한다.

```vue
<template>
  <div>
    <h2>사용자 관리</h2>
    <p>사용자 목록을 표시할 영역입니다.</p>
  </div>
</template>
```

주소를 이동하면 관리자 제목과 메뉴는 유지되고 아래 내용만 바뀐다.

## 중첩 라우트와 레이아웃의 차이

중첩 라우트와 레이아웃은 비슷해 보일 수 있다.

레이아웃은 여러 페이지가 공유하는 큰 화면 틀이다. 예를 들어 전체 사이트의 헤더와 푸터를 담당할 수 있다.

중첩 라우트는 특정 주소 영역 안에서 부모와 자식 화면을 함께 구성하는 방식이다.

처음에는 이렇게 생각하면 쉽다.

- 전체 사이트 공통 구조: layout
- 특정 주소 영역 내부 구조: nested route

## 자주 하는 실수

부모 페이지에 `<NuxtPage />`를 넣지 않으면 자식 페이지가 표시될 자리가 없다.

또 `pages/admin.vue`와 `pages/admin/index.vue`의 역할을 헷갈릴 수 있다. `admin.vue`는 부모 틀이고, `admin/index.vue`는 `/admin`의 기본 자식 페이지로 생각하면 된다.

## 정리

Nuxt는 폴더 구조로 중첩 주소를 만들 수 있다. 부모 페이지에 `<NuxtPage />`를 넣으면 하위 라우트의 화면이 그 위치에 렌더링된다.
