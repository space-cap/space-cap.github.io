# 컴포넌트 자동 등록

## 이번 장에서 배울 것

- `components` 폴더의 역할
- Nuxt의 컴포넌트 자동 등록
- 컴포넌트 이름 규칙
- 큰 화면을 작은 컴포넌트로 나누는 방법

## 컴포넌트란

컴포넌트는 화면을 구성하는 재사용 가능한 조각이다.

예를 들어 다음 요소들은 컴포넌트로 만들기 좋다.

- 헤더
- 푸터
- 버튼
- 카드
- 게시글 목록 아이템
- 검색 폼
- 모달

컴포넌트로 나누면 같은 UI를 여러 곳에서 재사용할 수 있고, 큰 페이지를 작은 단위로 이해할 수 있다.

## components 폴더

Nuxt에서는 `components` 폴더 안의 Vue 컴포넌트를 자동으로 가져올 수 있다.

```txt
components/
  AppHeader.vue
  AppFooter.vue
  PostCard.vue
```

이렇게 파일을 만들면 페이지나 레이아웃에서 별도 import 없이 사용할 수 있다.

```vue
<template>
  <div>
    <AppHeader />
    <NuxtPage />
    <AppFooter />
  </div>
</template>
```

이 기능을 컴포넌트 자동 등록이라고 한다.

## 헤더 컴포넌트 만들기

`components/AppHeader.vue`를 만든다.

```vue
<template>
  <header>
    <NuxtLink to="/">홈</NuxtLink>
    <NuxtLink to="/posts">게시글</NuxtLink>
    <NuxtLink to="/about">소개</NuxtLink>
  </header>
</template>
```

이제 레이아웃에서 사용할 수 있다.

```vue
<template>
  <div>
    <AppHeader />
    <main>
      <slot />
    </main>
  </div>
</template>
```

## 카드 컴포넌트 만들기

게시글 카드 컴포넌트를 만들어 보자.

`components/PostCard.vue`

```vue
<script setup>
defineProps({
  title: {
    type: String,
    required: true
  },
  description: {
    type: String,
    default: ''
  }
})
</script>

<template>
  <article>
    <h2>{{ title }}</h2>
    <p>{{ description }}</p>
  </article>
</template>
```

페이지에서 사용한다.

```vue
<template>
  <PostCard
    title="Nuxt 시작하기"
    description="Nuxt 프로젝트를 만들고 첫 페이지를 작성합니다."
  />
</template>
```

## 폴더 안의 컴포넌트 이름

컴포넌트를 폴더로 나누면 경로가 이름에 반영된다.

```txt
components/
  base/
    BaseButton.vue
  post/
    PostCard.vue
```

일반적으로 다음처럼 사용할 수 있다.

```vue
<template>
  <BaseButton />
  <PostCard />
</template>
```

Nuxt는 중첩 폴더의 경로를 바탕으로 컴포넌트 이름을 만들 수 있다. 프로젝트마다 설정에 따라 다르게 구성할 수 있으므로, 초보 단계에서는 파일 이름을 컴포넌트 이름과 일치시키는 것이 가장 안전하다.

## Lazy 컴포넌트

Nuxt에서는 컴포넌트 이름 앞에 `Lazy`를 붙여 지연 로딩할 수 있다.

```vue
<template>
  <LazyPostCard
    title="나중에 로딩되는 카드"
    description="필요할 때 컴포넌트를 불러옵니다."
  />
</template>
```

처음 화면에 꼭 필요하지 않은 무거운 컴포넌트에 사용할 수 있다.

초보 단계에서는 먼저 일반 컴포넌트 사용에 익숙해지고, 성능 최적화를 배울 때 Lazy 컴포넌트를 다시 살펴보면 된다.

## 자주 하는 실수

컴포넌트 파일 이름과 사용하는 이름이 달라서 인식되지 않는 경우가 있다.

`components/PostCard.vue`를 만들었다면 템플릿에서는 보통 `<PostCard />`로 사용한다.

또 컴포넌트 이름은 여러 단어를 조합하는 것이 좋다. `Button.vue`보다 `BaseButton.vue`, `PostCard.vue`처럼 역할이 드러나는 이름이 안전하다.

## 정리

Nuxt는 `components` 폴더의 컴포넌트를 자동으로 등록한다. 덕분에 페이지나 레이아웃에서 import 없이 바로 사용할 수 있다. 컴포넌트는 큰 화면을 작은 단위로 나누고 재사용성을 높이는 핵심 도구다.
