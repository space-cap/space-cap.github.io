# Delphi 12 Community Edition IDE 입문 문서 작성 계획서

> 작성 기준일: 2026-05-19  
> 작성 목적: Delphi IDE를 처음 사용하는 사람이 입사 초기 업무에 필요한 IDE 조작, 프로젝트 구조, 디버깅, 화면 개발, 빌드 흐름을 빠르게 익히기 위한 학습 문서 시리즈 기획  
> 기준 제품: Embarcadero Delphi 12 Community Edition 계열. 단, 공식 FAQ 기준 Community Edition은 12.1 Athens 제공 여부가 명시되어 있으므로 실제 설치 버전과 회사 사용 버전은 입사 후 재확인한다.

## 1. 문서 작성 목표

이 문서 시리즈의 목표는 Delphi IDE를 처음 접하는 사람이 다음 질문에 답할 수 있게 만드는 것이다.

1. Delphi, RAD Studio, Object Pascal, VCL, FireMonkey는 각각 무엇인가?
2. Delphi Community Edition은 어떤 용도로 사용할 수 있고, 어떤 제한이 있는가?
3. IDE 화면에서 Project Manager, Tool Palette, Object Inspector, Form Designer, Code Editor는 어디에 있고 어떤 역할을 하는가?
4. Delphi 프로젝트는 어떤 파일들로 구성되는가?
5. 버튼 하나를 올리고 이벤트 코드를 작성해 실행하는 기본 흐름은 어떻게 되는가?
6. 브레이크포인트, Step Into, Watch, Call Stack을 이용해 오류를 추적하는 방법은 무엇인가?
7. 회사의 기존 Delphi 프로젝트를 처음 열었을 때 무엇부터 확인해야 하는가?
8. 입사 초기 30일 동안 어떤 순서로 IDE와 언어, 프로젝트 구조를 익히면 좋은가?

## 2. 작성 범위

문서는 "IDE 입문"을 중심에 둔다. Delphi 언어 전체 문법이나 프레임워크 심화보다, 실제 업무에서 IDE를 열고 기존 코드를 따라가며 수정할 수 있는 역량을 우선한다.

| 영역 | 포함할 내용 | 우선순위 |
| --- | --- | --- |
| 제품 이해 | Delphi, RAD Studio, Community Edition, 라이선스 제한, 버전 확인 | 높음 |
| 에디션 비교 | Community, Professional, Enterprise, Architect의 가격/라이선스/기능 차이 | 높음 |
| 설치와 첫 실행 | 설치 전 확인, 계정/라이선스, 테마, 기본 환경 설정, GetIt Package Manager | 높음 |
| IDE 화면 구조 | Welcome Page, Project Manager, Structure View, Object Inspector, Tool Palette, Form Designer, Code Editor | 높음 |
| 프로젝트 구조 | `.dproj`, `.dpr`, `.pas`, `.dfm`, `.res`, unit, form, uses 관계 | 높음 |
| VCL 기본 | 폼, 컴포넌트 배치, 속성 설정, 이벤트 핸들러, 실행 파일 생성 | 높음 |
| 코드 편집 | 코드 탐색, 자동 완성, 선언 이동, uses 정리, 검색, 북마크 | 높음 |
| 디버깅 | 브레이크포인트, Step Over/Into/Out, Watch, Evaluate/Modify, Call Stack, Exception 처리 | 높음 |
| 빌드와 실행 | Debug/Release, Target Platform, Build/Compile/Clean, output 경로, 빌드 오류 읽기 | 높음 |
| 데이터베이스 | FireDAC 개념, 로컬 DB 연결, 회사 DB 연결 시 주의사항, CE 기능 제한 확인 | 중간 |
| 버전 관리 | Git 연동 또는 외부 Git 사용, 변경 파일 확인, `.dproj` 충돌 주의 | 중간 |
| 기존 코드 유지보수 | 레거시 프로젝트 열기, 패키지/컴포넌트 누락, 경로 문제, 빌드 설정 점검 | 높음 |
| 실무 온보딩 | 입사 후 물어볼 질문, 첫 주 체크리스트, 30일 학습 로드맵 | 높음 |

## 4. 반드시 확인해야 할 최신 정보

Delphi와 RAD Studio는 버전별 차이가 크므로 문서 작성 시 다음 항목은 공식 문서 기준으로 확인한다.

| 확인 항목 | 확인 이유 |
| --- | --- |
| Community Edition 제공 버전 | 공식 FAQ 기준 CE는 12.1 Athens가 언급되며, 최신 유료판 기능과 다를 수 있다. |
| 라이선스 제한 | 회사 업무에서 CE 사용 가능 여부는 매출, 팀 규모, 사용 목적 제한과 직접 연결된다. |
| 에디션별 기능 차이 | Community, Professional, Enterprise, Architect 사이에 DB, 플랫폼, 지원, 배포 기능 차이가 있다. |
| 설치 방식 | CE는 공식 FAQ 기준 Web 기반 GetIt 설치 방식으로 안내된다. |
| 32-bit IDE와 64-bit IDE | RAD Studio 12.3 문서에는 64-bit IDE Initial Release가 있으나 CE 12.1 사용 시 적용되지 않을 수 있다. |
| 지원 플랫폼 | CE, Professional, Enterprise, Architect 사이에 지원 기능 차이가 있다. |
| DB 드라이버 | CE는 로컬/임베디드 DB 중심으로 안내되며, 원격 DB 드라이버는 상위 에디션이 필요할 수 있다. |

## 5. 작성 원칙

1. "처음 IDE를 여는 사람" 기준으로 설명한다.
2. 메뉴 경로와 화면 이름은 영어 IDE 표기를 함께 적는다.
3. 예제는 VCL Windows 데스크톱 프로그램을 기본으로 한다.
4. 실무에서 기존 프로젝트를 유지보수하는 상황을 계속 연결한다.
5. Community Edition 기능은 추정하지 않고 공식 문서와 실제 설치 환경으로 확인한다.
6. 단축키는 보조 정보로 제공하되, 메뉴 경로를 먼저 설명한다.
7. 각 문서 끝에는 "바로 해볼 실습", "입사 후 확인할 질문", "자주 막히는 지점"을 넣는다.
8. Delphi 특유의 파일 구조와 IDE 자동 생성 코드는 삭제/수정 주의점을 명확히 표시한다.
