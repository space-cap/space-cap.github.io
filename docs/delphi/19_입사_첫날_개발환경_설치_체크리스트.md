# 입사 첫날 개발환경 설치 체크리스트

> 작성 기준일: 2026-05-19  
> 대상 독자: 회사 PC에서 Delphi 개발환경을 처음 구성하는 입사 초기 개발자  
> 목표: Delphi/RAD Studio, 외부 컴포넌트, Git, DB, 빌드, 실행까지 빠뜨리지 않고 확인한다.

## 1. 시작 전 원칙

회사 PC에 개인 판단으로 Delphi Community Edition을 설치하지 않는다. 회사 표준 버전, 에디션, 라이선스, 설치 순서를 먼저 확인한다.

설치 전 확인 문장:

```text
회사 표준 Delphi/RAD Studio 버전과 에디션, 외부 컴포넌트 설치 순서, Git 저장소, 개발 DB 접속 정보를 확인한 뒤 설치한다.
```
