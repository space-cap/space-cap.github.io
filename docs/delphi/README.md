## 먼저 잡아야 할 큰 그림

- `Delphi`: Object Pascal 기반의 네이티브 애플리케이션 개발 도구입니다.
- `RAD Studio`: Delphi와 C++Builder 등을 포함하는 Embarcadero의 통합 개발 환경 제품군입니다.
- `VCL`: Windows 데스크톱 업무 프로그램에서 많이 쓰이는 UI 프레임워크입니다.
- `FireMonkey`: Windows, macOS, iOS, Android 등 멀티 플랫폼 UI 개발을 위한 프레임워크입니다.
- `Community Edition`: 제한된 상업적 사용 조건이 붙은 무료 에디션입니다. 회사 업무에 사용 가능한지는 반드시 라이선스 조건과 회사 정책을 확인해야 합니다.
