# Community Edition 설치와 라이선스 확인

> 작성 기준일: 2026-05-19  
> 대상 제품: Delphi 12 Community Edition 계열  
> 핵심 메시지: 개인 학습용 설치와 회사 업무용 사용 가능 여부는 반드시 분리해서 판단한다.

## 1. 먼저 결론

Delphi Community Edition은 Delphi를 배우고 개인 프로젝트를 시작하기에 좋은 무료 에디션이다. IDE, 코드 편집기, 컴파일러, 디버거, 시각적 디자이너, 여러 기본 컴포넌트를 제공한다.

하지만 회사 업무에 쓰는 순간 이야기가 달라진다. 공식 FAQ 기준 Community Edition은 제한된 상업적 사용 라이선스이며, 매출 제한과 개발자 수 제한이 있다. 회사의 총 매출, 개발팀 규모, 회사 장비/네트워크 사용 여부, 개발 결과물이 회사에 이익을 주는지에 따라 사용할 수 없을 수 있다.

따라서 설치 전에 이 문장을 기억하면 된다.

> 내 개인 PC에서 학습하려는 Delphi CE와, 회사 업무를 개발하려는 Delphi CE는 같은 설치 파일이어도 법적 의미가 다르다.

## 2. Community Edition이란?

Community Edition, 줄여서 CE는 개인 개발자, 학생, 취미 개발자, 초기 스타트업, 제한된 상업적 사용을 위한 무료 에디션이다.

공식 FAQ 기준으로 Delphi CE와 C++Builder CE는 무료로 다운로드할 수 있지만, 라이선스 제한과 매출 제한이 붙는다. 또한 공식 FAQ에는 `12.1 Athens`도 Community Edition으로 제공된다고 안내되어 있다.

여기서 주의할 점은 "Delphi 12"라는 말이 항상 같은 제품 상태를 뜻하지 않는다는 것이다.

- 문서에서는 RAD Studio 12 Athens 전체를 설명할 수 있다.
- 최신 유료판 기능이 Community Edition에 없을 수 있다.
- CE 제공 버전이 유료판 최신 버전과 다를 수 있다.
- 회사가 쓰는 버전은 10.x, 11.x, 12.x 등 다양할 수 있다.

입사 전 개인 학습은 CE로 시작해도 괜찮다. 입사 후 실무는 회사가 보유한 정식 라이선스와 버전에 맞춰야 한다.

## 3. 공식 FAQ 기준 핵심 제한

아래 내용은 2026-05-19 기준 Embarcadero 공식 Community Edition FAQ를 바탕으로 정리한 것이다. 실제 법적 판단은 License Agreement 원문과 회사 계약을 기준으로 확인해야 한다.

| 항목 | Community Edition 기준 |
| --- | --- |
| 비용 | 무료 다운로드 가능 |
| 대상 | 개인, 취미 개발자, 학생, 오픈소스 기여자, 제한된 상업적 사용 |
| 매출 제한 | 연간 매출이 US$5,000에 도달하면 유료 라이선스 필요 |
| 회사 사용 | 회사 총 매출이 US$5,000을 초과하면 내부 앱 개발/배포에 CE 사용 불가로 안내됨 |
| 개발자 수 | 개발팀이 5명을 초과하면 유료 라이선스 필요 |
| 기간 | CE 라이선스는 1년 기간으로 안내됨 |
| 설치 방식 | CE는 Web 기반 GetIt installer 사용 |
| 기술 지원 | 유료 에디션과 다르게 공식 기술 지원 범위가 제한됨 |
| 원격 DB | 로컬/임베디드 DB 중심. 넓은 범위의 원격 DB 접속은 Enterprise/Architect 영역으로 안내됨 |

실무적으로 가장 중요한 항목은 매출 제한과 회사 사용 제한이다. "나는 신입이고 개인 공부용으로 깔았다"는 말과 "회사 업무 프로젝트를 그 IDE로 열고 수정했다"는 말은 완전히 다르다.

## 4. 회사 업무에서 CE 사용 전 확인할 것

입사 후에는 다음 질문을 먼저 확인한다.

1. 회사에서 제공하는 Delphi 라이선스가 있는가?
2. 회사가 쓰는 정확한 제품은 Delphi인가, RAD Studio인가?
3. 에디션은 Community, Professional, Enterprise, Architect 중 무엇인가?
4. 버전은 10.x, 11.x, 12.1, 12.3, 13.x 중 무엇인가?
5. 회사 업무용 PC에 CE를 설치해도 되는가?
6. 회사 네트워크 안에서 개인 CE를 사용해도 되는가?
7. 회사 프로젝트를 CE로 열거나 빌드해도 되는가?
8. DB 드라이버나 외부 컴포넌트가 CE에서 지원되는가?
9. 빌드/배포는 개인 IDE에서 하는가, 별도 라이선스가 있는 PC에서 하는가?

이 질문들은 소극적인 질문이 아니다. 오히려 실무적으로 아주 좋은 질문이다. 개발 도구 라이선스는 나중에 문제가 되면 개인이 감당하기 어렵다.

## 5. 설치 전 준비

개인 학습용으로 Delphi CE를 설치한다면 다음을 준비한다.

| 준비물 | 설명 |
| --- | --- |
| Embarcadero 계정 | 다운로드와 라이선스 발급에 필요하다. |
| Windows PC | RAD Studio/Delphi IDE는 Windows 환경에서 설치한다. |
| 충분한 디스크 용량 | IDE, SDK, 패키지 설치에 공간이 필요하다. |
| 안정적인 인터넷 | CE는 Web 기반 설치 방식으로 안내된다. |
| 관리자 권한 | 설치 경로와 SDK/드라이버 설치에 필요할 수 있다. |
| 회사 정책 확인 | 회사 PC에 설치할 경우 반드시 먼저 확인한다. |

설치 문서나 블로그를 볼 때는 작성 시점을 확인해야 한다. Delphi는 버전별 설치 화면, GetIt 항목, 지원 플랫폼이 바뀔 수 있다.

## 6. 설치 흐름

세부 화면은 버전에 따라 달라질 수 있지만, 개인 학습용 CE 설치 흐름은 보통 다음과 같다.

1. Embarcadero의 Delphi Community Edition 페이지에 접속한다.
2. 다운로드 신청 또는 계정 로그인을 진행한다.
3. 이메일 또는 계정 페이지에서 설치 파일/라이선스 정보를 확인한다.
4. Web installer를 실행한다.
5. 설치할 플랫폼과 기능을 선택한다.
6. 설치가 끝나면 IDE를 실행한다.
7. 라이선스 등록 또는 로그인 과정을 마친다.
8. `Help > About` 또는 IDE 시작 화면에서 버전과 에디션을 확인한다.

설치 중 선택지가 많다면 처음에는 욕심내지 않는 편이 좋다. Windows VCL 학습이 목적이라면 Windows 데스크톱 개발에 필요한 항목부터 설치하고, 모바일/크로스 플랫폼 SDK는 회사 요구가 있을 때 추가로 확인한다.

## 7. 설치 후 바로 확인할 것

설치가 끝났다면 다음을 적어둔다.

```text
제품명:
에디션:
버전:
빌드 번호:
설치 날짜:
라이선스 만료 예정일:
설치 PC:
```

IDE에서는 보통 `Help > About` 메뉴에서 제품 정보와 버전을 확인한다. 회사에서 문제를 물어볼 때 "Delphi 12입니다"보다 "Delphi 12.1 Athens Community Edition입니다"처럼 말하는 편이 훨씬 정확하다.

## 8. 첫 실행 설정

공식 First Look 문서에 따르면 RAD Studio Athens를 처음 시작할 때 테마를 선택하고, 소스 제어와 공통 설정을 구성할 수 있다.

처음에는 다음 정도만 설정해도 충분하다.

| 항목 | 추천 |
| --- | --- |
| Theme | 눈이 편한 테마 선택 |
| Source Control | 회사 Git 정책이 있으면 그 기준을 따른다. 개인 학습은 외부 Git 도구를 써도 된다. |
| Layout | 기본 레이아웃으로 시작 |
| Font | 한글과 코드가 잘 보이는 폰트 선택 |
| Autosave | 팀 정책 확인 전까지 기본값 유지 |

초기에는 IDE를 많이 꾸미는 것보다 기본 레이아웃에 익숙해지는 것이 좋다. 선배와 화면을 같이 볼 때 기본 위치를 알고 있으면 소통이 빠르다.

## 9. CE에서 자주 생기는 오해

### 오해 1. 무료니까 회사 업무에도 괜찮다

아니다. 공식 FAQ 기준 CE는 제한된 상업적 사용 라이선스다. 회사 총 매출, 개발팀 규모, 회사 장비 사용 여부와 연결된다.

### 오해 2. 최신 RAD Studio 문서의 모든 기능이 CE에 있다

아니다. 공식 문서는 RAD Studio 전체 또는 유료 에디션까지 포함해 설명할 수 있다. CE 제공 버전과 기능 범위는 따로 확인해야 한다.

### 오해 3. 개인 PC에 설치했으니 회사 프로젝트를 열어도 된다

위험하다. 그 사용이 회사에 이익을 주거나 회사 업무와 연결되면 CE 범위를 벗어날 수 있다.

### 오해 4. CE로 만든 프로젝트는 나중에 유료판에서 못 연다

공식 FAQ는 CE로 만든 프로젝트 파일을 유료 버전에서 열 수 있다고 안내한다. 다만 사용한 컴포넌트, 패키지, 플랫폼, DB 드라이버에 따라 추가 확인은 필요하다.

## 10. 입사 후 권장 행동

입사 첫날 또는 장비 세팅 시 이렇게 움직이면 좋다.

1. 회사가 지정한 설치 파일과 라이선스를 받는다.
2. 개인적으로 설치한 CE와 회사 업무용 IDE를 혼용하지 않는다.
3. 회사 프로젝트를 열기 전에 필요한 외부 컴포넌트 목록을 받는다.
4. `Help > About` 화면 기준으로 제품/버전/에디션을 기록한다.
5. 기존 프로젝트의 Target Platform과 Build Configuration을 확인한다.
6. 첫 빌드는 선배가 안내한 절차대로만 수행한다.

도구 설치는 개발의 첫 단추다. 여기서 "일단 되는 대로" 설치하면 나중에 패키지 경로, 라이선스, 빌드 설정이 엉켜 시간을 잃는다.

## 바로 해볼 실습

개인 학습용 PC에서만 진행한다.

1. 공식 Community Edition FAQ를 읽고 매출/팀 규모 제한을 메모한다.
2. Delphi CE 다운로드 페이지에서 현재 제공 버전을 확인한다.
3. 설치 후 `Help > About` 화면에서 버전과 에디션을 기록한다.
4. 새 VCL Forms Application을 만들고 실행해본다.
5. 설치 경로와 프로젝트 기본 저장 경로를 기록한다.

5. 빌드/배포는 개발자 PC에서 하나요, 전용 PC나 서버에서 하나요?
6. 설치 순서 문서나 사내 표준 개발환경 문서가 있나요?

## 자주 막히는 지점

- CE와 Trial을 혼동한다.
- Delphi CE와 RAD Studio Trial을 혼동한다.
- CE로 회사 프로젝트를 열어도 되는지 확인하지 않는다.
- 공식 문서가 설명하는 최신 기능을 CE에서도 당연히 된다고 생각한다.
- DB 연결 기능 범위를 확인하지 않고 설치한다.
- 회사 공통 컴포넌트 설치 순서를 무시한다.
