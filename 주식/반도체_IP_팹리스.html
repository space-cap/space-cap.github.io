IP 전문 vs 팹리스 비교

설계 IP 전문 (오픈엣지, 칩스앤미디어)

  • 공장·재고 없음 → 최소 자본으로 최대 마진
  • 한번 채택 시 안정적 로열티 반복 수익
  • 글로벌 빅테크가 고객 → 레퍼런스 확보 중요
  • 영업 사이클 길어 단기 실적 가시성 낮음

팹리스 (LX세미콘, 어보브반도체)

  • 설계 후 외주 제조 → 재고 부담 일부 존재
  • 양산 규모가 수익성을 좌우
  • 스마트폰·가전 경기와 연동성 높음
  • IP 전문 대비 밸류에이션 프리미엄 낮음
